# N8E Claim Boundary

Allowed N8E statement:

- N8E is a formal engineering ablation with caveats.
- Raw Doppler FGO factor is active but low marginal value in current
  no-feedback FGO.
- Candidate factors remain diagnostic unless a later stage promotes them.
- FGO output is not fed back into EKF.
- FGO output does not replace EKF NAV.
- Trace/final_v23 outputs are not solver input and are not used for tuning.
- N8E is not a paper performance claim.
- N8E makes no outperform final_v23 claim.

Blocked N8E statement:

- Any unqualified paper performance claim.
- Any claim that FGO output replaces EKF NAV.
- Any claim that FGO output feeds back into EKF.
- Any claim that trace/final_v23 output tunes FGO weights.
- Any claim that Go2 fields are truth.
- Any promotion of diagnostic candidate factors to formal factors.
