# N7B2 Contact-Conditioned Velocity Segment Review

This review asks whether the revised contact-state candidate improves the
interpretation of Go2 velocity consistency.

Comparisons:

- Go2 velocity versus receiver-native velocity.
- Go2 velocity versus raw Doppler velocity factor.
- Bias and RMSE grouped by contact-state v2 label.
- Velocity norm distribution grouped by contact-state v2 label.

The comparison is source consistency, not truth error. Go2 velocity is not
truth, receiver-native velocity is not a truth label, and raw Doppler velocity
is not a truth label.

The result can support a future N7C review only if contact-state quality is
ready and velocity consistency by contact state is acceptable. N7B2 itself
does not activate any solver prior.
