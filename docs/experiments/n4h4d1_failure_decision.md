# N4H4D1 Failure Decision

The N4H4D1 decision combines config/init parity, first-epoch diagnostics, update residual diagnostics, and the update-isolation matrix.

The classifier may recommend a next stage such as config unit repair, time alignment repair, mechanization debug, position/velocity/yaw update convention fixes, covariance/noise investigation, state feedback sign repair, or more instrumentation.

This decision is a debugging route selector. It is not a parity pass, not a proposed factor result, and not a formal performance claim.
