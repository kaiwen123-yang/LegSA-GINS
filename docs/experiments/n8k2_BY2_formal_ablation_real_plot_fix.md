# N8K2 BY2 Formal Ablation Real Plot Fix

N8K2 fixes the N8K formal ablation figures that were materialized as low-information audit panels. The stage keeps the N8K formal ablation runtime evidence, loads NAV/STD/EVAL/feedback reports where available, and regenerates applicable figures as real trajectory, time-series, factor, feedback, or legged-factor plots.

Scope boundaries:
- no algorithm math changes;
- no feedback gate, covariance, window, or mode tuning;
- no degradation matrix run;
- no trace/final_v23 tuning or solver input;
- no paper performance claim or outperform final_v23 claim;
- runtime figures and reports are not committed.

All BY2 figure outputs are addressed by the `BY2_PLOT_AUDIT_ROOT` role alias.
