# N7C5 Contact Probability Factor Review

N7C5 treats contact as probability/confidence, not a hard threshold. The contact
review checks per-foot probability, support/swing probability, uncertainty,
alternating pattern, and mode/gait consistency.

The default recommendation is to use contact as weighting/gating unless the
probabilistic evidence is strong enough for a future factor.

No trace/final_v23 output is used for contact tuning.
