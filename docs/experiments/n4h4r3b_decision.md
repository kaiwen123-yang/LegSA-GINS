# N4H4R3B Decision

Decision precedence:

1. Measurement-copy or output-substitution suspect -> writer/measurement-copy fix.
2. Reference independence failure -> evaluator/reference fix.
3. Covariance/config mismatch -> covariance/config parity fix.
4. Over-tight residual/gain evidence -> residual/gain parity fix.
5. No copy/reference/config issue and metric gates pass -> visual validation with an external-clean closeness caveat.

Metric-gate pass is not enough when EXTERNAL_CLEAN_REPLAY closeness fails. Too-good results require this audit and must not be written as an outperform-final_v23 claim.

No raw Doppler, Go2 prior, LSIM/OIM, source-aware weighting, FGO, output-only correction, tuning, epoch deletion, or paper performance claim is part of N4H4R3B.
