# N9A Summary Panels

N9A writes cross-condition summary panels under `<N9A_SUMMARY_DIR>`.

The summary panel set includes:

- condition by algorithm horizontal metric heatmap/bar panel;
- condition by algorithm yaw metric panel;
- condition by algorithm up metric panel;
- pass/fail boundary panel;
- degradation strength panel with missing degradation results marked rather than
  fabricated;
- robustness ranking panel;
- algorithm contribution stack panel.

These panels are audit and case-review assets only. They are not paper
performance claims and do not claim outperform final_v23.
