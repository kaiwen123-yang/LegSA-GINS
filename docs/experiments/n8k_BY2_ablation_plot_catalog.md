# N8K BY2 Ablation Plot Catalog

The ablation plot catalog defines 14 required categories for every formal
ablation variant:

- trajectory;
- position errors;
- velocity;
- attitude;
- consistency;
- observation quality;
- comparison;
- summary panels;
- case review;
- FGO factors;
- feedback;
- legged factors;
- ablation metadata;
- audit sanity.

If a figure is not applicable to a variant, N8K writes a documented placeholder
panel and records the reason in the plot coverage report.
