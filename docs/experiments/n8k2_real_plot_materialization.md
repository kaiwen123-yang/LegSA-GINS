# N8K2 Real Plot Materialization

Applicable data figures must contain plotted rows, axes, and figure-specific visual encodings. N8K2 regenerates trajectory, position, velocity, attitude, consistency, observation-quality, comparison, FGO-factor, feedback, and legged-factor figures under the N8K2 BY2 audit output role.

Not-applicable panels are allowed only when the N8K catalog marks a figure as not applicable and records a reason.
