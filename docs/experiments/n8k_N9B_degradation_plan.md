# N8K N9B Degradation Plan

N8K only writes the N9B degradation plan.

N8K does not run the full degradation matrix and does not generate degradation
runtime artifacts.

The N9B plan includes existing degradation families and extensions for receiver
velocity, raw Doppler, Go2 attitude, Go2 horizontal velocity, contact
probability, foot kinematic signals, yaw-rate/relative-odometry factors, and
combined degradation.

N9C is reserved for degradation figures and case review.

N9D is reserved for math, output-evaluation, and filter-construction full-chain
audit.
