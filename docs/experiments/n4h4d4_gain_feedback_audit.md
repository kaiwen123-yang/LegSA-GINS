# N4H4D4 Gain Feedback Audit

This audit summarizes debug-only Kalman gain proxies, dx magnitudes, covariance trace/min-diagonal, and stateFeedback application counts.

It is meant to identify over-correction, covariance collapse, large attitude dx spikes, and missing feedback. It is not a retuning stage.

No output-only correction, no epoch deletion, and no performance claim are allowed.
