# N7B2 Next Stage Plan

N7B2 is a gate before any Go2 velocity/contact weak-prior activation.

If v2 contact remains uncertain, the next stage is
`N8A_no_feedback_FGO_foundation_or_N7B3_contact_model_review`.

If contact becomes ready and contact-conditioned velocity consistency is
acceptable, the next stage may be
`N7C_go2_velocity_contact_weak_prior_activation`.

If contact becomes ready but velocity consistency remains weak, the next stage
is `N7C_yaw_rate_or_contact_only_prior_review_or_N8A`.

None of these decisions are paper performance claims. PR #21 remains an open
evidence branch and is not part of the N7B2 merge path.
