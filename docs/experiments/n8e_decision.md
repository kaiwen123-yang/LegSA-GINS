# N8E Decision

N8E decision status is produced by
`N8E_FORMAL_ABLATION_WITH_CAVEAT_DECISION_REPORT.json`.

The ready condition is:

- matrix complete
- all required caveats present
- claim boundary passes
- no-feedback/FGO boundary passes
- figures generated and nonempty

The expected ready status is
`formal_engineering_ablation_ready_with_caveats`, with recommended next stage
`N9_paper_experiment_packaging_or_N8F_additional_data_review`.

Candidate factors still need deeper review, so the secondary recommendation is
`N8F_candidate_factor_review`.
