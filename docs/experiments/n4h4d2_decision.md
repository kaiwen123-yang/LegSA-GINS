# N4H4D2 Decision

N4H4D2 produces `N4H4D2_DECISION_REPORT.json`.

The decision prioritizes confirmed formula evidence, then single diagnostic
variants that strongly improve the failed replay, then short-window
mechanization frame/gravity evidence. If evidence remains coupled or weak, the
next step is extended instrumentation rather than a blind solver edit.

No output-only correction, parameter tuning, epoch deletion, trace solver input,
or performance claim is allowed in this stage.
