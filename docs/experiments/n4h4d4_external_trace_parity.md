# N4H4D4 External Trace Parity

N4H4D4 compares LegSA-v23-core output with external clean replay NAV only as an evaluation reference.

External clean NAV is diagnostic/evaluation-only. It is not solver input, not a tuning signal, and not an output-only correction source.

The report records aligned row count, first-row/early-window differences, full-run H/Up/Yaw/Roll/Pitch gaps, and first divergence markers.

No performance claim is made in this stage.
