# N8C Plot Catalog

N8C required figures:

- horizontal trajectory and horizontal difference time plots
- horizontal, up, yaw, roll, and pitch error plots
- default-vs-weak yaw policy plots
- factor residual proxy plots
- factor contribution on/off plots
- candidate diagnostic-only delta plot
- visual decision and metric summary panels

Each mandatory figure is recorded in `N8C_PLOT_DATA_COVERAGE_REPORT.json` with plotted series count, row counts, x/y ranges, nonempty status, monotonic time, and reason codes.
