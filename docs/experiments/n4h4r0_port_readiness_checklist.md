# N4H4R0 Port Readiness Checklist

Before N4H4R1 starts, the following must be true:

- Reference submodule is present.
- Reference gitlink mode is `160000`.
- Reference commit is recorded.
- License status is checked.
- Core source paths are located.
- Port module manifest is created.
- Raw/result directories are excluded.
- Target new directory is selected.
- Old self-written core is marked diagnostic.
- Config/input/writer contracts are aligned.
- Audit scripts are in place.
- Chinese comments are required for critical C++ functions.
- No performance claim is made.

N4H4R1 may start only after this checklist is satisfied or missing evidence is
recorded explicitly as `evidence_missing`.
