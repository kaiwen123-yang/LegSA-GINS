# N8J Generalization Plan

N8J is BY2 engineering validation only.

If N8J passes, the next work may package the BY2 experiment evidence or start
BY3 replication/generalization checks. N8J itself does not validate indoor,
outdoor, or GNSS-degraded generalization.

The selected policy must remain fixed during N8J. Generalization work must
preserve:

- no trace/final_v23 feedback tuning;
- no output substitution;
- no direct NAV overwrite;
- no future-data feedback;
- no paper performance claim.
