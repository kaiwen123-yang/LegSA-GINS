# N4H4D3 Guarded Fix Replay

The guarded replay runs the default LegSA-v23-core solver on clean status-yaw
input without diagnostic variants.

The output is compared against the N4H4D baseline, the D2 diagnostic matrix, and
the external clean replay reference. The comparison is an engineering gap screen,
not a proposed factor result and not paper performance evidence.

Runtime artifacts generated by this stage must remain outside git.
