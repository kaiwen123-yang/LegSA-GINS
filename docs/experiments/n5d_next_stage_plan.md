# N5D Next Stage Plan

If N5D status is ready_for_source_aware_weighting:

N6A begins a source-aware LSIM/OIM weighting foundation. N6A must start as a
separate stage with its own claim boundary and must not retroactively turn N5D
stress results into paper performance.

If N5D status is ready_with_weak_stress_evidence:

N6A may treat raw Doppler as a candidate source, but the weak stress evidence
must stay explicit in reports.

If N5D reports source, time, clean-degradation, or consistent-degradation
blockers:

N5E should fix raw Doppler source integrity, time alignment, noise model, or
gating before any source-aware weighting work.

N5D itself does not implement LSIM/OIM, source-aware weighting, Go2 prior, or
FGO.
