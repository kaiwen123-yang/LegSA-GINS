# N8K BY2 Ablation Case Review Protocol

N8K writes one case review per formal ablation variant and an overall summary
report.

Figure suitability labels:

- `internal_audit_only`;
- `paper_candidate`;
- `redraw_for_paper`;
- `direct_use_possible`.

N8K defaults generated figures to `internal_audit_only`; paper figure selection
is deferred until later packaging stages.
