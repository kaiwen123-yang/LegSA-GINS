# N4H4D2 Formula Parity Audit

N4H4D2 audits LegSA-v23-core formulas against read-only reference evidence.

The audit records short source aliases, line numbers, and formula summaries for
Earth/Rotation, INS mechanization, GNSS update, EKFUpdate, and stateFeedback.
It does not copy long reference source, compile reference code, or use
final_v23 output as solver input.

Formula mismatch candidates are diagnostic leads for a later guarded fix stage.
They are not proof of a final performance result.
