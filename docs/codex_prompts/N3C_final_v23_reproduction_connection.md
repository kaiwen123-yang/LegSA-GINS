# N3C final_v23 Reproduction Connection

Stage N3C connects observed final_v23/KF-GINS baseline outputs to standardized
LegSA-GINS baseline files and defines the BY2 source-role/path contract.

This stage adds parser, standardizer, manifest, dry-run wrapper, BY2 path-probe,
documentation, audits, and tests. It does not implement proposed factors, raw
Doppler, Go2 priors, source-aware weighting, LSIM/OIM, FGO, trace tuning,
output-only correction, or numerical performance claims.
