# N4 LegSA-GINS Filter Core

Stage N4 adds a self-owned C++ filter core foundation with lightweight math,
21-state error-state contracts, simplified IMU propagation, receiver-native
position/velocity/heading updates, toy dry-run outputs, audits, docs, and tests.

This stage does not implement raw Doppler, Go2 priors, source-aware weighting,
LSIM/OIM, FGO smoothing, final_v23 numerical parity, trace solver input, or any
performance claim.
