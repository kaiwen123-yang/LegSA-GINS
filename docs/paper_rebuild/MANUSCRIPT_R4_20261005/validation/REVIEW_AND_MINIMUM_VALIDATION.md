## 4. 第二批：最少新量测，不能靠旧RMSE代替

**V02：时间对应。**先恢复BY2/H/O每session所用两路事件索引、映射/base_time/offset、操作者与选点区间，区分“截公共起点”与“修正时轴”。新短记录至少3个分离的独立对应marker：2个拟合b/d，剩余及更多作留出。这只是下限；只有公共触发/已知或稳定latency、同一物理响应等条件有依据时，才能把斜率解释clock drift。硬件接口是否支持公共触发当前未知，不能保证有；没有时只估effective event relation，不称纯clock offset。

marker可在起/中/末，但不要追求加速度峰与GNSS位置峰机械重合。记录sensor acquisition、外层message stamp、到达/写盘时刻的可知范围。无独立latency证据要把它留在有效关系内。留出残差门在实验前依据实际采样/提取分辨率登记，不能预填1ms等伪校准界；剩余误差用真实速度、加速度、投影角变化率传播。不得用导航或reference RMSE搜索最优offset。单次踢动不足以分开b/d/delay，增加marker也不自动解除delay随时间变化的混淆。

**V03：安装/输出点。**对同一实际结构做一次有坐标标志的静态survey：右/左天线相位中心或可追溯厂家偏移、robot IMU敏感点及轴、FP X-mark/sensor/POI。独立重复读取/定位3次是重复性检查下限，记录工具分辨率与方法系统项，不能由3次直接保证全部误差已识别。采集时实际TF/配置比教程截图更重要。现有CAD可说明结构，0.3103m部件原点距离不等于0.350m相位中心基线；275mm建模占位、手册3cm指导和1m基线0.4°规格都不能填本次uncertainty。现在测量也不能无证追溯为所有旧session已校准；须确认版本/安装未变化并保留旧未测项。

**V04：fixed正确性与可用性联合检查。**可与survey共用fixture，新数据最小覆盖24短block：2非平行已知方向×水平/实测tilt×良好接收/受遮挡×3独立重新获取。每block事前固定记录时长及重获取操作，不等fixed成功才结束。保留fresh dual-fixed数量、等待/连续性、none/float、相对独立投影角的误差尾，以及fixed但方向错误的block；错误定义需预登记应用容差并把survey uncertainty算入，不能照原RMSE临时定阈值。

24是覆盖条件的最小设计，**不够证明极低失效率**，长序列的数千epoch也不是数千次独立fixed尝试。已知几何能判断方向对错，但不自动证明每个integer向量正确；若要integer correctness还需可验证整数oracle/硬件相位偏差等证据。原RTKLIB或rawcore在新数据上的执行如需要，另冻结同一输入/窗口/支持合同，不据成绩选条件，不改旧9/12结果。

**V05/V06：参考与最小预算。**GPS现表只称agreement，可先保留shared cross-term及同support解释，不必立刻买新的全场轨迹系统。若坚持绝对厘米级/真精度排序，则新增不共享主GNSS观测的survey或光学等reference；实际装置可用性未知，不能承诺。静态方向survey只闭合静态角/几何，不代替动态位置truth。

TIM优先用V03/V04的同时static数据估Ub及时间相关性，再用未用于预算拟合的独立方向block检验uψ预测和覆盖。运动中位置变化不是误差cov；双receiver共同GNSS来源的cross不得默认为0。wrong-fixed离散错误与correct-fixed小扰动Gaussian预算分开。若无法识别cross，报告明确假设的bounds或保留agreement，不能填0后靠MonteCarlo证明校准。HV如要做其uncertainty贡献，还需独立运动/姿态/time/point及cross记录；否则主稿只研究heading主测量链，HV保留working proxy即可。
