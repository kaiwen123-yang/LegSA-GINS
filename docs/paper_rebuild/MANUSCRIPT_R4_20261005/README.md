# 论文主线判断、r4改写与下一步

2026-10-05。本轮交付是可连续阅读的GPS Solutions英文正文，以及原文学习、原V3效果量和最小补测方案。不是新增一批导航运行。原V3结果、方法源代码和原始数据均保持原身份。

## 1. 主线合适，但应把真正有证据的贡献放到最前面

建议主线为：**短基线航向与机器人运动信息辅助的四足机器人GNSS/INS导航：有效工况、收益大小与失效边界。**英文工作标题为 *Short baseline heading and robot velocity aiding for quadruped GNSS INS navigation*。描述性标题优先；LegSA-GINS保留为项目名称，F04等内部键留在补充材料，暂不硬造一个“新滤波理论”的缩写。

需要回答的实际问题很明确：机器人慢走、侧移和机身倾斜时，速度方向不能直接当机身航向；短安装间距又放大双天线位置差的方向误差。在这个条件下，如何选择可信的基线航向，怎样接入机身姿态和速度，哪些额外信息真正有用，以及什么情况下这些辅助信息也不能继续工作。

**现有数据能支撑这条应用与方法评估主线；还不能仅凭模块组合和大量矩阵成员证明足够强的新理论贡献或保证期刊录用。**投稿价值应落在可复核的观测设计、明确的信息依赖和量化的条件收益。若希望把贡献进一步提高，应增加能回答固定正确性、安装/时间误差和冻结参数转用的证据，而不是把同样的模块换一个宏大的名字。

不建议把当前稿改成“新的短基线整数模糊度固定方法”。原V3使用双接收机位置解构造基线投影航向，没有提出新的整数搜索/验证准则。可以认真研究短基线固定状态、动基线路线的有效性与失败，但它们目前是测量环节与横向比较，不是原算法已经完成的AR创新。

## 2. 能写进正文的四条具体发现

下表全部来自原V3封存结果的再整理。Δ为完整配置减去对应删项配置，均保持原支持集合。中断结果使用原45个配对情形，后来135次诊断没有替换原数值。

| 论文问题 | 已有结果 | 应写出的含义 |
|---|---|---|
| 在线航向到底解决了什么 | 三自然序列无在线航向的yaw RMSE为8.090/7.137/5.739°，完整配置为1.886/1.934/2.434°；完整配置H RMSE为0.0979/0.0684/0.0545 m | 航向信息的作用明确；完整配置相对已带检查航向的基准只有较小自然增量，不能把全部收益都归给后加模块 |
| 机器人信息有什么独立效果 | 519个共同完成配对中，姿态辅助使roll/pitch全部降低，中位减少1.072/0.664°；速度辅助的H改善472对，中位减少1.12 mm、均值减少10.65 mm | 姿态收益明显，普通扰动下速度的典型增量有限；必须同时给幅度和方向数 |
| 速度辅助在哪种中断中有意义 | 保留航向、移除GNSS位置和速度20 s的9种位置中，整窗H RMSE中位数从无速度辅助的7.961 m降至0.241 m；完整GNSS中断20 s则为10.301与10.292 m | 最强证据是有条件的速度辅助。这里是整个274 s评价窗的统计，不是中断终点误差；不能声称完全GNSS失效后依然独立导航 |
| 权重设计是否全面提高精度 | 去掉covariance inflation后完成数由519/541变成513/541；共同完成513对的H中位Δ为+0.98 mm，均值+24.24 mm | 它在本批扰动中减少6个失败，但普通已完成情形存在误差代价。成功运行数量与误差要一起报告 |

Doppler在518对中使H降低453对，但中位减少仅约0.15 mm、均值约1.55 mm；因此保留为辅助来源，不能把它写成主要厘米级性能来源。速度删项配对中Up变差365对，但中位变化只有约+0.004 mm，平均反而降低0.60 mm；只数“多少对变差”同样会夸大实际影响。

以上自然误差均相对共用GNSS来源的商业融合参考。现有事实不支持将其改称独立真值。可以完整报告参考一致性、相同支持下的差异和失败情况；如果要宣称绝对精度与真实误差优越性，需要独立参考或可识别的相关模型。

## 3. 这次具体改写了什么

[GPS Solutions r4全文](manuscript/manuscript_gps_solutions_r4.md)与同目录Word保持同一内容。Word由Microsoft Word实际排成19页、5386词；摘要214词、6个关键词；正文双倍行距，表内单倍行距。共有5张可编辑表、6个原生独立公式、7个原生行内数学对象。所有19页已实际目视检查，数值与关键方法条件另经同行代理定向核读。

1. 摘要和引言先写机器人具体运动、短基线方向与辅助速度的依赖，再写做了什么和获得什么结果。避免用“完整框架”“全面验收”“证据闭环”代替研究问题。
2. 方法把heading准入、SDK转换与dispatch、按来源的R放大写在正文，包括原封配置的门限、alpha和cap。不能要求读者翻审计日志才能理解主要算法。
3. 结果按自然表现、失败数量、组件效应量、两类中断、外部路线组织。5张表与这些问题直接对应，mean、median、分母和负结果同时保留。
4. 将版本审计和大量hash移到证据文件，Discussion解释信息路径和适用条件。保留会改变科学解释的缺口：7段IMU缺口暴露22个成员，影响尚未单独识别；后来分段诊断不替原结果。
5. 正文不再引用实际上尚未插入的Fig.1–8。按作者安排，本轮没有接管绘图；已有图源仍供专门绘图对话使用。最终图需与本稿问题匹配，不能把没有图说成投稿排版完成。

全文阅读了作者提供的三篇直接相关范文，共37页，实际查看16页关键图表：[逐篇写法与r3→r4依据](paper_models/THREE_PAPER_WRITING_MODELS.md)。它们分别示范具体参数问题、同骨架方法对照和TIM装置—测量—实验组织。学习的是论证方式，不复制原文措辞、图像或未充分支持的强结论。

一个中文内容示例，可用于后续中文讲解而非另造新结果：

> 当接收机位置和速度失效而基线航向仍可用时，机器人速度仍能够转换到导航坐标系，并通过航向事件进入滤波更新。在20 s中断的9个配对情形中，加入这一速度观测后，整窗水平RMSE的中位数由7.961 m降为0.241 m。完整GNSS中断时，姿态转换和更新调度同时失去所需输入，两种配置的误差十分接近。这说明速度消息的存在不等于可用的独立速度观测；其作用取决于方向信息和更新入口是否保留。

## 4. 横向对比在论文里如何使用

外部比较已有多个输入层次，不能为了一个榜单将其全部称“同输入算法比较”。完整的既有身份与验收见[上一阶段横向比较入口](../TIM_EVIDENCE_20261005/README.md)。本轮把其中影响主论证的事实放进r4 Section4.1/4.5，未新跑算法。

- 同一骨架的组件删项最适合解释本方法哪个输入产生什么作用；F01→F03改变不止一个因素，不能称纯RV增益。
- LC01/两接收机IEKF更接近方法层面对照。现有结果不支持全部指标显著更优；BY2/H的配对yaw区间含零、不同参数版本可改变排序，应如实报告。
- RTKLIB动基线和载波指南针反映当前数据、适配与安装条件。BY2四种RTKLIB配置只有60–194/1370个fresh fixed输出，支持率和自身支持误差必须一起呈现。差成绩真实保留，但还不能推出“该类方法不适用于所有四足机器人”。
- 严格OiSAM为275/275、0/271、55/378；分段初始化方案的主要动态支持为275/267/370，属另一协议。Wen/GNC没有自产姿态成绩。不能沿用较早9组合表来掩盖严格连续处理的缺口。

判断正确性的标准应是输入、量、初始化、参考使用、失败分母和已知实现差异交代清楚。对手结果比我们差，可以支持本次对照的结论；仅凭差成绩不能反证实现完整，或证明方法普遍优越。

## 5. GPS Solutions与TIM分别还缺什么

**GPS先推进。**主文需要一个清楚的GNSS/INS应用问题、可实现的观测规则和与问题对应的验证。现有V3可以承担大部分性能与消融章节。新增工作的优先级应是缩小关键解释的不确定性，特别是0.35m实际基线、时轴与fixed方向正确性，而不是再增加几篇外部baseline。

**TIM继续保留，但必须围绕一条真实测量链收敛。**最可行的是短基线投影航向：定义输出量/物理点/时刻，识别双接收机误差相关项，区分correct-fixed连续误差与wrong-fixed离散失败，并用未参与预算拟合的独立已知方向验证。导航滤波中的工作R、RMSE和厂家1m基线规格不能直接当作本次安装的测量不确定度。

最简的小角传播关系可以解释为什么短基线需要这项工作：若b是N/E基线、ψ=atan2(bE,bN)，则g=[-bE,bN]/(bN²+bE²)，uψ²约为g U_b gᵀ。U_b必须包含左右接收机误差及其交叉项，不能默认独立。由位置误差到角度的放大尺度约随1/L变化。该关系是标准一阶传播，不是本项目新理论；TIM贡献需要真实参数、适用域和留出验证来支持。

目前TIM r3仍是工作稿。本轮没有把GPS稿换标题再另发一篇TIM；同一研究结果不能只换叙事重复投稿。TIM具体测量方案见[最小验证设计](validation/REVIEW_AND_MINIMUM_VALIDATION.md)。

| 优先级 | 实际工作 | 需要新采集/新求解吗 | 完成后能解决什么 |
|---|---|---|---|
| 1 | 用已有33配置/110段诊断，对7个gap和原22个暴露成员做预定义近缺口/远离缺口/共同支持敏感性表；将已有135诊断的中断内/精确终点/恢复结果整理为独立补充小节 | 只读已有结果，无新求解；本轮仅设计，尚未声称完成 | 解释原V3结论对支持与复合版本是否敏感，不能单独归因gap修复 |
| 2 | 找回BY2/H/O逐session的事件索引、时间变换与实际输出点；测量同一安装的天线/IMU/参考设备点位 | 部分可用旧配置；缺失物理量需实际量测 | 让图、杆臂和对时描述能被复核 |
| 3 | 已知方向/倾斜/接收环境下做短静态块，固定采集时长并独立重新获取；另记录多个分离时间marker | 少量新数据，建议24短block是覆盖设计下限，不是期刊规定 | 检验fixed是否伴随正确方向、可用率、误差尾；给TIM预算真实输入 |

| 5 | 输入/对时资格闭合后，8个新候选冻结参数转用，最多两配置×8段 | 建议而非当前全部重跑；未来≤16次 | 测试参数转用，不再在BY2上回调参数 |

新8段有4段有dual-fixed、4段没有。全部先按固定准入规则登记，无合法初始航向时的no-init也是结果；不能先挑表现好/有fixed的4段再声称独立泛化。BY2是开发集，BY2H/O按作者说明没有参与参数开发；它们仍应保留这一身份，不因想增加数据而倒推成训练集。

单次“蹬一脚”能提供粗事件对应，不能独立识别clock drift、传输/接收机延迟和不同物理响应。新记录至少3个分离marker只是最小设计，需保留拟合与留出；没有共触发或延迟证据时只能报告有效事件对应，不能随意写已校准到1ms。禁止按参考RMSE反向优化offset。

## 7. 仍未达到投稿终版的部分

科学上：7gap支持敏感性未完成；真实时间/点位/方向量测尚未闭合；跨环境冻结参数评价未执行；TIM数值预算及留出验证未完成。写作上：主图仍需制作并插入，现有补充证据需整理成可投稿的SI，相关工作要围绕最后贡献补足而不是泛泛加引用；作者、基金、数据可用性、声明与生平等待作者核定。模型辅助的实质性内容生成应按实际用途遵循期刊披露规则，不能一律称纯语言润色。

本轮19页Word是完整连贯的文字初稿，不等于已有全部投稿附件或完成终审。正文双倍行距、表内单倍是当前阅读版；正式投稿时按编辑部对全稿行距的解释再次核定。参考文献目前10条，后续围绕最近邻工作补足实质比较；不以凑数量替代文献定位。

官方依据于2026-10-05核对：[GPS Solutions作者指南](https://link.springer.com/journal/10291/submission-guidelines)要求Word、约5000–5500词、150–250词摘要、4–6关键词、双倍行距与作者—年份引用，并要求足够新内容。[TIM作者指南](https://ieee-ims.org/publication/ieee-tim/information-authors)强调I&M贡献、measurement performance/uncertainty及可复核的实验。这些版式符合性不能代替新颖性判断。指南中互联网公开稿条款与出版社一般preprint政策的适用关系沿用既有待核记录，本轮不变更GitHub可见性。
