# R4写作结构与术语

一句话论证：在0.35m短基线的四足机器人上，双天线航向与机身状态辅助能改善部分导航分量，并在航向保留的GNSS平移观测中断中显著限制位置误差；该速度辅助仍依赖航向与调度入口，不能接替完全失去的GNSS。

正文按问题—方法—试验—数值结果—解释组织。主要结果先看自然性能，再看失败数量、组件效应量、两类中断和外部导航路线。标题使用描述性全名；LegSA-GINS保留为项目标识，F04等只出现在补充映射。没有为写作重命名原算法或数据。

|正文术语|含义|不用的误称|
|---|---|---|
|baseline heading|按双接收机位置差获得的水平投影方向加安装旋转|新整数模糊度算法|
|robot horizontal velocity|SDK速度经声明姿态转换后的水平辅助观测|独立腿部里程计|
|Doppler-derived velocity|原始Doppler经过后端解算的速度产品|直接紧组合原始Doppler因子|
|covariance inflation|依据来源质量与创新放大R|已标定的不确定度或最优鲁棒滤波|
|reference error or agreement|与共用GNSS来源商业融合参考的差|独立绝对精度|
|whole-window RMSE|整个评价窗内的误差统计|中断终点漂移|

R3的逐段审计式免责声明合并到实验设计和Discussion；直接影响方法正确理解的条件保留在相应方法小节。运行hash、作者复现审查、原代码状态属于补充记录。R4不再写Fig1–Fig8已存在的空引用；图形制作仍由用户指定的专门对话接手，正文现在用5张真实数值表完成可读的证据连接。图形尚未完成意味着这仍是文字初稿，不是投稿终版。
