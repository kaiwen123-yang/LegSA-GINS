实际搜索次数可以大于最终非缺失窗口数：某些窗口在完成选择期求解后才遇到未来模型不可用。所有缺失/拒绝窗口计入分母，未补帧、删去或用商业 FIX 填充。

部分固定将本例实验可用观测从 1 次增加到 7 次，但全时段输出密度仍低，尚不能声称优于 V3 或已解决载波鲁棒性。7 次决策时刻为 135.998、141.998、155.998、169.998、171.998、295.998、301.998 秒。

当前准备器逐历元要求 GPS L1 code-SPP 成功；失败时连多星座 DD 模型也不建。同时星历固定为 100 秒以前已收到的前缀，后续收到的新星历尚未推进。57 个模型缺失窗口暴露的是这条准备流程的可用性限制，不代表这些时刻完全没有可用原始多星座载波。下一版本应因果维护粗位置线性化点与星历可用性，旧结果完整保留。

这批真实输入用于下一步 native 导航对比：原标量航向、双 PVT 三维基线、完整整数载波基线、部分整数载波基线；各自在共同 HV-off 与共同因果 body-HV 条件下评估。最终精度结果必须同时报告全时段航向、水平、垂向和实际更新数。
