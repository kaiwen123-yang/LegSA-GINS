# 载波方向信息：续作的三个可实施竞争方案

日期：2026-10-07。只读代码审查基点 `8cd93b2`。本文件是工程研究设计，不是论文材料或正式运行登记。本轮算法编辑、测试、整数搜索、原始/参考数据读取、导航和评价均为 0；仅在 Ubuntu-22.04 WSL 阅读源码、既有工程记录和两篇一手文献，并写本文件。主分支、原 V3、旧冻结运行和结果不变。

## 1. 决策：先提取尚未利用的相对载波信息，再检验有向信息能否缩小整数集合

建议首先资格验证 **B：物理连续弧内的相对载波姿态因子**。它提供现在“必须先得到单类方向点”路径没有直接利用的观测，不必等待绝对整数唯一，也不必关闭合法的 PVT 航向。**A：完整方向集合的有界输出**是其相同输入下的竞争策略和接口基线；**C：合格有向运动先验作用于整个连续候选域**检验能否进一步减少真实的整数/方向歧义。三者都是内部研究变体，不新增第三、第四项外部数值基线。外部方法仍只保留已审查的 PD-PAR 与 2013 gyro-integral 两项有条件适配。

这不是保证 B 会改善当前 V3。相位时差可能被时钟/同步/非整周偏差污染；相对姿态信息也可能在静止或弱激励时很弱。A 可能因为方向域仍宽而完全不更新；C 可能因先验无资格而退回原始集合。应先用能区分这些原因的局部反例与模型检查，再登记完整窗口对照，不能从旧有限负结果直接结束新目标，也不能预先把新路径写成已完成创新。

## 3. A：不要求整数唯一的完整方向集合输出

### 3.1 估计对象与最小接口

对冻结源中所有未永久失效的整数 origin，在当前共同观测视图定义

`D_N(t) = { b : J_t(N,b) <= tau_t, ||b||=L }`，
`Theta_t = union_N azimuth(D_N(t))`。

现有椭圆/球帽模块给的是每个 D_N 的**必要外包**，取所有分量 union 可直接产生保守 Theta 外包。类间重叠不需要整数合并；整数类只能按相同物理整数关系精确合并。不同源的集合不能因为角度重叠而互相继承完整性。

新增 `DirectionSetObservation` 应携带 source/origin、完整性、current model/row/Q 身份、全部 circular components、原始成本域、所有兼容类质量、逻辑时刻与实际可用时刻。它不携带“fixed N”或仅某一类的 Cb。保持目前物理弧/相位质量/五槽健康要求；把“五槽单整数类”改成“五槽共同非空 origin 路径 + 当前完整方向集合”的独立接口。每槽临时不兼容只影响该次 publication 历史，不永久删源；不同时间的绝对方向不能直接求静态交集来假装机器人没转动。

### 3.2 怎样使用它才不伪造高精度观测

第一种用途是测量域仲裁：在相同基线方位/外参模型下检验 PVT 方向域与 Theta 是否相容。相容不是独立确认，不相容也只说明条件模型冲突，不能据此证明哪一个正确。宽域/不完整/冲突可返回 UNKNOWN；不能用 EKF 已融合 GNSS 的姿态挑掉某个 N，再将剩余载波当独立绝对航向。

若要产生实质导航修正，可以先实现一个**有界方向修正**研究内核，而非伪 Gaussian 点。以当前预测基线方位为原点，若全部 Theta 可放在同一个合法局部圆周 chart 中，误差区间为 [a,b]，且 `0<a<=b<pi`，选择预定 `delta=kappa*a, 0<kappa<=1`，则对其中任意真实误差 e：

`(e-delta)^2-e^2 = delta^2-2*delta*e <= 0`。

负区间对称处理；区间含 0、跨不可定向分支或全圆时不作这一修正。该性质只是**真方向属于所用外包、正确 chart、局部方向修正**条件下的确定性几何性质，不是三维导航误差/协方差改善保证。当前域可能宽于实际航向误差，因此返回 zero-action 是合理结果。方向修正可绕导航系重力轴作用于姿态，但不能把此式变成零测量噪声的 EKF 更新；需另存集合/有界偏差，传播 reset 与状态互相关。若暂不实现这种状态语义，A 只能是集合/仲裁输出，不能冒充现有 15 列高精度 pointprovider。

另一种正规选择是保持每个方向模式的 filter branches/混合似然，但本轮不建议直接扩成大多假设滤波器。`exp(-每类最小成本/2)` 不是已归一化模式概率；还缺连续域积分/体积、先验及阈值外尾部。任意取均值或只取最近模式都会丢掉尚未排除的方向歧义。

**最小反例：** 两整数对应相同窄方向域时允许方向输出但不宣称固定；±179°必须在圆周上相邻；±90°双峰不能平均为 0°；近竖直返回全圆/未资格；预测落在宽域内部必须允许不修正。原 source 没覆盖真实 origin 时上述性质不适用。

## 4. B：弧内未固定整数消元的相对载波姿态因子（优先）

### 4.1 增量来自哪里

从两个合法时刻的同一物理 SD 弧集合，构造同频同星座、相同整数关系坐标的相位观测

`p_i = Lambda n + H_i R_i r + e_i`，`i=0,1`。

使用当前原始 DD 的线性映射 F_i 得到这些关系。要求 `F_0 A_0 = F_1 A_1 = Lambda`，由此

`z = F_1 y_phase,1 - F_0 y_phase,0`
`h(R_0,R_1) = H_1 R_1 r - H_0 R_0 r`，
`Q_z = D Q_stack D^T`，`D=[-F_0, F_1]`。

整数在观测层代数消去，无需估计或接受 n。H_i 必须取各自实际卫星几何和因果 anchor，不能把“短时间 H 变化小”写成恒等；同一个信号的波长不变，跨频/星座不盲差。此式带来的是导航系中基线变化信息，**不是新的整数固定算法**。静止同 H 时对共同姿态旋转存在 gauge，绕基线轴的运动也可能无信息；不能宣称单因子获得完整三维绝对姿态。

使用已有 ECEF clone 与当前姿态，令 b_i=R_i r、左扰动 `R_i'=Exp(delta_theta_i)R_i`，预测函数的两块导数为

`dh/d(delta_theta_0)=+H_0[b_0]x`，
`dh/d(delta_theta_1)=-H_1[b_1]x`。

残差采用 z-h 时导数再取相应负号；native 当前 NED 扰动需显式坐标变换。安装方向、长度、时间、anchor/卫星几何误差要列在工作模型中，不能因整数消去就消除这些误差。

### 4.2 最小实施，不新建整数求解器

- 新的 `ArcPhaseDifferenceFactor` 只包含两时刻 physical-node/关系映射、z、完整 Qz、H0/H1、r、时序/噪声来源。构图不依赖已固定的整数数值；不能伪造一个全零 FrozenCandidate 复用旧图接口。
- 第一轮按固定、互不重叠的五原始 epoch 块取首末端点；所有块都记录，端点/相位凭据只消费一次。不先做每 0.2s 滑动差分；邻接差分共享相位时，交叉协方差非零，不能当独立因子连加。
- 部分失弧只保留两个时刻都连续的物理关系；pivot 换坐标可精确变换，全断之后旧因子结束，新 arc 从新端点积累，任何同 SV 新 token 不继承旧整数或旧相位端点。
- 先复用已有双姿态 clone 的传播/reset/退役接口，新增上述观测函数；不修改导航传播内核，不关闭 PVT 来制造“载波机会”。不读取导航后验去修 N 或补半周。
- 未检出的单目标/pivot 周跳、非整周偏差、时钟重置必须有物理模板及质量拒绝路径。旧 GLRT 的“给定 N、自由单历元 b”分布不能直接贴到这个跨时姿态因子上。共同准入应固定物理质量、完整 Q 与故障假设，再按本因子的秩/状态定义核定统计含义。

### 4.3 相关性与 PD-PAR 的关系

令线性化更新误差为 `e+ = (I-KH)e - K nu`。若已知 `C=Cov(e,nu)`，必须保留对应交叉项；若只有有效的边缘二阶矩上界 P、R，可沿现有 Young 架构使用任意 epsilon>0 的保守界

`P+ <= (1+epsilon)(I-KH)P(I-KH)^T + (1+1/epsilon)K R K^T`。

这是任意互相关下的矩阵不等式，前提是 P、R 确实界住相应局部误差二阶矩。它不是把 R 随便加大，也不证明当前 RAWX 噪声/偏差已被标定；非线性/异常偏差超界另列。PVT 和载波同源、历史端点可能已经影响状态，因此不能默认 C=0。若工作界过保守而 exact-skip，保留此结果。

更一般的 PD-PAR 适配在全观测中把未选 N_u 保持为跨时共享实值 nuisance。完整白化矩阵 W=Q^-1 下消元为

`W_perp = W - W A_u (A_u^T W A_u)^+ A_u^T W`。

它是白化空间的 nuisance 投影，不能将这个半正定精度矩阵直接当正定 Q 传给旧接口。跨时共享 A_u 通常耦合各基线；旧按 epoch 分离球面搜索不能自动继承精确证书。B 的两时刻差分是“保留不依赖 N 的对比关系”的小型可执行入口，不声称已经实现 PD-PAR。

特例也要承认：单历元中未选 nuisance 自由度恰好覆盖所有被删相位坐标、没有跨时共享/其它约束时，profile 消元可能等价于保留观测的 marginal likelihood；不能一概声称实值 nuisance 总比删行增加信息。应以实际共享弧/跨时设计矩阵证明本项目的信息增量。

## 5. C：有向运动约束筛整个域，并保留原始集合退路

令 r 为已知 body 安装向量，D 将第二 body frame 转到第一 body frame，g 为有符号的导航系重力方向，q=R0^T g。则

`b0=R0 r, b1=R0 D r`；
`g^T b0=q^T r, g^T b1=q^T D r`；
`g^T(b0 cross b1)=q^T(r cross D r)`。

末项保留方向/手性。R6 的同 H、双等长整数反射别名可保持 Gram 与高度，却在合适几何下改变此三重积符号。因此这是比只约束 acos 夹角**信息更多**的问题；但基本有向转角/旋转平面思想在 2013 工作中已有，不能把三重积写法本身算新颖。

最小扩展是将 `directed_motion.py` 的点检查升级为 **source-origin 对应的整个连续域必要检查**。例如 b_i 位于中心 c_i、半径 r_i 的外球，则三重积偏差满足

`|g^T(b0 cross b1)-g^T(c0 cross c1)| <= r0||c1|| + r1||c0|| + r0*r1`。

线性高度的椭球极值可直接用 `g^T c_i +/- sqrt(rho_i*g^T C_i*g)`。只有整个候选外区间与含误差先验区间严格不交才可判该先验下矛盾；区间重叠仅保留，不算存在性证书。逐类保持同一 origin 的跨时对应，不能把两个时刻不同整数类的中心拼成一个好点对。保守外包过宽时先报告无增益，不改 tau/Q。

前端始终同时保留 `raw_support` 与 `prior_compatible_support`。先验无资格、重力/符号未知、弱激励、时序不合法或误差界失效时退回 raw_support。退回恢复的是此前未永久失效的原假设，不是复活已失去物理连续性的旧 arc。

**重要不可承诺项：** 错先验可能删真类却保留另一个错类，集合非空并不能发现它。若允许先验任意失效又没有独立的故障约束，可靠输出必须把 prior-fault 分支也纳入，此时并集可能退回完整 raw_support。不存在“既允许任意坏先验、又保证有效硬删竞争者”的免费方法。不能重用此前 bounded-prior selector 的好例子掩盖这个反例。

陀螺、重力估计或足对相对转动都要有实际来源/误差界。由已融合 GNSS 的姿态产生 D/q 再用于载波选择，会回灌信息；来自同 IMU 的量也不能作为与 EKF 独立的额外测量。两脚只给部分旋转可观子空间时，应传 rank/nullspace 集合，不能补齐不可观轴后声称独立完整 SO(3)。全断弧后可以使用新 arc 的新原始集合重新获取；旧 N 数值绝不越过中断。若以后跨断弧连接旧方向域与新方向域，须显式共同来源/条件似然账本，不能把已用旧方向再次当免费先验测量。

## 7. 最小验证与公平比较，先不执行

建议下一次局部登记只包含下列六个有判别力场景，不重复自然数据搜索。所有真值仅由独立物理生成器持有，checker 不读真值选择 N/窗口。

| 场景 | 可被证伪的内容 | 预期必须保留的失败行为 |
|---|---|---|
| 两整数同窄方向域、两个相反方向峰、±pi wrap | A 是否真正按全部方向而非整数数目工作 | 相反峰不得 mean；宽域含预测不得强制修正 |
| 已知安装向量在运动中，整数改变但同弧不变；变化 H 与完整 shared-pivot Q | B 的符号/单位/秩及时间差整数消去 | 真 N 任意换常量不改变 z；绕基线/静止 gauge 不制造绝对精度 |
| 时间差相邻端点复用 | Qz 和跨因子相关；measurement ledger | 不能将相关差分独立连用；仅固定非重叠版本可先进入实现 |
| pivot 退休、部分幸存、全断后相同 SV 新 token、隐藏目标/pivot 周跳 | B/C 的弧资格与故障映射 | 新 token 无继承，全断无旧测量输出；未检出异常不宣称已安全 |
| R6 精确反射别名加有向重力信息，及错误先验/弱转动 | C 是否有独立于 Gram 的筛选信息 | 正确宽界含真域；错界可删真类必须暴露，退回原集合，不用空集检测冒充万能健康判据 |
| 所有模式共享 IMU/PVT 误差，并让更新前后端点都影响状态 | joint/Young 的条件与输出身份 | 不把 C=0 当默认；比较代价、二阶矩界与 skip，不只比较某次误差变小 |

真实对照应分成两个问题，不能混成一张“固定率”表：

1. **绝对方向/AR 层：** 原 singleton provider、A、C 使用相同 source 生成、原始 cost/tau/Q、全部兼容类、物理弧和每类 Holm 质量规则；完整性/预算/延迟门不变。若进行 PD-PAR 适配，必须另列未选整数域和完整似然变更，不继承旧 selected-support 证书。统计输出覆盖、方向分量/宽度、临时拒绝、永久退休、恢复与预算；没有整数标签便不报正确固定率。
2. **导航增量层：** 相同 V3 完整窗、相同绝对方向仲裁和所有非载波输入，仅在一臂开启 B；控制臂保持同样 clone/传播/reset 但不加因子，隔离状态架构变化。B 不是新的 AR 横向对手。全部失败/缺失/耗时入分母，先完成并封存导航再由原 evaluator 读取既有参考。不用参考挑激励窗/噪声/阈值。

既有 HV 含 GNSS 航向处理的输入路径若本轮不改，应在两臂完全一致并明确保留，不能称整体本体/GNSS 已完全解耦；如果改为 body-frame source，则为单独因素，不与载波改变捆绑归因。比较 PVT 与 carrier 时必须使用相同投影/外参测量函数，不用 Euler yaw 的定义差异制造改进。

“相同准入”指相同信息资格与风险口径，不是把旧 fixed-N 自由 b 卡方自由度硬套到新非线性相对因子。新因子统计模型尚未闭合时，只做模型资格/半合成，不能仅因为创新式子不同就取消异常门。

## 8. 建议的实施顺序与可交付成功定义

先做 B 的独立 observation map/完整 Qz/clone Jacobian 小内核和六场景内的相关检查；同时让 A 输出纯集合 sidecar，保留原 pointprovider 不变。暂不做新整数枚举，不新增 native 全矩阵。物理支持、噪声工作界与身份闭合后，再登记同三完整窗的 B-on/B-off 导航对照。C 在能给出有来源的有向先验界时接入整域必要检查；不能用现有两个最优点充当整个候选域。

可称“可信”的当前可验证内容是：没有遗漏已声明域内候选；沒有把多峰伪装为单峰；观测只在实际可用时使用；坏测量拒绝与物理失弧分开；跨断弧不复活旧 N；所有结论明确依赖来源、误差域和工作 Q。它不等于已校准真实固定风险，也不等于实际导航已稳定超过 V3。后者必须在完整窗及既定尾部/非退化门上取得新证据。

若 B 有效，只能先结论为“未固定载波的相对信息带来导航增量”；若 C 在正确先验下排除原本完整保留的错误方向类，同时错误先验/失弧能按声明退出，才有进一步研究新的 AR/方向可信性机制的依据。A/B/C 不应为了凑三项贡献分别重命名旧组件。
