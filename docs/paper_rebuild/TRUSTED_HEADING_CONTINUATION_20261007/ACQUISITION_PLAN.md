# 独立方向参考与三场景采集草案

日期：2026-10-07。状态：DRAFT_REQUIRES_EQUIPMENT_INVENTORY。此文件只定义下一阶段怎样获得目前缺失的证据；没有假定用户已拥有设备，没有安排或实施实机动作、购买、采集、导航或评价。实际设备、场地、时间同步和可行运动范围确认后，再登记具体次数、时长、运动脚本、参考资格和停止条件。原BY2/H/O及V3不改变。

## 1. 要补的证据，分成两个问题

问题一：转动、支撑切换、载波中断时，系统对当前绝对方向、相对传播、不可用和重新获取的标识是否与独立参考相容。问题二：在原有良好PVT仍可使用的情况下，新机制是否改善完整导航且不伤害H/V和尾部。二者均不能由候选更多、连续曲线、单次RMSE下降或代码PASS代替。

全部绝对方向来源中断时，IMU和点接触通常只支持相对传播。实验应测出误差/不确定性随中断增长和何时应宣布不可用，不把无限期绝对航向有界当作无条件验收要求。参考失效是评价不可用；它不等于被测系统失效，也不应被填补为零误差。

## 2. 需要用户提供的最少设备信息

1. 现有Go2型号、固件与采集程序；能否同时记录原始关节角/速度、力或接触信号、原始IMU，以及现有SportModeState；实际topic/频率/时标是什么。
2. 两台接收机/天线的型号与RAWX/SFRBX/HP位置输出条件；是否有原始时间脉冲、外部事件或可记录的硬件触发输入。
3. 可用方向参考：光学动捕/外部相机、可测量刚体靶标、独立惯性参考、全站仪及其数量。请说明可用设备而非默认新购。
4. 可用室内/室外场地、可视范围、卫星环境、可重复遮挡方法；能否跨日重复相同路线。
5. 已有CAD/实测的天线相位中心基线、IMU敏感中心、SDK body原点、参考刚体外参，以及各自测量不确定度。

缺设备时仍可继续本地模型/合成资格；不能把这些缺项用URDF默认值、估计轨迹最佳对齐或SDK字段名称补成已知。

## 3. 独立方向参考的条件选项

|选项|能支持什么|采用前必须确认|
|---|---|---|
|外部光学刚体姿态，至少三个非共线标志点|覆盖范围内的独立三维姿态和位置；适合转动/支撑切换与遮挡实验|参考刚体与机体/IMU刚性外参；标志可见性；参考世界轴到NED的独立测量；姿态、时间和位置误差资格|
|已标定的外部多相机与刚体靶标|有合格几何和视野时的独立运动/方向参考；可设计室外局部验证|相机内外参、尺度、世界方位、动态曝光/同步和遮挡质量；不能用与被测解共用的GNSS/姿态来挑解或逐帧校正|
|独立惯性方向参考（例如独立高等级陀螺系统）|在其已验证漂移界覆盖的有限时间内提供方向参考|独立初始方位和独立IMU；实际误差界；与被测GNSS的辅助关系。若参考仍依赖同一GNSS环境/修正，不自动称独立真值|
|测量仪器观测刚体多个目标|具备足够同时几何观测时可给方向，也可补位置参考|单个移动棱镜只有位置，不能单独提供机体yaw；顺序测两点必须处理运动与时差，不能当同步双目标|

优先使用已经具备且能验证误差的参考。没有设备信息前不指定品牌、精度、采购预算或保证哪一选项可行。仅有姿态参考时可以验证航向；H/V绝对改善仍需相应位置参考，否则保持对商业参考的一致性和独立方向结果分表。

参考世界坐标若没有独立方位标定，只能支持相对转角，不得把运行后最小RMSE的yaw偏移称绝对方向。世界变换和机体外参应在校准阶段冻结，留出评价不再拟合。侧向基线投影与Euler yaw分别从参考姿态按同一实测安装向量计算，避免混淆被测物理量。

## 4. 先校准，再冻结

- 固定天线方向RX1→RX2、机体/IMU/参考坐标、杆臂和安装旋转，保留测量记录及误差预算；SDK body与IMU中心不能默认重合。
- 记录设备采样时间、主机收到时间和时钟映射。优先使用已有硬件同步能力；若只可软件同步，独立测量延迟与抖动，不从航向误差反推最优时偏。
- 对方向时序误差给出实际预算：例如在角速度上界为omega_max时，时差上界delta_t至少带来omega_max*delta_t量级的方向不确定性；是否足以判断研究收益须事前确认。该式是预算关系，不是预设设备性能。
- 原始关节/FK若可获得，核对单位、关节顺序、几何版本、时间和SDK足端字段差别。接触力只作有来源的接触证据；共同滑移仍需外部参考或另一个可识别来源，不能以足力大直接标作无滑移真值。
- 参考质量、资格门、坐标变换、开发数据和留出数据边界在正式评价前固定。参考不进入前端候选、仲裁、噪声选择或在线导航。

## 5. 三类完整场景与最小采集结构

建议设备资格后登记一次小型开发采集，以下三类各至少三次完整重复；方法冻结后另一天重复同三类作为留出。次数和时长在设备能力、正常操作范围及可完整观测时长明确后锁定，本草案不是执行登记。

|场景|脚本应控制或记录的变量|主要判别|
|转动|水平转向与含roll/pitch的多轴转动分开；有短静止/弱激励段、左右转向和有限稳定段；姿态幅度/角速率取实机允许范围|Euler与基线投影模型差异；有向信息能否排除反射；弱转动/绕基线轴时应不制造可观性|
|支撑变化|同路线的正常接触切换、起停、转弯和不同可重复支撑条件；记录每足源与接触状态；如有可行的小范围滑移条件单列|足对关系何时有效、切换是否撤销旧token、可观子空间与相对传播是否改善；不可把SDK高层代理当独立FK|
|载波中断与恢复|局部失星/部分弧中断与全部支持中断分开；固定事件开始/结束标记；保留足够的故障后观察区间；运动与静止分别有控制|旧整数是否退休、存活关系是否合法、新弧是否重新验证；空窗、误接纳和恢复时间；相对传播期间误差增长|

可重复遮挡优先考虑场地中的自然遮挡或被动遮挡装置；不使用发射式干扰。实际物理遮挡会同时影响接收机PVT和RAWX，按真实源日志报告；不得称只改变载波。离线相位删除/周跳注入另建半合成表，原始数据只读，同故障输入用于公平对照。

参考有条件时再增加一个联合场景：转弯与支撑切换过程中进入/退出遮挡。它用于检验交互，不替代前三类的单因素解释。事件时刻依据脚本/独立时间标记确定，不看到估计误差后选择最有利段。

## 6. 每次完整保存的输入与输出

- RAWX/SFRBX、两端PVT/HP位置及状态、锁定/半周/时钟标志、天线/信号身份；原始记录永不覆盖。
- IMU、关节原始流（若可用）、SDK足端/速度/力，采样与收到时标，接触和物理弧token来源。
- 独立参考原始观测与质量标志、冻结标定、事件时间、外参和时钟误差预算；不是只保存处理后的漂亮轨迹。
- 每历元raw方向域、先验相容域、完整性范围、owner/来源、拒绝/退休/重获原因、当前绝对测量/相对传播/不可用状态。
- 真实端到端时延：输入到达、前端准备、搜索/因子、验证、发布、native消费的时间；超时/队列/忙丢弃全部入分母。

无真实整数标签仍不报真实正确固定率。独立方向参考可以检验被接纳方向是否明显错误，但不能唯一倒推出整数N正确。

## 7. 评价与进入完整版本的判断

保持原V3、匹配内部控制和作用臂各自身份。所有完整重复进入结果；技术失败、参考空窗、算法不可用、超时、右删失逐项保留。先封存算法输出，再由评价读取独立参考。

必报四类结果：
1. 方向和导航：wrap-safe yaw RMSE/P95/P99/max，H/Up对应指标及大误差事件；参考不足的指标NA。原完整窗与实际共同时间键分别报告，不插值补成有利共同支持。
2. 可用性：导航输出、当前合格绝对方向、仅相对传播、不可用分别给全部机会计数及有定义的时间占比、最长空窗。参考可用性另报。
3. 可信性：所声明方向域与独立参考误差域的相容性、明确违例、不可判定；错误高置信输出、弱激励退出和先验撤销。若两域仅相交不能声称完整真实覆盖；缺乏噪声/故障资格仍不报告完整性概率。
4. 恢复与代价：同源/同故障/同准入下的受限恢复耗时、未恢复及右删失、错误接纳证据、真实时延/超时。沿现合同连续1秒确认和20秒恢复观察，不把右删失者真实恢复时间记为20秒。

原三窗采用门A/B继续有效；不能用新参考事后改门。留出数据若需不同应用阈值，必须在见留出误差前登记且与原门分列。新方法只有在合格参考、完整分母、匹配对照及留出上同时支持其声称时，才能从条件研究结果升级；采购、现场可达性、真实采集和用户设备信息仍是外部待补，不在本文件中声称完成。
