# 足端未知相关性：固定线性更新的条件 minimax 反例

此命题针对当前声明的工作不确定集合，不认证真实 SDK 的相关性或误差上界。

在固定条件信息集 I 下，把已知状态/观测均值减去，令中心化误差 e、测量误差 n 与线性创新 r=He+n 满足边缘二阶矩 P、R。W 为事先固定 PSD 计分矩阵。假设不确定集合允许所有满足完整 joint PSD 的 C=E[en^T|I]，没有额外已知的来源结构限制。

若 V=R-HPH^T 为 PSD，可构造与 e 不相关的中心化 v，二阶矩为 V，令 n=-He+v。于是 C*=-PH^T，r=v，而且

    [[P,C*],[C*^T,R]] = [[I,0],[-H,I]] diag(P,V) [[I,-H^T],[0,I]] >= 0.

对于在本次创新之前固定的任意线性增益 K，后验中心化误差为 e-Kr，二阶矩为 P+KVK^T。因此该允许反例下的计分至少为 T=tr(WP)。另一方面 K=0 对集合中所有 C 的计分均为 T，故

    inf_K sup_C tr(W P_post(K,C)) = T.

不更新是一个 minimax 解，不一定唯一。该结论比“某五档 epsilon 或整个 Young 同族均无益”更强；它解释了在这个宽未知相关性集合中，为何仅更换更新公式也不能保证工作 trace 下降。

它不能证明实际 n=-He+v，不能否定真实足端信息，不能排除有依据的更紧 cross 结构，也不能把条件不满足写成必有收益。它不覆盖依据本次 residual 自适应选 K 的非线性/选择后模型，亦不把工作加权 trace 当作实际 yaw 误差。完整 P24 与嵌入 W21 是全状态结论的对象，不能只抽姿态边缘冒充全状态证明。

数值验证计划：先做有限合成资格，再对原封存的全部2510组P/H/R逐条直接检查 V。P按原工作PSD前提和新的对角归一化浮点资格检查，V不loading、不clip、不改噪声。明确正裕量支持反例；明显负方向仅记条件不满足；数值边界未定保留NA。该判定不是区间算术的精确PSD证明，物理二阶矩资格也没有因此建立。
