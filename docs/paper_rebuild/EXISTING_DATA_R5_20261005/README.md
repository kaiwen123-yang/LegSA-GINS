## 这次用到了什么

原V3的6,468次矩阵和三个主实测序列作为主要结果，数值不改。进一步从135次已有失锁实验中整理故障期间、末端与恢复过程，从H/O的22个既有成员整理七处IMU中断附近及共同时间点的结果。详见[既有结果分析](existing_results/README.md)。

新提供的八段记录已经实际处理。NMB1～NMB4提供合法双固定航向，完成两种配置的八次最终运行；XB1～XB4没有合法双固定航向，按当前初始化规则保留为八个无输出组合。

输入传感器的速度和角速度变化表明机身时间存在约1.1秒有效差，本轮据此统一对齐并重新关联航向；该处理不使用参考轨迹拟合。详见[时间关系](existing_results/timing_nmb/README.md)。

NMB数据中，相邻有效GNSS位置观测最长相隔163.0～172.6秒。时间对齐后的完整融合水平RMSE分别为1647.668、897.338、10265.359和955.324 m。原始导航输出显示中断期间明显漂移，GNSS恢复后重新靠近接收机轨迹。这批数据已写入正文4.6节和表6，用于呈现长缺测与初始化的实际边界。
