# IMU 时间链独立交叉检查

直接 IMU 通道也出现约 1.1 s 的有效时间差，因而四段速度模长的约 1 s 峰不能仅归因于 SDK 速度内部滤波。NMB1/2 的双 fixed 航向变化率与 IMU8 的 gyro-z 均得到清晰且相同的相关峰；把中心平滑窗口从 2 s 改为 1 s，峰值只变化 0.02 s。

正 lag 定义为 `corr(GNSS 航向变化率(t), IMU gyro-z(t+lag))`。这说明相同转向在 body IMU 记录时间轴上较晚出现，与速度模长诊断方向相同。尚未区分时间戳固定偏移、GNSS 解算链和其他测量延迟；这里也未估计时钟漂移。

IMU8 保存角增量、比力增量和逐行积分时长。诊断逐行用增量除以实际时长，gyro-z 单位 rad/s、比力单位 m/s²，不把增量误作原始采样值。两段原时戳最大间隙分别 0.020029/0.019992 s。IMU 在 0.02 s 等距内部网格上插值、中心均值平滑；航向解包后在同样中心窗口作局部线性斜率，拒绝跨相邻 GNSS 航向间隙大于 0.40001 s 的窗口，覆盖跨度至少为窗口的 80%（仅加 1 μs 浮点容差）。不换轴、不挑相关符号，不跨边界外插。gyro-z 是近水平情况下的航向角速度近似，两路不精确等价所引起的峰宽保留。

加速度通道没有给出一致时间信息：首 5 s 比力模长中位数为 9.720561/9.738054 m/s²；以其作静止重力代理后，绝对比力模长偏差与 GNSS 速度模长变化率的 2 s 主窗口峰值相关仅 0.098596/0.167265，峰位置 −4.60/−4.88 s，1 s 敏感性也不一致。该模长主要响应步态及垂直比力，不能等同水平切向加速度，因此不据此否定或估计对齐量。
