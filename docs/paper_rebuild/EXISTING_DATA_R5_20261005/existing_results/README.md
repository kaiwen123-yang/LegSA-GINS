# Existing-data results for the r5 manuscript

Two completed analyses use the existing recordings and saved outputs:

1. [Domain-resolved 135-run results](DIAGNOSTIC135_PAPER_RESULTS.md): horizontal aiding during complete-loss and heading-retained translation loss, with all nine placements, exact terminal errors and all three recovery bins.
2. [Seven-gap / 22-member sensitivity](GAP22_PAPER_RESULTS.md): original and segmented diagnostic results on own and exact common support, with fixed near-gap domains and the remaining recording.

The linked pages contain three manuscript-ready English result paragraphs in total. Small tables can enter the main manuscript; the full domain and member tables can enter the supplement. The original V3 whole-window matrix remains the main results source. Domain-resolved diagnostic results provide a separate temporal analysis of the same registered fault cases; the seven-gap table quantifies output-support and compound-version sensitivity.

The complete populations are retained: 2520 pair-domain quantities summarized into 280 groups; 22 method–sequence members, 7 interruptions, 77 restart records and 1804 domain/quantity rows. Exact output keys and all original measured denominators are preserved. No new estimator, evaluator or provider was invoked. Only saved error, support, metadata and publication tables were opened; the analysis did not open raw or commercial-reference streams.

`READY_V08.json` and `READY_V07.json` bind the two result blocks. `READ_SCOPE.csv` distinguishes manually read documents from full machine numeric processing. `GAP22_SAVED_EVALUATION_BINDINGS.json` additionally checks every original/diagnostic member uses the same saved reference identity and frozen evaluator, with zero recorded time-offset adjustment.
