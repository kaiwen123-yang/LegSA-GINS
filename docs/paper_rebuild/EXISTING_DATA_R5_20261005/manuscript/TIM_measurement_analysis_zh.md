# 紧凑双天线组合导航的测量关系与不确定度分析

本节作为TIM方向的测量分析补充，与GPS Solutions初稿使用同一组观测、实验和结果。分析从短基线航向的几何灵敏度出发，建立机身速度、时间匹配和共同参考之间的关系，并用已有记录量化可观测的影响。

## 1 短基线航向的误差传播

两天线的位置差决定基线方向。令导航系基线为 b = p₂ − p₁，水平投影长度为 r = √(bN² + bE²)，机身航向为 ψ = atan2(bE, bN) + π/2。方向对基线误差的一阶灵敏度为

jψ = [−bE/r², bN/r², 0]。

相应的航向方差为 u²(ψ) ≈ jψ Ub jψᵀ，其中

Ub = U₂₂ + U₁₁ − U₂₁ − U₁₂。

U₁₁和U₂₂是两端位置的协方差，U₁₂与U₂₁表示两接收机误差的相关性。两端可能共享卫星、改正和传播环境，因此相关项参与位置差的误差传播。对于0.35 m的水平基线，10 mm横向差对应约1.637°方向变化。该数值给出安装尺度下的几何灵敏度，说明毫米至厘米量级的相对位置变化如何形成角度波动。

倾斜时，基线水平投影方向还受到天线相对于机身的轴向关系影响。已有记录按名义侧向基线计算，投影方向与欧拉航向的差值RMS为0.031°～0.044°；用投影方向重新表达外部对照后，航向RMSE的变化不超过约0.0043°。在这些记录内，被测角定义的这一差异小于动基线和载波罗盘表现出的误差量级。

## 2 机身速度的姿态与时间耦合

机身速度通过姿态旋转转换为导航系水平分量，其观测模型为 zH = k S Ĉ M vSDK。速度输入、姿态、尺度和时间共同影响最终观测。对联合输入向量 ξ 作一阶展开，可写为

UH ≈ Jξ Uξ Jξᵀ。

其中，速度的灵敏度为 k S Ĉ M；小姿态扰动的灵敏度为 −k S Ĉ[MvSDK]×；尺度的灵敏度为 S Ĉ M vSDK；时间的局部灵敏度为 żH。联合协方差保留这些输入之间的相关项。速度越大，相同方向误差在水平速度中形成的误差通常越明显；加速和转向时，时间匹配误差的影响也随信号变化率增加。

原有135次失锁实验显示了这种依赖关系的实际后果。航向保留的20 s平移失锁中，机身速度将九位置故障内水平RMSE均值从30.474 m降至0.860 m，恢复后最初5 s从11.024 m降至0.260 m。该条件下，速度和倾角两个通道各接受100次更新。全部GNSS同时失效时，这两个通道的故障内更新数为零。由此，速度辅助的有效性与方向来源和实际更新过程相联系。

## 3 时间关系与输出可用性

记录中的机身消息时间由秒和纳秒字段重建，GNSS采用接收机时间。采集时，以踢动产生的机身IMU响应和接收机位置、速度的起动变化确定共同起点。一个局部时间差δτ分别引起近似的位置变化vδτ、速度变化aδτ和航向变化ψ̇δτ。因此，同一时间偏差在静止、匀速与转向过程中具有不同影响。

IMU缺口还影响可形成估计的时间范围。对原有H/O记录采用实际IMU间隔及分段处理后，每种配置的有效输出分别为58,556/58,580和72,810/76,548，对应99.9590%和95.1168%。最长一次满足输入条件的重初始化等待为20.143 s。在共同时间点上，完整融合的水平RMSE分别从0.068369 m变为0.068056 m、从0.055648 m变为0.054444 m。这组结果将误差与可用性联系起来：仅报告已有输出的RMSE，会遗漏等待期间的服务中断。该比较反映整套分段处理的作用。

## 4 共同参考下的结果解释

算法与商用融合参考在同一时间、同一坐标系和同一物理点比较。设差值d = zm − zr，则

Ud = Um + Ur − Umr − Urm。

算法和参考共享GNSS来源时，交叉协方差影响差值的方差。本文据此将实测RMSE作为相对于该参考的误差统计，将滤波器工作协方差作为观测权重参数，并通过同一参考下的成对消融比较辅助信息的效果。几何灵敏度、条件误差、恢复过程和输出可用性共同组成现有数据能够直接呈现的测量证据。

以上方程构成TIM稿的方法分析，文中数值来自已有记录的统计或明确给出的几何计算；联合输入协方差的数值估计不由工作权重或RMSE代替。当前初稿可据此展开测量链及误差传播，并与GPS Solutions稿的导航实验配套使用。
