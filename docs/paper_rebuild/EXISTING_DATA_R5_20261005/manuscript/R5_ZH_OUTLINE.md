# 中文初稿结构

论文题目：融合短基线航向与机身运动信息的四足机器人GNSS/INS组合导航。

正文按研究问题、导航方法、实验设计、实测结果、讨论和结论六节展开。第2节给出状态、观测、航向控制、机身辅助和协方差膨胀；第3节说明三个主序列与八个附加记录、参数和时间处理；第4节对应六张表，依次呈现自然序列、完成率、消融、失锁、外部对照和附加实测。

原V3主结果保持原数值。新增135次既有实验的时域统计、22个既有H/O成员的共同支持比较。附加NMB/XB实验采用由输入传感器确定的时间对齐；四个NMB的长缺测漂移与四个XB的无初始化结果写入第4.6节和表6。TIM的测量与不确定度分析另附。

作者以中文Word为修改主稿；同目录英文稿对应相同主要方法与六张数值表。绘图沿用单独的图件工作，当前稿件包含正文、可编辑公式、表格和参考文献。
