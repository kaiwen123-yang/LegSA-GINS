# 八段现有记录的固定参数迁移

本轮使用 2026 年 1 月 5 日的 nmb1–4 与 xb1–4。nmb 四段存在 771、750、904、697 个双接收机 fixed 且定位有效的同 iTOW 航向历元；xb 四段均为 0。八段均登记 F03/F04，nmb 执行估计，xb 记录无合法航向初始化。

F03 是位置、接收机速度与状态门控双天线航向骨架；F04 另含原定 RD、来源权重、机器人横滚俯仰和水平速度。两者采用相同新序列初始化，保留原数值参数。运行使用已修正的 measured-dt IMU8 实现，属于新序列迁移，不替换原 V3 的任何结果。

记录时间按 GNSS UTC/GPS 与机器人 Unix 时间转换，固定 offset=0，不用参考误差选择偏移或窗口。安装角、天线杆臂、加速度比例和速度比例使用原冻结值；所有新段共用这一约定。航向只来自双 fixed 的高精度天线坐标，GNSS2−GNSS1 横向基线加 90°。第一千个有效机器人样本后，取首个有合法航向与 GNSS1 位置的时刻初始化；初始横滚/俯仰与速度保持原规则 0。

完整估计窗口是输入的时间交集，初始化之前的等待保留可用性分母。若真实 IMU 缺口使输入不连续，不填补缺失运动；本轮 xb 本来就无合法初始化。原始末尾不完整帧不构造 IMU。所有 native 完成或无初始化状态封存后，再读取各段商业融合参考进行离线比较。
