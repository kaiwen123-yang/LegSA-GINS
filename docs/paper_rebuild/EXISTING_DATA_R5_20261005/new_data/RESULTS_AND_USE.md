# 现有八段数据的实际使用结果

4段NMB具备合法双fixed航向，均真实执行F03和F04；4段XB没有一次合法双fixed航向，按同一初始化规则自然未初始化。最终16个方法—序列组合全部有记录，其中8个原生运行正常退出、8个NO_INIT。NMB均出现明显轨迹失效，不能称为验证了迁移精度；XB错误指标留空，不能当作零误差。

## 固定实现与时间处理

本轮使用stage_07修正IMU实际间隔后的原生可执行文件，保持原F03/F04噪声、先验、安装角、比例系数和模块门限数值。原V3历史结果与原可执行文件未改。F03是与F04近同骨架、去除RD/RP/HV的条件对照；本轮没有调整任何配置改善成绩。

记录内GNSS UTC与body Unix时间先转换为同一天绝对时间。源内GNSS航向角速度与直接IMU gyro-z相关支持约1.14秒事件错位，四段GNSS/SDK速度另支持约1秒；统一将body时间前移1.1秒。该值来自输入事件，不使用评价参考，不称硬件时钟校准。IMU/RP整体挪时，IMU增量、实际dt和RP数值不变；HV按移后时间重新关联原GNSS A1，仍使用同一冻结旋转与比例公式。GNSS、原始Doppler和参考不挪时。初始化仍是1000帧暖机后首个合法位置/双fixed航向；移时后按该规则重新确定种子，没有按误差选窗口。

原始Doppler由GNSS1 RAWX/SFRBX→固定RTKLIB转换→原始Doppler速度求解生成，未复制PVT速度。F04真实RD更新数在下表。已保存GNSS、辅助输入、配置及运行manifest的对应身份。

## 执行历史和复算

T01实际调用8次：4个F03退出但block-list配置被原生inline解析器读成默认值，4个F04在原始Doppler血缘门前拒绝求解，整轮未准入。T02修正为inline配置，实际调用8次，所有运行参数向量168项与manifest核同；保留零offset的负结果。T03统一有效时间对齐，再调用8次。总原生进程调用24次，最终采用8次；4个T01进程未进入估计。离线方法评价为T02/0.1、T02/0.15、T03/0.15各8，共24次。XB只登记NO_INIT，未调用原生进程。
