# Follow-up mechanism diagnostics (after the first registered results)

This extension is chosen after inspecting the original 72 selections / 504 paired outcomes and 30 real searches. All old files and decisions remain unchanged. Any replay below is reused development evidence, including rows originally labelled HELDOUT; it is not a fresh held-out validation. No new integer searches, threshold fitting, or production admission are authorized by this extension.

## Why these two changes

Original tests expose accepted correct integers with biased baseline direction, especially pivot faults with weak redundancy. Real multi-GNSS windows also show residual incompatibility: 9 of 10 exceed the primary residual gate on available rows, and all 10 lose some selected active arcs. There are no pivot-coordinate switches in those windows. Thus an integer objective certificate or a two-candidate consistency decision is not a measurement-quality guarantee. Changing the pivot or reconnecting a new arc cannot resolve the measured residual problem.

1. Add geometry-only fault sensitivity to each frozen model. For an SD-signal fault column f in metres per cycle, whiten with the full retained covariance. Let H=W B, g=(H' H)^(-1) H' W f, and h=||(I-P_H) W f||². A persistent bias a cycles produces free-baseline mean bias g a and residual noncentrality h a², conditional on the fixed integer/model. Use family alpha=0.01 divided over all supplied physical signal hypotheses, a two-sided Gaussian threshold, and detection power 0.95 to obtain a minimum detectable bias. Report cycles, baseline bias norms per epoch, and undetectable directions. These are model sensitivities, not error bounds, validated physical faults, false-fix risks, or heading protection levels. No gate changes follow from the sensitivity values.

2. Add an explicit full-temporal-covariance admission path. The fixed future times, integers and active-arc requirements remain. For a supplied known joint Q, stack free b_k, compute the exact GLS residual with n-3K degrees of freedom, and allocate alpha/2 to its upper-tail gate. For each marginal baseline covariance C_kk, the squared Mahalanobis distance to its registered length sphere is bounded by a chi-square(3) error at the true baseline. Allocate alpha/(2K) to each of K length gates. Bonferroni controls the conditional correct-candidate rejection budget without assuming independent epochs. This conservative gate avoids claiming a global product-of-spheres optimum. The full Q must be explicitly supplied; no covariance is estimated from failures or truth to make real windows pass.

## Fixed replay scope

After module tests pass, compute sensitivity for the three geometry strata's registered matrices and all saved real fixed windows; this consumes saved models only. Compare old independent-epoch admission against the new joint admission for the 72 already selected synthetic candidates in CLEAN and TEMPORAL_RHO08 (144 paired replays), with unchanged alpha_total=0.01 and unchanged selected N. Supply the generative Q only: block-diagonal for CLEAN and its declared rho=0.8 temporal cross-covariance for TEMPORAL_RHO08. This is an oracle-covariance mechanism check, not a practical covariance estimator or a new independent simulation. Keep all missing, unsupported, adverse and low-power outcomes.

Do not apply a fitted full Q to the real data. Any production measurement flag remains false, and no V3 or EKF input changes.

## Selection-dependence correction, before follow-up execution

Review of the original synthetic generator found that TEMPORAL_RHO08 starts its future AR(1) recursion from the last selection-noise sample. Its future marginal covariance is rho^|i-j| times Q, but those samples are also correlated with selection noise. Substituting the correct future marginal Q alone does not justify a conditional zero-mean Gaussian statement given the selected candidate. The new API will expose this assumption explicitly: the original rho08 replay returns statistics with UNRESOLVED_SELECTION_DEPENDENCE and no shadow admission. CLEAN uses its registered independent validation noise. This is a model correction, not a relabelling of old outcomes.

To exercise a closed independent-selection working model, add exactly 72 new future-only noise realizations, one per already selected candidate, with the original CLEAN future geometry and generative mean. Seed each from the first 16 SHA-256 hex digits of the UTF-8 string CARRIER_JOINT_FUTURE_V1| plus its exact case_id. Start the five-epoch stationary AR(1) with a fresh independent standard normal vector, then apply rho=0.8 with fresh innovations; do not use any selection noise. Generate the full future Q analytically from those fixed rules. A producer may read the existing synthetic truth solely to generate the declared mean; the validation worker receives only observations, Q and frozen candidates. Report those truth reads separately. This adds 72 future-only validations to the 144 reused replays, for 216 total and zero new integer searches. Seal decisions before the evaluator reads truth for outcome labels. These are an exploratory mechanism test with reused geometries and selections, not a field-calibrated noise model, independent AR success-rate benchmark or new held-out cohort. Alpha remains unchanged.

For a matched method comparison on the 72 fresh future blocks, also execute the unchanged original independent-epoch gate once per block. This adds 72 validation-only calls, not integer searches or independent samples. Thus the follow-up performs 216 joint decisions plus 72 new IID decisions; the other 144 IID decisions are reused from the sealed initial trial. Each full-Q result has a paired IID comparator on identical data and frozen N. Methods and alpha remain fixed before these new future outcomes are read.
