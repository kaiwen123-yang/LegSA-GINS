# CLEAN5 sequence adapter plan

Status: C-02 contract freeze and read-only code audit, 2026-09-07. Audit base: `64ce0b9a032a0f86d1e139c3aa563ed3e1a74e83`. This document plans C-03; it does not execute or authorize provider generation, solver execution, evaluation, or trace-content reads.

All new adaptation code belongs under `src/legsa_gins/paper_rebuild/clean5_sequence/`, with entrypoints under `scripts/paper_rebuild/`. Existing BY2 modules, shared implementation files, `cpp/`, the two raw locks, and `A04_F04_ROLE_DECISION_RULE.md` remain unchanged. Do not monkey-patch BY2 constants or masquerade BY2H/BY2O as BY2. A reusable low-level function may be called with explicit sequence arguments; an entrypoint that also imposes BY2 identity must be replaced by a CLEAN5 composition of those low-level functions.

The sequence contracts freeze source-relative identities, the independent 44-row lock, R1, B′, initial values, numerical parameters, methods, evaluation identity, and the BY2O input-only window. Local roots are resolved only from ignored local configuration. C-03 consumes these frozen contracts without choosing a new time shift, sign, frame, lever arm, initial value, threshold, or outage window from output metrics.
