## 修改决定

**图3把版面面积用于空间轨迹。** 原来的完整路线、狭小厘米局部、航向曲线三列挤占空间；R5按方法组分开局部，保持共同参考与本文曲线，用深色和线型区别对比方法。图9继续负责航向横向比较。空间坐标不作视觉夸大或方法特异的平移。

**图4补齐用户明确确认的两条路线。** 两种方法是官方接触辅助InEKF、足端运动学航位推算。足端航位推算通过机载姿态把机体系运动转到导航坐标，并非另一种EKF。原前两面板的七初值检查保留，但属于一个既有实现的等变性质说明；新跨方法面板使用两条路线已完成的一次起始对齐后的相对表现，不混称绝对航向精度。

**图8展示三种机制不同的已有退化。** 使用固定seed00的位置噪声、方向噪声加乐观精度、机身速度噪声案例。按观测不一致、来源协方差调整、航向响应顺序阅读。案例依据退化机制和已有完整数据选择，未搜索最佳种子；保留位置代价、接近中性的结果和完整统计分母。
