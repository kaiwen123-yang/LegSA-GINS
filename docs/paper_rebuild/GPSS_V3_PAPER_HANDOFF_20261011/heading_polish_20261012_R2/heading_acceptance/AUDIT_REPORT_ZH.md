# C-LAMBDA / C-WLS 接受检验核对与独立补充

日期：2026-10-12。当前科学基线仍为冻结 V3。本文档区分文献核心、数值求解完成和新增加的工程输出接受层。

## 先纠正此前的表述

“没有整数接受检验”不等于“C-LAMBDA / C-WLS 没实现完”。两篇原文的单基线估计器已经实现并验证了核心求解；原文并没有规定这里新增的 ratio ≥ 3 在线接受步骤。

通俗地说，每个历元都可以求出一个最符合观测和长度约束的整数/方向答案。但“这是本次搜索里最好的答案”和“这个答案好到足以信任”是两个问题。原来结果回答前者；本轮新增一层事先固定的质量判断，比较最佳和第二个不同整数答案的成本差距。它既不会使用参考方向挑选答案，也不改变原来的方向估计。

## 已经完成的部分

- **C-LAMBDA：** 联合 float 和交叉协方差、各向异性球面子问题、完整约束整数目标、最佳与次佳全局分支界证书。原有 ratio 数值其实已保存，只是没有拿阈值决定输出接受。
- **C-WLS：** 期刊 Algorithm 1 几何候选、完整相关协方差的 wrapped 目标、全部唯一候选起点的细化、完整候选池收敛检查和最终排序。保存了每个细化候选的整数向量和目标；收敛失败仍作为原生失败保留。
- **输入适配：** 本轮使用最终 `RAW_REPRO_V2__TECH_RETRY_2`，包含原始卫星发射时刻和 SPP 几何延时修复；不回到旧 V1，不改变新旧版本结果。

## 本轮新增的步骤

名称固定为 **project-added ratio screen**（项目新增成本比筛选），不要在图中改名为“原文修复版”或“正确固定”。

规则在 `PLAN_LOCK.json` 登记并提交 GitHub 后才应用到全部历元。原方法各自的成本定义保持不变，最佳/次佳取两个不同整数 hypothesis。阈值 3 沿用项目已有 DD-KF 的工程数值，一套设置跨三序列，未根据参考误差校准。

对 C-WLS，多个粗起点可能细化到完全相同的整数结果；先按整数向量合并，不能拿同一个整数的两个重复拷贝当作第一和第二候选。任何原生不收敛/搜索失败均不被挽救。成本零、缺少次佳、非有限值、候选池不完整都单列。

C-LAMBDA 成本以 joint-float 最小残差为基准；C-WLS 为完整 wrapped 观测成本，二者有不同常数项。因此共同采用数值 3 只是明确的工程对照，不能当作共同标定的错误固定概率，也不能跨方法比较 ratio 数字大小。

4. 图 5 以航向误差时序/局部放大为中心，再配精度分布与简洁覆盖说明。展示本项目在实际机器人上的方向输出表现，不把它写成原始整数求解器同输入排名。
