## 解释时要讲清楚的含义

图4(b)只消除已知初始旋转，独立数值核对确认全路径重合。1.89×10⁻⁷m是不同运行消除旋转后的差，不是地理定位精度。

图7的凸起是中断期间位置误差增加、绝对观测恢复后的校正；它不是机器人走出的空间轨迹。左列全GNSS缺失时辅助更新也暂停，右列保留方向和辅助调度。

图10上排比较三种估计配置，中下排比较原方向观测与融合航向。紫色是测量输入，不是另一个导航算法；三列分别为方向缺失、噪声、尖峰。详细解释见上方专门读法。

完整轨迹来自既存坐标/NAV、已登记坐标转换或同点有符号ENU误差与参考的精确重建。没有用水平误差模长反推轨迹，没有通过拟合变换美化结果。所有不完整、局部坐标或仅方向方法都有去向记录。
