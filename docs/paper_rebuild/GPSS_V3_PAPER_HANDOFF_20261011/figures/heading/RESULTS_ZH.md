# Q2：短基线方向观测何时可靠？

在当前0.35 m双天线安装和三组实测记录中，**新方向输出是否持续、已输出方向是否满足物理一致性，是两个需要分别检查的问题。** 一次固定状态本身不足以同时回答这两个问题。

主图从这一点展开。RTKLIB原配置在常规行走、大幅机身运动和单侧天线遮挡中的新固定输出分别为153/1370、179/1350和112/1885，即11.2%、13.3%和5.9%。图(a)保留这些新输出的完整误差分布，图(b)给出它们在整个实验过程中的位置，因此较小误差段与未覆盖时段可以一起读。图(c–d)进一步显示，常规行走窗内153个固定输出中，有35个带有超过0.04 m的长度残差；局部放大中包含0.70775 m的基线长度，而安装名义长度是0.35 m。

这35个历元在保存的程序执行记录中都至少有一次成功浮解更新加入长度项。固定解后验检查记录了大长度残差，仍保留固定输出。这个已有结果把讨论从“解算是否返回固定状态”推进到“返回的方向何时可以进入融合”。它不需要预先确定唯一的物理故障原因。

四种RTKLIB配置的完整结果放在补图SQ2_RTKLIB_all_configurations。更换星历、增加星座与采用fix-and-hold，各自在新输出数量、有效时刻误差和保持旧值后的误差之间有不同表现。例如，常规行走中fix-and-hold的新输出RMSE为4.512°，但只有60/1370个新输出；大幅机身运动和遮挡记录对应10.623°及19.206°。四种配置都应结合输出时间线解读，不能只按有效时刻RMSE排序。

三种原始双天线处理路线的九组保存结果放在补图SQ2_raw_dual_antenna_methods。上排用完整绝对误差累积分布代替多条±180°跳变曲线的叠加，下排保留各自实际输出时间。C-LAMBDA和C-WLS误差分布接近，是保存结果本身的特征。DD-KF在大幅机身运动记录中绝对误差分布较集中，在遮挡记录中则更差；三种方法的有效样本和覆盖不同，图中不填补未输出区间。

FAR和声明PAR策略已在三组记录实际执行，六个策略结果的接受数均为0。完整计数与失败类别保存在FAR_PAR_ALL_THREE_TRIALS.csv及各记录的失败表中，作为补充结果呈现。C-LAMBDA/C-WLS的方向候选未设置整数接受检验，因此其“有输出”与FAR/PAR的“被准入输出”分别说明，不合并为一个固定率。

DG01/DG01R与输入历史核对提供解释这些比较的测量背景。钟差修正后，常规行走GPS L1、双接收机固定状态下的包裹双差残差P95从0.476949收窄到0.191856周。六份同历史RINEX恢复后，631733个码和299516个相位字段以及LLI/SSI差异为0。这些已完成的修正说明，原先未校正钟差或输入历史不一致时的诊断不能继续作为最终物理归因。

这一组在五问题主线中的作用是建立方向观测的条件：**后续融合应利用可获得的方向，同时处理稀疏更新和观测质量变化。** 下一组即可讨论，加入这些信息后，本文方法与滤波、因子图路线在导航精度和输出连续性上各自表现如何。
