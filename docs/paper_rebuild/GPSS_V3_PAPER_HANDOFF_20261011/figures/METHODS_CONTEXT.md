# 随图统一说明的方法与评价条件

正文用LegSA-GINS作为方法名称；V3是冻结科学版本标记。原内部F/A编号用于源数据对应，不作为图例。

| 比较路线 | 实际信息与输出 | 评价和图件用途 |
|---|---|---|
| 机器人自身观测 | 机体IMU、接触标签和足端运动学代理；官方接触InEKF；积分参照另使用机载姿态 | 结构验证用规范集合/零空间；相对精度进行一次10 s平移与航向对齐 |
| 原始双天线方向 | 原始码相位、星历、长度约束和各自候选/接受策略 | 使用各方法原生输出状态、方向误差和覆盖；候选输出与整数接受状态分别定义 |
| 两位置/单位置IEKF | 高层位置、IMU和共同初始方向；文献与项目标定噪声条件 | 自然与退化系统比较；单位置只指在线更新；原起点和几何状态随表保留 |
| OiSAM | RTK位置、机体IMU及每次初始化方向；估计姿态、位置、速度和偏置 | strict与V3使用现成共同点、共同时间表；segmented另保留输入缺口恢复协议 |
| Wen TC / GNC | 原始码与适配AHRS运动联系，或原始码与Doppler | 同GNSS1位置图；未自行估计的姿态不列成绩 |
| GINav | 官方SPP/INS与其速度对准路线 | 实际初始化等待、输出与速度越界保留；无合法全窗指标时保持空值 |
| 本文内部对照 | 同一状态估计器中按已登记配置改变航向、RD、RP、HV和来源加权 | 通过真实配置及单开关实验解释作用；受控退化复用一条录制，九布置/种子不称九次独立实地采集 |

三条正式自然记录的公开名称为常规行走、大幅机身运动和单侧天线遮挡，分别对应原始by2、by3、by1。作者已说明第二条包含幅度较大的动作和明显振动。图中“遮挡记录初段”的短共同支持与实际遮挡发生时段分开说明。

位置和姿态误差沿用已经完成的评价合同及Fixposition融合参考。不同输入层次、初始化次数和物理点在上述表中集中定义。参考与接收机系统共享GNSS信息；当前数据不提供独立速度误差评价，空缺的速度指标不填零。统计分母区分全注册案例、共同完成案例和实际输出历元。

冻结V3航向来自双接收机已解算位置差及质量准入。机身水平速度辅助已使用历史航向旋转，辅助更新由有效GNSS事件调度。完全GNSS失效和平移失效但航向保留是不同实验条件。来源权重在规定上限内放大量测协方差，不将“倍率有上限”延伸为任意状态误差有界的理论结论。

全部官方实现、基于论文的实现分支和工程适配身份，在METHODS_AND_EVALUATION.csv及各源记录中逐项保存。共同物理点和共同时间支持用于比较已完成系统结果，内部单开关实验用于解释单项贡献。
