# 横向比较的论文组织

这套比较以三条已完成研究线为基础：机器人自身观测的绝对方向约束、短基线GNSS方向获取、导航融合。各方法承担清楚的问题，保留真实结果和已经完成的控制，不再按算法目录逐个展示。

## 两个已经存在、应恢复到正文的联系

**联系一：同一IEKF骨架的方向信息控制。** LC01/EXT05C在线双/单位置更新已完成；LC01-BR在平移中断时保留相对基线更新也已完成。BR的A2全窗H中位2.786 m，对应LC01为1.407 m。这说明方向约束的存在与位置收益之间还取决于其他运动信息和融合方式，能自然引出本文已有HV实验。

**联系二：V3/OiSAM共同点对比。** 现成表的support=COMMON_POI_OISAM_V3_TIME、physical_point=POI_MIDPOINT。常规274共同点上V3/OiSAM H为0.096757/0.105953 m，yaw为1.778176/4.659461°。遮挡记录仅54共同点，H接近、OiSAM yaw更小；大幅运动记录严格协议无共同输出。主图应同时展示全窗输出时间线，帮助读者理解这些精度的适用时段。分段恢复结果另外展示，保持其自身协议和GNSS1评价点。

## 稿件中的写法

结果部分先说明机器人自身观测为什么需要绝对方向，再展示方向获取的实际质量与连续性，随后比较完整导航表现，最后用内部对照解释航向、机身状态辅助与来源权重的作用。

外部比较的作用是验证方案在当前机器人数据和传感器条件下的实用价值。已有受控实验负责解释各项设计。这样既保留你已经完成的大量比较，也让读者明白每一组结果为什么出现。
