## 4. 运动学输入参照也已经完成，旧摘要的名称需要修正

HX05 的真实定义为

`v_body = −mean_contact(ω × p_foot + foot_speed_body)`，

随后使用机载 `rpy` 构造姿态，将速度旋转到世界系并做三维梯形积分。无接触的相邻区间不插值、不累计位移。**它不是直接把 SDK 的 velocity 字段积分，也不是一个新发表的独立状态估计算法。**

`TIM_EVIDENCE_20261005/comparisons/METHOD_ACCEPTANCE_MATRIX.csv` 的 LEG_DR 输入摘要写成了 `SDKbody velocity +manufacturer attitude`，与 HX05 登记、源码和实际 RESULT 不一致。本轮不修改旧文件；论文整理应恢复为“接触运动学积分（使用机载姿态）”。
