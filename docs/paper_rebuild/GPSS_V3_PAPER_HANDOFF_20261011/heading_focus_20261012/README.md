## 核心结果的阅读方式

自然记录中，基础GNSS/INS加入持续方向后，航向RMSE从8.090/7.137/5.739°降到1.916/1.941/2.432°；完整V3为1.886/1.934/2.434°。主要航向收益来自持续方向更新，机身倾角、速度和来源加权由各自受控对照解释。

最接近的标定双位置IEKF在常规记录更好，在大幅运动记录与V3相近，遮挡记录V3更好。图9共同历元口径与全频率冻结统计不同，不覆盖后者。

C-LAMBDA/C-WLS原论文没有规定本轮ratio≥3，既有核心求解并非未完成。作者要求补充质量判断后，本轮先以提交6a1e536锁定工程规则，再生成10446条mask并封存，最后连接既有误差。筛选后仍存在大角度误差，故保留原方法和新增版本分别报告。没有重跑原生求解器或更改冻结V3。

正文只重点讨论两个D59精度边界；5951条核心结果、2164条消融配对及283条未完成结果完整保留。没有为改善图面而改分母或删除结果。原始参考为Fixposition衍生参考，沿用原评价定义。
