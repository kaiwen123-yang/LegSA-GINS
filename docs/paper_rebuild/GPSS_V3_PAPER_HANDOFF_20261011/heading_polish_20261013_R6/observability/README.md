## 七次运行到底是什么

**同一个接触辅助InEKF、同一段机器人日志，采用七种不同的初始全局坐标朝向。**

|保持相同|改变的量|
|---|---|
|估计器、参数、IMU记录、足位代理、接触记录|初始全局朝向，以及按同一旋转同步变换的世界坐标状态和协方差|

七个角度为 **−150°、−100°、−50°、0°、+50°、+100°、+150°**。0°复用原有主运行，另六个角度来自之前已经执行的逐历元回放。每份保存63,277条状态；本轮没有重新执行这些运行。它们是一次采集的七个初始化设置。

图例只突出−100°、0°、+100°三条代表曲线，其余四条用灰色显示；灰色的四条仍分别对应−150°、−50°、+50°、+150°。

## 三个面板怎样读

**(a) 先看方向不同。** 机器人记录的是同一段运动，但七个运行采用不同的全局坐标朝向，结果在平面里整体旋转。它们的相对运动形状相同。

**(b) 再把坐标朝向统一。** 绘图使用各次运行已知的初始旋转，将七份结果转换回0°运行的朝向。七条轨迹因此重合；这一步没有搜索或拟合一个最有利角度。

**(c) 最后量化重合程度。** 对比逆旋转后的各条轨迹与0°运行，最大差约1.89×10⁻⁷m。该量是运行之间的一致性残差；图中没有用它表示相对真实位置的定位精度。

这张图展示：同一份机器人相对运动观测允许整体旋转后的全局表达。运动的形状能够保持，但需要额外的绝对方向信息才能确定它相对于地理方向的朝向。图中的七初值检查负责解释这一性质，航向精度提升由后续方向观测和融合结果展示。
