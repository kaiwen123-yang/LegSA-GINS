## 数据复用

本目录不复制R5的数据包。`SOURCE_POINTER.json`记录R5的一秒汇总、三例指标及实际倍率摘要的路径和hash。绘图脚本直接读取这五个已有文件，不计算新的中位数、范围或RMSE。全部原生样本、全61类型筛选及完整541对照仍由R5材料保存。

在原工作区运行`python build_fig8_r6.py`即可重绘；在其他目录可用`--source-dir <R5/aiding目录>`指定同一已归档来源。图注内容沿用R5，见`CAPTIONS_ZH_EN.md`。

结果解释不变：第一行体现位置退化时的航向保护及位置代价，第二行为小幅航向收益，第三行为航向近中性而位置改善。倍率是来源协方差相对自身基准的调整，不是精确卡尔曼增益；色带是每个时间箱内的范围，不是回放置信区间。
