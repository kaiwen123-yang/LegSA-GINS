# 图 8：从“堆三个案例”改为解释一条真实处理过程

![图8](preview/F08_heading_quality_scaling.png)

这张图现在只想说明一句话：**在某些观测退化条件下，按来源调整观测影响，能够减小航向被带偏；这种作用不等于普遍提高每一次回放的航向精度。**

沿 (a)→(b)→(c) 阅读：位置观测与预测出现米级差距，而输入仍自报厘米级精度；实际策略对不同来源施加不同的协方差倍率；同一次回放中，完整方法的航向偏离显著小于关闭来源加权的对照。主图只使用之前一直采用的首个位置加噪回放，没有重新挑更有利的seed。

## (a) 什么输入变坏了？

这个已完成回放给位置输入加入水平σ3 m、垂直σ5 m噪声，同时保持原GNSS18的精度字段。灰线是**位置观测与滤波预测之间的三维距离**，也就是保存日志中的位置创新范数；它不是相对于地理真值的位置误差。橙色虚线是输入自报三轴标准差的范数，约0.023 m。

原GNSS18的hash与原native记录完全一致；600个所示位置更新的三轴标准差平方和与保存的base_R_trace一致，最大数值差约1.1×10⁻¹⁹。因而图中的“自报精度”不是从结果倒推的。

单看大创新不能断言测量一定错误，因为创新也受预测误差影响。本例的位置噪声由既有实验定义明确施加，图(a)用于展示这一受控条件下的实际不一致程度，不据此发明一个新的异常判定门槛。

## (b) 来源加权具体做了什么？

这一格去掉了难读的三条高频倍率曲线。每一行汇总同一前120 s的600个原记录倍率：蓝点为中位数，粗线为25%–75%区间，细线为完整范围。

| 来源 | 中位倍率 | 四分位区间 | 原记录范围 |
|---|---:|---:|---:|
| 位置 | ×2.08 | ×1.46–3.13 | ×1–5 |
| 机身水平速度 | ×10 | ×10–10 | ×2–10 |
| 方向 | ×1 | ×1–1 | ×1–1.0085 |

协方差变大，表示该来源相对于其自己的基准被相对减弱；这里方向观测基本维持原协方差，位置和机身速度更新更明显地被减弱。**倍率不是精度提升倍数，也不是卡尔曼增益的精确倒数；不同来源的基准协方差和物理单位不同，不能把三行当作绝对权重排行榜。**

机身速度输入在这例中并未被人为加噪。它的创新可以因其他来源扰动后的状态预测发生变化，因此这行表示其更新与当前估计发生不一致后的实际处理，不等于认定机身速度传感器物理损坏。关闭来源加权的对照同时改变多个来源的策略；这一张不能把收益单独归因于位置倍率。

## (c) 这种处理对应什么航向结果？

紫色虚线关闭来源加权，蓝色实线为完整方法。展示区间仍统一为原来的前120 s。两条原始序列没有平滑，没有移动时间或角度。

本例完整274 s航向RMSE由29.80°降为2.70°。与此同时，水平位置RMSE从3.17 m升到3.56 m；这个代价写在图下方。图不再试图同时说“位置和航向都更好”，而是把航向的条件性稳健收益说清楚。

## 为什么不再将三个案例并排放正文？

本轮读取了三个案例的实际来源日志。位置加噪与“位置加噪＋速度源冲突”的航向形状、位置倍率、机身速度倍率都很相近，主要共同成分是坏位置。把它们并列为两个等大的正文故事，会给人重复堆效果的感觉。方向噪声与乐观std的独立条件确有收益，但首例只是1.731→1.631°，不适合用同样的巨大视觉权重讲“大幅改善”。

三种条件各自全部九个变体仍完整画在 [配套比较](preview/S_F08_all_condition_variants.png)。[完整时间序列](preview/S_F08_full_heading_histories.png) 和 [513配对分布及实际来源时序](preview/S_quality_complete_statistics.png) 也继续保留。原位置加噪和跨源冲突中的大误差、原生发散均未删除。

## 完整结果允许怎样写结论？

全部541个登记来源加权对照中，有513个双方共同完成、6个仅完整方法完成、22个双方未完成。513对里，完整方法有190例yaw RMSE较低、323例较高；定义“关闭−完整”后，中位降低量为−0.000258°，最大恶化为1.1505°。多数变化很小，但不能因此把每个恶化都称作可忽略。

因此正文可以说“在部分退化条件下限制较大航向偏离、增加完成案例”，不能写成“所有条件或典型条件普遍提升航向精度”。对应原始数字在 `F08_OVERALL_PAIRED_RESULT.json`、`tables/F08_ALL541_WEIGHTING_COMPARISONS.csv`、`tables/F08_ALL513_COMPLETED_PAIRS.csv`；完整5951结果、2164四项消融对照和283未完成记录也原样保留。
