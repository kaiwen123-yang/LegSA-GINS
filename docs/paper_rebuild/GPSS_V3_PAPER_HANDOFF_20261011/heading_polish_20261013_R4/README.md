## 本轮决定

图1、4、5、6、7、9、10的出版图原样保留。图4另修正文外图注和来源描述。图2的主SVG和原排版PDF不变，从SVG重渲染3840/7680像素宽PNG，并提供实际可缩放的阅读页及放大PDF。

图3和原图11合为一张正文图3，每场景一行“完整地理路线—同点空间细节—100s航向误差”。原独立图11转为历史/补充来源，正文仍按图1–10讨论。完整路线纳入八个主导航配置，厘米局部和航向分别采用具备同点位置与实际姿态输出的六配置。不同输出点在米尺度概览中明确标注，不作为同点评分。

原遮挡局部是参考轨迹近静止片段：10s内参考净位移约6.13mm，SDK独立来源低速读数与其一致。新空间细节采用参考确定的228–233s恢复运动，原遮挡期间的航向过程继续显示。机载SDK弱辅助并非独立运动真值，诊断使用准确限定措辞。

图4是一种接触辅助InEKF、一次BY2记录、七种初始全局朝向，其中0°复用H5、六种非零设置为H6原生回放；与用户记得只比较过少数方法一致。消除已知坐标旋转后重合是预期。图4属于原理说明/实现验证，不当成七方法比较或精度提升证据。

图8改为一条已完成退化回放的三面板机制说明：位置观测与预测不一致且标称不确定度仍小；实际来源协方差调整不同；同一回放航向偏差减少，同时保留位置代价。总体513共同完成案例中190改善、323升高，中位降低量−0.000258°，说明贡献是条件性稳健收益，不能写成普遍提高典型航向精度。完整变体与失败仍在配套图表。
