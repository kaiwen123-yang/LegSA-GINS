本轮主SVG和PDF与R3逐字节相同，框、文字、图标、连接关系均不变。旧主SVG没有任何嵌入位图，文字和线路本身可无损缩放。

- [主编辑SVG](editable/F02_method_traced.svg)、[PDF](figures/F02_method.pdf)。
- [放大阅读PDF](figures/F02_method_reading.pdf)：同一矢量原稿的完整图及两页分区放大，不重新排图；扩大阅读尺寸，使细字便于检查。

上一轮图库的放大弹窗仍有max-width:92vw限制，未提供真正的原尺寸浏览。当前独立页面直接显示SVG，实际检查200%宽3630px、可横向滚动，390px手机窗口适配354px图宽，无脚本异常。检查记录和截图位于qa/F02_VIEWER_CHECK.json及相邻PNG。

作者随后确认打开原尺寸文件也觉得模糊，因此本轮另提供放大阅读PDF，按260mm宽显示完整矢量图，并提供输入与估计器两页局部。原174mm版式中普通文字约6.5–7.5pt，阅读版相应放大，不把小字难读全部归因于缩略图。

PNG由原SVG按新像素尺寸重新渲染，没有用低分辨率PNG拉伸。图2版式和科学内容不变；最终稿可继续用矢量PDF/SVG。图1保留作者通过的R3版本。
