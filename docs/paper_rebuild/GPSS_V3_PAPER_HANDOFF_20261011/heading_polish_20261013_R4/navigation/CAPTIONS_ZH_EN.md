# F03_integrated_routes_and_heading

三场景导航路线、同点空间局部与航向误差的合图。每行依次展示完整评价窗的地理路线、由参考运动确定的POI局部、以及固定100秒的航向误差。全路图纳入所有主导航输出；本文、IEKF和恢复OiSAM在POI中点，TC/GNC保留原GNSS1位置，因此全路只作空间概览，不作同点精度排名。厘米局部全部统一POI；OiSAM仅用自身估计姿态与已有登记杆臂作显示点变换，没有使用参考姿态。遮挡局部采用参考确认的228–233秒恢复运动，不再将近静止点团称作运动路线。右列使用与图9相同的六方法共同动态时刻；TC/GNC没有自估计航向，不画伪航向曲线。常规/大幅运动的100秒窗口为40–140秒，遮挡为154.945–254.945秒；灰带是原登记遮挡183.94–225.95秒，淡蓝带对应空间细节时间。所有原生轨迹点及共同支持记录保留，缺口断线。

Integrated navigation routes, same-point spatial details and heading errors for three recordings. Each row shows the complete geographic route, a reference-defined POI detail, and a fixed100-s heading interval. The overview includes all principal navigation outputs: LegSA-GINS, IEKFs and reinitialized OiSAM use the POI midpoint, whereas TC/GNC retain their registered GNSS1 positions; it is therefore a spatial overview rather than a same-point accuracy ranking. Every centimetre-scale detail is at the POI. OiSAM point transport uses only its own estimated attitude and the previously registered lever arm, never reference attitude. The obstruction detail covers reference-confirmed recovery motion at228–233s instead of a nearly stationary interval. Heading uses the same six-method common dynamic support as Fig.9; no heading is invented for TC/GNC. The100-s windows are40–140s for the first two records and154.945–254.945s for obstruction. Gray shading marks the registered183.94–225.95s obstruction; pale blue identifies the spatial-detail interval. All native route points and common-support records are retained, with breaks at gaps.
