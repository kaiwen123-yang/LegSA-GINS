## 必须一同读的定义

- 原始 by2 → BY2 → 常规行走；by3 → BY2H → 大幅机身运动；by1 → BY2O → 单侧天线遮挡。
- 原 V3 正式评价窗分别为 [66,340]、[413,683]、[3186,3563] s。前两记录时间原点 1772784000，遮挡记录为 1772780400。对齐来源见原故事账本。
- 九个中断布置来自同一记录，不是九次独立野外实验。M5 下排是完整评价窗 RMSE，上排为瞬时误差；两者不混用。
- OiSAM 严格单次初始化支持 275/0/55，主要停止原因是输入 IMU 缺口；分段重新初始化动态输出 275/267/370 另立身份。M4 的遮挡记录精度来自早期 54 个共同输出，不能代表后续遮挡过程。
- M4 使用 POI_MIDPOINT 与共同时间支持；分段 FGO 的 GNSS1 位置不混入该同点位置比较。FGO 航向的后续覆盖另见 S5。
- 完整 V3 与基础配置相差多个开关，不能把 F04−F01 的全部收益归为单独航向作用。F01→F03 才是本图使用的方向链对照。
- R 放大倍数越大，表示相对减弱该来源的影响，不能读成更大信任，也不是完整卡尔曼增益的倒数。
- 目前没有证明跨方法信息完全相同。原始码/Doppler、位置产品、机载状态、初始化和输出物理点各自列在方法表。
