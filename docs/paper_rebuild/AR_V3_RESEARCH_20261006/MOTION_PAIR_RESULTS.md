## 2. 反射别名：正确运动先验仍不能给出整数真值

首例单位 LOS 的解析关系是 `Hv=λd`，`v=(0.3,0,0) m`，`d=(1,1,1,0)`。生成整数 `N=(2,−1,1,0)` 与反射整数 `N′=(3,0,2,0)` 对应两个等长、同夹角的精确相位解释。码取两解预测的中点，是明确注入的合成码扰动；本例不是全观测无噪声，也不是生成 N 已被完整似然唯一偏好的前提。

首例 81 点的**零相位残差子模型** oracle 保留这两个点，原始成本分别为 `0.08690803657701887` 与 `0.08690803657701883`。盒外完整有限权目标的 Gaussian 下界为 `0.3347194011553368`，高于已知可行上界 `0.08690803657701877`；可以排除低于该上界的盒外整数。该检查不求解盒内有限权连续 profile，因此不是完整 CILS 全局 oracle。

有限相位权重下 profile b 后，两方法都偏好反射 N′。新方法首例的 N′ 约化成本区间为 `[0.0869050558277, 0.0869050559859]`，生成 N 为 `[0.0869051666738, 0.0869051668193]`；这项很小的排序差来自同一有限权目标的码相位折中。两方法的返回基线一致，额外运动下界增量为 0，相对生成基线的偏差约 0.30 m / 50.75°。不能将条件模型中的严格排序误写为生成整数已正确固定，也不能把构造性大误差当成真实 V3 失败率。

静止、绕基线轴转 90°、近零夹角三个场景同样返回 N′；相应新方法额外运动下界均为 0。静止与绕轴场景观测及数值输出相同，符合“机体旋转幅度不等于基线方向激励”。正确夹角区间同时包含生成与反射基线；错误区间同时排除这两个指定点，但不表示其整数类没有其它有非零残差的连续可行点。

## 3. 保存几何工作噪声：相同整数，更高当前计算代价

三个保存几何场景使用同一底层 seed=20261007 的两历元 SD Gaussian 噪声，是配对条件，不能按三个独立样本报成功率。码 / 相位分别用保存的 SD 方差（m²）生成，相位不再次乘波长，完整 Q 不变。已知注入噪声的每期 `rᵀQ⁻¹r` 为 `10.7621002761` / `27.0504463674`，总计 `37.8125466435`（28 维）；这只是保存 Q 工作模型的一次样本，不是实际 RAWX 噪声已校准的证据。
