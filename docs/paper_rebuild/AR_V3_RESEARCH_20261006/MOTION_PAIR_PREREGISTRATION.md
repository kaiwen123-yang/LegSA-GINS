# 两历元运动约束 R6：机制资格预注册

状态：仅准备，**整数搜索 0 次**。本计划不运行真实导航，不改 V3/main，不读取 trace，不改变观测门、噪声权重或整数域。实执行须在本计划、runner 和内核版本登记提交后，由 root 明确启动。机器可读输入见 [MOTION_PAIR_PREREGISTRATION.json](MOTION_PAIR_PREREGISTRATION.json)；内核理论见 [MOTION_BOUND_DESIGN.md](MOTION_BOUND_DESIGN.md)。

## 1. 要回答的问题

在相同码 / 相位观测、完整组内 Q、独立历元工作协方差、共享整数 N 和固定长度 0.35 m 下，增加未知初始姿态下的两基线夹角区间，是否带来可解释的整数排序变化？先验证该方法**不能**区分的情形，再讨论有噪声 / 变化几何的作用。

两方法分别是现有 `solve_temporal` 的独立球面目标，以及 `solve_motion_pair` 的夹角约束目标。新内核只在完整整数向量的叶子上给成本上下界；整数树节点使用 Gaussian 整数松弛下界。新结果的上界排序、搜索结束、整数身份分离、连续内层全局最优、整数接受和真实整数正确性是不同结论。仅 `integer_winner_separated` 在模型及数值界成立条件下支持最优整数身份的分离；不授予连续全局最优、错误固定概率或导航准入。

## 2. 精确反射别名与物理生成

波长取 GPS L1 `λ=299792458/1575.42e6 m`，`L=0.35 m`，`v=(0.3,0,0) m`。共同 pivot 的单位 LOS 为 `(0,0,1)`。前三个目标的 `ux=−λ/0.3`、`uy=−0.5,0,0.5`，`uz` 均取单位球正根；第四个目标为 `(0,0.4,sqrt(1−0.4²))`。因此 `H=up−us` 满列秩，且

```
H v = λ d,       d = (1,1,1,0).
b1 = (0.15,s,0), b2 = (0.15,s cosθ,s sinθ),
s = sqrt(0.35²−0.15²), θ = 60°.
N = (2,−1,1,0),  N' = N+d,  b'i = bi−v.
```

这对整数 / 基线在平面波相位模型 `λN+Hbi` 中完全相同，两个长度和基线夹角也相同。注意 `θ=60°` 是 yz 投影的相对角；真实三维基线夹角约为 `0.9374607 rad`，runner 直接从向量计算，绝不把二者混用。正确运动先验从已知生成姿态得到，只把夹角区间交给求解器；未知初始绝对姿态 R0、真整数和真基线均不进入求解器参数或种子。

原始几何观测使用同一单位 LOS 上 24,000 km 的合成卫星和接收机 `−bi/2,+bi/2` 的距离差生成。通过差平方公式计算 RX2−RX1 的 SD，再做 target−pivot DD，避免大距离相减失精度。有限距离和线性化 H 的偏差逐例记录；“精确别名”是线性化模型的解析等式，非对任意真实卫星轨道的声称。别名例的相位无额外注入噪声；**码取两解几何预测的中点，故有明确合成码扰动，不是全观测无噪声。** 完整共 pivot Q 由独立 SD 方差构造，码 / 相位 SD 标准差分别固定为 0.5 m / 0.003 m，不按结果调节。

必须独立检查：两组相位预测相同、等长、等夹角、两指定点的完整成本相同。有限相位权重下重新 profile 连续 b 时，两整数类的最小总成本未必相同；码相位折中和曲率可改变排序。因此不强求搜索器的最优两类成本恰好相等，也不能将此类 profile 排序变化称为“角先验解除精确相位别名”。正确角域不能在几何可行性上区分上述两个点；错误角域会同时排除它们，**但不等于这两个整数类的所有连续基线都不可行**。

同 H 满列秩时另有直接证明：`Δphase=H Δb` 不含 N，确定 Δb；两长度已知后 `cosβ=1−||Δb||²/(2L²)` 已确定。未知 R0 下两向量的相同 Gram 可由某个 SO(3) 映射，真实三维转动本身不解除该两历元退化。单纯增加更多 Gram 项也不足以排除公共反射；rank 3 情形还需 proper rotation 的手性要求。此处不扩展到多历元方法。

## 4. 独立有限域 oracle 与界检查

仅在首场景枚举 `N0+{−1,0,1}^4` 的 81 个预定整数点。每点直接由相位方程最小二乘解两个 b，再检查相位残差、长度和角域，计算完整原始成本。这是**零相位残差子模型**的完整有限域 oracle，既不调用候选搜索器，也不等价于有限权 CILS 的连续内层最优化。保存每个可行点；不得把其最优点冒作完整 CILS 真值。

另以独立 Cholesky / SVD 完成全 GLS，得到 `Jfloat, ahat, Qaa`。盒外任意整数至少有一个坐标不在 `[li,ui]`，其成本下界为

```
Joutside >= Jfloat + min_i distance(ahat_i, {…li−1} ∪ {ui+1…})² / Qaa_ii.
```

外部下界若不超过已知可行点上界，则明确写“盒外未排除”；通过时也只排除低于该上界的盒外整数，不授予盒内非线性全局排序。有限域零相位 oracle 与完整有限权似然的区别不能省略。

另固定随机种子 20261006，每场景生成 32 对已知可行的等长基线与事前整数扰动，共 256 个 fixed-N 检查。将新叶子的下界加回同一 float 常数，与独立完整原始残差成本比较，并复算其上界点成本。它们不调用整数搜索，不按结果重抽，不代表全域数学证明。任何下界违反或诊断异常须保留记录并停止后续搜索，不将问题修成成功后覆盖。

## 6. Go / no-go

数值资格首先要求反射等价、错误界排除事实、原始目标恒等式、完整 Q 和已知可行对下界检查不违背。任一失败先修资格问题，当前结果保留，不改登记参数重跑。

推进 R7 的最低积极证据是：在**正确先验的保存几何高斯工作噪声行**，旧目标已认证的首选整数不同于生成整数，而新目标给出严格分离的生成整数；或者旧搜索在固定预算内未决，新目标已有证据分离生成整数。后者是搜索 / 证书能力证据，不能改写为旧模型已错误固定。两者均须解释成本和约束来源。仅 ratio 上升、候选变少、上界首位变化、成功恢复本已由无噪声满秩码唯一确定的解均不计。反射场景的 profile 排序变化也不计作解除别名的证据。

若上述证据不存在，结论仅为这八个场景的有限机制证据不足以支持扩展；不是证明所有运动方法或该机制普遍无效。本轮不得用调参、换随机种子或追加易例制造积极证据。

积极结果意味着继续进入 R7 前必要的局部风险设计与检查，合格后再推进；并非预先锁死后续导航任务。错误先验下的代价仍须独立说明：真值排除、原始残差成本变化、错误整数上界排序 / 分离及未决状态均原样报告。当前尚没有在线识别错误先验、撤销错误约束或风险控制机制，不能将积极排序写成“错误先验代价已可控”。因此积极结果将 `navigation_expansion_allowed` 记为 `null`，含义是等待 R7 局部风险资格，不能仅凭 R6 自动放行；证据不足则本轮记为 `false`。所有结果均为合成机制诊断，排除在正式 V3 实测绩效表之外。
