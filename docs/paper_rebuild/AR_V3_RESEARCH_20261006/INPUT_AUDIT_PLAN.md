# 同完整历史的输入诊断登记

仅以既有V3三序列的六个接收机原始CSV为输入，使用已登记的官方convbin。
不调用导航、整数解算或评价，不读取参考。运行计划见INPUT_AUDIT_PLAN.json。

1. 每个raw文件只读取一次，核已有原始哈希；按文件顺序提取完整UBX帧并校验。
2. 与HX02保留的完整UBX逐字节比较，同时核旧OBS输入身份。
3. 同一官方convbin、同一选项转换完整UBX一次，共六次，单次120秒上限，无自动重试。
4. 比较完整OBS的原始科学记录及逐信号C/L/D/S、LLI，覆盖旧15个差异事件。
   另核按旧窗口提取的UBX是否与DG01R截窗输入一致，从而固定转换器之外的变量。
5. 所有差异保留，不因支持或数值不一致重新选窗口/改标志。
   若六份完整输入和输出均一致，只能解释被控制的转换/历史差异；
   不由此断言原始载波无物理偏差或整数一定正确。

转换是输入诊断，不增加正式方法结果。原始文件、HX02/DG01R及V3不写入。
输出在WSL研究scratch；小型差异表与回执提交研究分支。
