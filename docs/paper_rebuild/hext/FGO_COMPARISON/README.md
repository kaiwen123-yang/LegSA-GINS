OiSAM与V3在BY2H/BY2O的共同支持位置误差接近，OiSAM在BY2O的3D RMSE略低；V3在三条序列的航向RMSE均更低。这里只报告已有参考下的系统应用表现，不声称统计显著、独立真值或同输入求解器优势。Wen TC与GNC在原始GNSS位置层有直接比较价值，GNC三序列误差均较低；二者辅助观测不同，不能把全部差值归因于GM/GNC。

共同支持只选已有有效历元：各方法距同一名义秒≤5ms，方法间差最多10ms，不插值算法输出。`COMMON_*`的actual/finite/matched都是所选子集计数，原数量另存`own_*`；自身支持行始终保留。V3共同支持指标从既有误差序列派生，原全支持指标原值保留；没有重新调用V3解算器或旧评价器。

完整表保留LC01两种BY2H起点：FILE_START与CONTRACT_START均带既有几何审查`FAIL`，后者还有结果见后修订边界，不提升为新验证主结果。EXT01–03与RTKLIB四变体的native-valid、ratio-fixed、causal-held三种支持共63行原值保留，沿原paired分母和缺口/保持时长定义；它们是航向层方法，不能补成完整导航位置成绩。旧结果未记录的名义分母留空。
