## 三项贡献应怎样表述

1. **短侧向双天线的方向观测与准入。** 研究紧凑足式平台上的安装几何、同历元位置差与可用性，而不是声称新的载波整数解算器。
2. **本体弱观测与多速度来源的条件互补融合。** 把RP、SDK速度、RV和RD实际约束与收益分清；新候选的价值是解除速度测量构造及更新调度对GNSS的依赖。
3. **来源质量、鲁棒性及失效机制的证据。** 以同骨架消融、真实接受次数、完整失败分母和中断/恢复过程支撑，保留SA代价与新数据负结果。这是系统与实验贡献，不能硬称第三个全新基础算法。

现有主方法没有自主整数模糊度固定，也没有正式接触/FK足式里程计。标准EKF、LAMBDA、误差传播和无滑移关系是继承知识。新颖性来自具体问题与实现及其证据，不能靠改名或给旧结果补未执行的公式获得。

## 横向证据如何组织

30个登记身份中18有执行链/条件/诊断，12未准入；选定链的15 PASS/3 PARTIAL不等于30篇完整复现。四类外部方法分别回答不同问题：接触估计看相对运动与gauge；raw双天线看候选/接受/支持及方向一致性；LC看解级融合；FGO同时看严格连续与分段初始化支持。内部四个单开关消融负责机制归因。不能把不同输入、点位或支持塞入统一精度排行榜。

[完整30身份](02_COMPARISON_REGISTRY.csv)、[241条可定位证据](02_COMPARISON_EVIDENCE.csv)、[11内部配置](02_INTERNAL_CONFIGS.csv)均保留来源行键。原V3 6468运行与后来的33/135诊断、严格/分段FGO、R5八段分开。NMB公里级漂移和XB八个NO_INIT组合是研究边界，不删掉换成有利故事。

## 最终决策：值得一周，先做速度独立与鲁棒性

完成12次科学运行、12次离线评价，并独立复算30行结果。另有2次读取输入前的配置拒绝，完整保留在执行账本中。新候选通过事先固定的研究继续门，但不应立即替代原V3。

以下基线是10月4日诊断版本M0；候选M2为独立RP和机体系SDK速度。正常条件统计全窗，故障条件只统计固定20秒失效段。单位为m：

|条件|基线H RMSE|候选H RMSE|基线V RMSE|候选V RMSE|
|---|---:|---:|---:|---:|
|正常|0.097560|0.099028|0.049001|0.049016|
|GNSS位置、速度、航向全失效|58.292571|0.836635|5.118368|7.126477|
|GNSS位置、速度失效，航向保留|0.702330|0.748108|7.151547|7.122955|

完全失效时水平RMSE降低98.56%，正常水平代价约1.47毫米；但完全失效时垂向RMSE增加39.23%，保留航向时水平RMSE增加6.52%。缺失GNSS记录与保留invalid记录的三模式NAV/STD逐字节相同；失效期间候选实际接受100次RP和100次body速度更新，证明新入口不再依赖GNSS消息。

这些证据来自一段BY2录制的一个固定20秒事件。M2仍是SDK速度代理和二维body约束，共享双天线初态，frame/物理点尚未独立标定；参考也共享GNSS来源。它支持投入研究，不支持跨场景优越性、完整足式里程计或新AR的主张。

下一周的明确优先级：

1. 闭合frame、物理点与时间语义，保留因果/过期/去重规则。
2. 将SDK速度与接触选择的足端运动学速度分开验证，处理坏脚、滑移及共享IMU相关性。
3. 先解释垂向漂移和D62代价，再用冻结参数扩展到BY2H/O与已有NMB/XB；无初态、发散和大误差都保留。
4. 按[七天计划](05_ONE_WEEK_PLAN.md)完成组件消融与独立复核，再决定是否建立新的论文主版本。完整模糊度固定研究另立阶段。

现有论文可以继续依照前三项贡献组织；若新版本成功，第二项将有更强的独立速度观测与缺测连续性证据，第三项可进一步形成来源质量和失效恢复方法。不能把这次候选效果追认到原6468次结果。
