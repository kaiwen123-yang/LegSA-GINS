## 作者最新决定

本轮仅讨论和有限试验：原 V3 成稿继续作为主线，GPS Solutions 与 IEEE TIM 均为主要目标。作者愿意花一到两天判断新整周模糊度是否有价值；有价值再推进，无明确收益则回到 V3，补必要证据。不承诺一周得到新算法，不让候选研究阻塞成稿。此前一周资格审查建议由本范围取代。

已授权：独立 sandbox 的算法诊断/小试；对新颖性的反证性一手文献检查；V3 可用的测量模型及验证设计；阶段 Git 提交和 GitHub 维护。所有算法代码写入、诊断、计算和测试均在 E 盘 Ubuntu-22.04 WSL，原始输入只读。Windows 仅用于发起 WSL、GitHub 工具调用或显示交付物。

## 两条可独立结束的产出

1. **候选 AR**：先核查标准原始载波链及已知整数合成条件，再判断先验失效处理的最小候选是否值得推进。真实输入窗口和参数在运行前冻结；前端资格失败时不以强先验、参考角度拟合或筛掉失败来追求固定率。不得声称 1–2 天小试已经形成完整 AR 方法或期刊创新。
2. **V3 / TIM 支撑**：把短基线航向被测量、误差传播、相关性及失效状态讲清，区分已有日志、假设下的数值验证和必须新增实测的量。标准雅可比推导不单独称新理论；闭环验证须有未用于拟合、具有已说明不确定度的检查量。

原 V3 稿件、生产源码、历史 6468 项结果、EXT/R5 和速度诊断均保持既有身份。当前基于双接收机已解算位置的航向不是本项目自己完成了载波整数固定。

## 本轮规则

- 原始载波试验沿用信号、half-cycle、tracking arc、星历及每接收机时刻的显式契约；不以两端绝对 FIX 作为 RAW AR 入门条件。
- 合成整数真值可检查代码与条件机制，不能代替实测相位模型资格。真实数据无整数标签时错误固定概率为 NA；与共享 GNSS 商业融合输出的比较只称一致性。
- 先验注入若只做简化候选枚举，必须明确搜索范围及模型；不冒称已实现 C-LAMBDA、FFRT 或严格完整性保证。
- 同输入支持、保留拒绝/失败与完整分母；所有实际试验尝试可追踪。根代理提交并推送阶段成果，子任务不操作 Git。
- 是否继续依据模型正确性、可信风险口径下的可用率/恢复收益、与最近似文献的实质差别，不依据“固定率更高”或重新命名贡献。
- 当前没有自动排程，也没有承诺在后台连续工作两天；本包记录本次已完成工作和有条件后续决定。

## 决策的解释

“保留 V3”是对论文进度的默认选择，不是对新颖性充分或录用的保证。“值得继续 AR”只代表下一项有限研究投入合理，不等于实测方法已成立。TIM 所需的测量方法、误差模型与验证可以逐项建设；推导通过和独立测量验证通过要分别记账。
