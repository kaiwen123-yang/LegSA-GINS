# 一项核心问题，而不是三个并列模块

日期：2026-10-06。本页是运行前的研究逻辑，不是已有算法贡献或录用预测。

## 1. 候选的取舍

| 候选 | 本轮处理 | 理由 |
|---|---|---|
| 完整足式速度解耦、再改 KF/FGO | 不作为本轮投入 | 已有独立试验有水平/垂向权衡；偏离当前航向主线 |
| 长度约束 + LAMBDA + IMU 姿态 | 只作标准基线能力 | 已有直接文献；尚须解释本项目真实载波链的失配 |

| 单基线可观测自由度内、考虑错误历史反馈的先验资格/整数验收 | 保留一个待否证问题 | 尚未证明新颖性或实际有效；必须能写出不同于既有 SSE/SS 切换的数学决策及代价 |

## 2. 一个必须讲清的集合关系

设在同一完整预定历元总体中，A 是无姿态先验的标准方法，B 是辅助先验方法，接受事件分别为 E_A、E_B，整数候选分别为 N_A、N_B。整数比较已变换到同一 signal/pivot 基底，真值为 N*。

若最简单候选 C 只在两者均接受且整数一致时输出：

\[
E_C=E_A\cap E_B\cap\{N_A=N_B\},\qquad N_C=N_A,
\]

则有

\[
\Pr(E_C,N_C\ne N^*)\le\Pr(E_A,N_A\ne N^*),
\]
\[
\Pr(E_C,N_C=N^*)\le\Pr(E_A,N_A=N^*).
\]

这是直接的事件包含关系，不依赖两解独立，也不是新的 AR 定理。它说明纯否决机制不能在同一分母下提高 A 的正确可用率。若实验中声称提高，须核查 C 是否实际含有额外接受/恢复分支、不同输入/时序、拒绝导致的后续递推历史变化，或分母被改变。

这里比较的是固定 A/B 候选轨迹；如果 C 的拒绝改变未来滤波状态，其内部 A 分支不能未经说明等同于另一条独立运行的 A。

同时不保证（条件概率仅在各自接受概率大于零时定义，零接受写 NA）

\[
\Pr(N_C\ne N^*\mid E_C)\le\Pr(N_A\ne N^*\mid E_A).
\]

例如在 100 个预定历元中，A 接受 90 个正确和 10 个错误解；C 恰好只保留 10 个错误解，则无条件错误接受比例仍为 10%，接受后的错误比例却从 10% 升到 100%。这是说明逻辑的反例，不是本项目实验数据。两条算法共用载波或错误历史，完全可能产生一致的错误候选；一致不等于独立确认。

因此本轮最小一致性候选仅用于检查“先验敏感性是否存在、拒绝付出什么代价”。不能由固定率下降推断真实风险达标，不能在无真值实测上给出正确固定率。若要主张更高可靠可用率，下一阶段必须定义新增接受路径，并与标准方法在可核查风险口径下比较。

## 3. 更值得形成的一页提案

**问题。** 0.35 m 级单基线平台中，绝对位置 RTK 状态与两天线相对相位可解性不完全相同；姿态辅助可能改善候选可分离性，也可能使错误候选显得自洽。本体倾角不能提供绝对 yaw，上一 GNSS 固定传播出的先验存在历史相关性。

**技术问题。** 能否只在几何上可观测的自由度内使用先验，并对错误先验和错误固定历史同时保留可判别的竞争解释，使新增接受路径具有清楚的适用条件？这是一项候选问题，尚不是已实现贡献。所提机制必须在数学上区别于已有惯性辅助、solution separation、integer aperture 和 false-fix recovery。

**最小前置验证。** 使用现有每接收机发射时刻后端；已知整数合成例检验符号、天线交换和 pivot 变换；少量事前固定 BY2/BY2O 原始历元检验长度约束标准解及仅倾角辅助解。两支路均不输入评价参考 yaw。合成检查正确候选/拒绝；实测仅报告残差、支持、候选稳定性等可观测项。

**继续的条件。** 标准测量链资格解释清楚；候选能在未调参条件下产生与最近似方法不同、可解释的接受/恢复行为；错误先验下的代价被计入，且有后续独立真实测量检查路径。只有这些成立，才值得投入更完整的风险—可用率/恢复试验。

**停止或暂缓的条件。** 真实标准链仍存在未解释的显著失配；候选仅等价于已知切换/调权；效果依赖共享参考校正、强 yaw 先验或删掉失败；仅有纯否决门却宣称更高正确可用率。此时回到 V3 成稿，保留本轮诊断作为内部研究记录，不能把技术修复包装为新 AR 理论。

## 4. 如果保留 V3，三项贡献如何组织

只建立“一项主问题 + 三层证据”的结构：

1. **测量对象与处理方法**：在紧凑足式平台上如何定义、获得和选择可用的短基线航向；清楚说明实际双位置解与接收机状态门。
2. **误差机制与适用条件**：解释水平投影、时间偏差、相关位置误差、倾角/安装和异常状态怎样限制测量；区分原 V3 实现与后续修正。
3. **测量及导航验证**：按实际支持、失效与恢复、共享参考边界展示已有结果；补独立方向检查与未用于拟合的验证，才能增强 TIM 的计量贡献。

这三层不是三项已经证实的新理论。若方法与近作只有工程组合差异，应在论文中诚实界定系统/应用贡献，并以新观察和可复用验证增强价值；不能用更强措辞替代缺失的技术差别。
