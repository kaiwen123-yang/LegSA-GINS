## 先补可验证的信息

下一实现仍可使用现有优化器，但须把 candidate available、source arc eligible、integer acceptance defined、measurement qualified 分开。不能把 native 字符串 fixed、全局最优或 A/B 一致直接转为可信 FIX。

最小接口记录原始 hashes、GPS week/tow、两接收机/信号身份、SD/DD方向、pivot与整变换、PR/CP/half-cycle/subHalfCyc/locktime/clock reset、弧ID/终止原因、候选整数/基线/完整残差及Q、RP时间/来源、拒绝原因、被测量定义与条件协方差。

## 1–2 天的有限里程碑

1. 固定 BY2 [80,82] s 做 raw 元数据审计，核 exact pairing、公共相位/半周有效信号、reset/transition/缺失及潜在稳定 pivot。并输出所有 constellation/signal 的同窗有效性数量。只读，不求解或读参考，不因不足扩窗。
2. 若没有足够连续信号，记录具体原因，不改时间戳或半周语义凑弧；先实现资格状态机与已知整数时序单元模型。若有支持，再冻结一个候选生成块/因果验证块分离的最小时间弧小试。可起草各5历元的两块，但实际长度须在科学执行前由输入支持登记。
3. 验证块到达后才能作延迟输出，时间戳为验证结束时刻；不能把未来检查伪装成第一历元的在线能力。固定/变 pivot 的整数变换、跨历元相关性、clock reset与相位弧终止先有测试。
4. 已知整数条件至少区分干净弧、RP偏置、非整周相位偏差、真正整数周跳（真值随 slip 更新）、缺失/重现。输入、seed和预算事前固定；不以单次成功或全拒绝声称解决错固定。

时间弧增加历元不等于增加独立证据。同弧多路径、SDK偏差和观测误差可相关；不能把重复确认当成已校准风险。阈值如需风险含义，要声明噪声/故障模型、校准集和独立验证集；不足则写风险未标定。新 scientific run 另冻合同，本文件不启动额外求解。

当前 GPS L1 isolated A 信息少，仅为机制基线，不是完整 V3或同信息 SOTA。正式比较前需补同星座/频点/时间弧信息的基准，不用削弱输入的巨大误差制造新方法收益。

## EKF 接入前提

先输出 shadow 资格记录，保留 V3。新 AR 不能更新 EKF 后又把该结果未声明地反馈为自己的先验。AR 使用 RP，而 EKF 已使用同一SDK RP/IMU时，两者相关；条件基线协方差不能直接当独立 yaw 方差。

需选择并验证明确方案：联合状态保留交叉协方差、分离独立信息源，或有依据的保守相关性处理。只手动放大噪声不等于解决重复信息。整数未决、迟到、弧终止、测量点/姿态投影、异常恢复须有明确状态机，不 hold 可能错固定的航向作有效新观测。

有意义的短期进展是可用弧资格、可审查接口，以及预定故障的检测/漏检/拒绝代价；不是只报可用率。若仍有不足，交付边界和需补测量，不阻塞 V3 成稿，也不要求作者逐项决定常规研发流程。
