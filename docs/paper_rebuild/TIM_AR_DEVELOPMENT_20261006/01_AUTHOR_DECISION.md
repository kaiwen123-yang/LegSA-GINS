# 本轮作者决策：TIM 成稿推进与载波相位路线

2026-10-06。本页由本轮授权和冻结试验结果更新；旧 V3 仍是论文性能主线。

## 已作出的决定

TIM 正文继续写，不等待新 AR 成功。正文加强“实际测的是什么、如何形成测量、误差如何传递、哪些状态可用、实测证据支持到哪里”。原 V3 的性能表保留身份，新公式/合成检查不能倒写成原 V3 已实现的物理误差补偿。

载波相位研究继续，但本轮 D 不升级为可信 FIX 或主文的新 AR 贡献。D 是标准截断二次先验惩罚的透明实现；20 次新 C-ILS 已完成，正确 RP 下保留 3 个有益整数纠正，错误 RP 下仍有 3/4 错误候选，相位异常下仍有 2/4。每组只有 4 例且共享噪声，不能称真实错误固定率。全局最优证书、长度正确、两支同整数，都不等于真实整数正确。

下一项值得推进的是候选的测量资格：连续原始相位信息能否提供额外的整数区分与异常检测证据。先审计一个固定短窗口的相位弧支持，不用参考误差挑选窗口；再决定是否值得实现跨历元验收。此方向也有已有方法，不能预设新颖性。

## 三项贡献怎样组织

| 成稿线索 | 本轮可写内容 | 不能跨过的边界 |
|---|---|---|
| 紧凑侧向双天线的航向测量定义与误差链 | 把基线投影角与 Euler yaw 分开，给出倾斜/横向误差/跨接收机相关性/时间误差的传播关系，并注明各源码版本实际使用的模型 | 推导已知几何关系不等于发明新测量原理；合成验证不等于设备标定 |
| 以航向可用性为条件的机器人辅助导航 | 原 V3 的姿态、水平、垂向及失效尾部证据；解释为什么本体速度收益依赖航向与使用条件 | 不将 SDK 速度写为独立接触/FK 足式里程计；不把所有状态称 FIX |
| 带支持与失败分母的验证方法和测量资格 | 同支持对照、原始数据/输出封存、第二日期的负面迁移证据、整数候选与可信接受的区别 | 不能将 6,468 个控制回放视为 6,468 个独立实测；共享 GNSS 的商业融合参考不是独立真值 |

这些是当前论文组织线索，不承诺三项都已达到独立方法创新。若新 AR 后续满足同信息机制对照、故障场景收益、测量资格和融合一致性，再以一项完整的方法贡献替换较弱的系统表述；不会为了凑三点把一个方法拆成三个“创新”。

## TIM 还需要什么

当前最有价值的缺口是短基线测量质量及可信接受证据，而不是再增加 EKF 名称或只优化正常 RMSE。物理安装尺寸/方向、时标残差、RP 与 GNSS 的相关性、真实错整数标签或独立方向参考仍未被本轮合成试验补齐。原始 V3 的工程工作噪声也不能改称测量不确定度。

本轮会提供完整 TIM R4 可编辑稿、逐条 claim–evidence 对照和探索补充材料。它是成稿推进稿，仍须完成图件与物理测量证据才能声称投稿准备完成。作者无需为本轮常规参数、Git 或试验去留再次作决定。
