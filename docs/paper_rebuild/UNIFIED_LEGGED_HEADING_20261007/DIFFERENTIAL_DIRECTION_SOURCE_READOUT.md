## 2. 本次计算的量，以及未计算的量

令 `b0=r_i0−r_j0`、`b1=r_i1−r_j1`，共同 body0 中的原三维差分为

```
f = D b1 − b0,          D = R0^T R1
A = [−I, I, D, −D],    W = A Sigma12 A^T
Hrel = −[D b1]x,       Jrel = Hrel^T W^−1 Hrel.
```

端点顺序为 `[r_i0,r_j0,r_i1,r_j1]`。一般 `Sigma12` 必须保留足间、时间间和共同／差分交叉块；本次只沿用原未标定工作模型 `Sigma12=(0.01 m)^2 I12`，所以 `W=4 sigma_p^2 I3`，不是两个端点的 `2 sigma_p^2 I`。逐区间直接矩阵传播与简式最大差为 5.97e−19 m²。

信息量是冻结线性化点和 W 的局部均值信息，非一般异方差分布的完整 Fisher 信息。沿 `D b1` 的转动不改变基线方向，J 的秩为 2。每条原三维残差、完整 J、三个特征值和 body0 弱轴均保存；不能将可观测轴标准差称为绝对 yaw 标准差。一般模型中的 W 可随 D 变动，协方差方向依赖不在此处伪装成第三个确定方向。

另外分别报告：

- 长度差 `||b1||−||b0||`、原长度资格与门限。长度不依赖 D，不能拿 gyro 使它“对齐”。
- 原 f 在 `u0=b0/||b0||` 上的径向分量和两个正交切向分量；径向投影不等同于有限转角下的长度差。
- 归一化方向 `q=D b1/||b1||−b0/||b0||` 的两维切向分量。单位向量导数使用 `(I−u u^T)/||b||`，四端点全映射传播；不添加沿基线的第三个旋转量。
- 原径向／切向联合协方差和归一化切向 2×2 协方差。长度资格、原 3D 残差与归一化残差是同一端点数据的不同读法，不作为独立因子相乘。

本次 D 只是在源内用原 IMU8 的 `Exp(dtheta)` 逐行右乘形成的条件线性化点。积分严格从 START 后第一行至 END 来源行，不取 END 后样本；沿用历史 Rx(−1°)、原 gyro 前缀均值去除和 foot identity 映射。没有使用 NAV 姿态、估计 bias、coning、地球或运输转动，因此它不是 native 完整两时刻 D，不能由残差直接认证或否决真实足方向。

真正接入同一状态时，D 应来自共同 `R0/R1`，足端测量噪声仍是端点 W；不能把本次 gyro 条件残差和原 IMU 又当两条独立证据反馈。

这只是弱轴几何关系。35 条后足 RR–RL 接近侧向，与天线弱轴几乎平行，不能为了突出“互补”而删除。没有给天线虚构一个噪声，不把两个 3×3 J 相加当最终信息。

两时刻规范分析见 [差分方向信息设计](DIFFERENTIAL_DIRECTION_INFORMATION_DESIGN.md)：R0 无绝对锚时，对 R0 消元得到的终点独立绝对增量为零。有真实独立起点锚 A 时才可计算 `Delta I1=J−J(A+J)^dagger J`，并在共同坐标中保留原交叉块。即使两个秩 2 的弱轴不平行，理想起点锚传递也一般只留下秩 1，不是终点满秩 3。已有 IMU/RP 先验应使用真实 joint prior，不能把 shared gyro 作为新独立先验重复加入。本读出不读取导航 prior；gap 没有当前 carrier 不等于 native 没有历史绝对先验，初始化、先前 PVT/RP/carrier 与 IMU cross 仍可能保留信息。

```
Qwhite = sum Dpre diag(arw^2) Dpre^T dt
Sconditional = W + Hrel Qwhite Hrel^T.
```
