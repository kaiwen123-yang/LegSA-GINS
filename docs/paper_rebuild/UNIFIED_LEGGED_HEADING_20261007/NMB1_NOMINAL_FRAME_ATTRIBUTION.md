# NMB1 名义 frame 两臂的效应归因

**撤销历史IMU −1°旋转没有减轻foot加入后的水平退化；XYZ垂向收益保留。** 这次输入改变确实改变roll与加速度偏置状态，但XYZ的水平轨迹几乎不变，NULL稍有改善，因此foot相对NULL的水平劣化增大。结果不支持将原退化归咎于该1°约定；也不证明原−1°物理安装假设正确，或新的rawbody名义轴已经实体标定。

这是root在既有NMB负例和活frame链审查后批准的唯一两臂诊断。legged完成2 native＋2冻结评价；本读出只读取已封存NAV/IMU_ERR/事件/误差表，没有额外native、evaluator、raw或reference载荷读取。新stage `SUPPORT_POSE_NOMINAL_FRAME_NMB1_01`；读出 `NMB1_NOMINAL_FRAME_READOUT_01`。

## 身份与完整分母

新两臂NULL／XYZ均使用固定 `0a69a7181eca853b5864793d09a7adb7d618f925eab1ba4b2ff4410f4dbdaa29`，显式body0_xyz，仅support_pose_mode不同。共同IMU输入把原增量逆乘Rx(−1°)，时间/dt与scalar不变；RP/SDK/foot/baseline/初始化/工作噪声/PVT-priority fallback均不变。本轮没有拟合角度、时间、尺度或依参考选择输入。

旧NULL是先前4f79 binary及默认XY NULL，旧XYZ是0a69 binary；NULL不消费足点因子，已有默认路径功能保留，但不能把新旧四臂称相同可执行文件字节的完整2×2。保持原工作噪声而非全协方差坐标运输，也意味着这是单一名义frame输入模型诊断，不是全概率模型的纯坐标等价试验。

四臂完整NAV与保存评价支持均80,272点；自然位置空窗 `[40749.60018873215,40912.600195646286)` 38,008点，约163s。新两臂均COMPLETED，online reference opens=0，耗时39.247/39.481s。四臂SDK全窗1182/1755、gap523/815实际接受相同；旧/新XYZ足END全窗476/481、gap242/242接受相同，NULL都不尝试足更新。新两臂PVT heading696/696与carrier12/12相同。**gap内无carrier点**，不能把本轮足点收益叫作载波航向填补。

## 状态已改变，但foot作用机制保留

frame旧→新在gap使NULL／XYZ roll均值分别改变−0.804147／−0.803706°，native ba_y均值分别改变+0.052171／+0.051658 m/s²。gap入口ba_y也已由旧约−0.026变为新约+0.053m/s²，两臂共同调整不是foot单独产生。gap中点NULL的vD从−1.320004变为−1.226538m/s，XYZ则从−0.016135变为−0.013354m/s。名义frame没有解除NULL垂向漂移，XYZ仍直接控制该漂移。这里ba是已保存软件body状态分量，不是新的物理IMU标定结果。

新旧XYZ的gap原生水平p差RMS仅18.711mm，而新旧NULL是278.915mm。对应评价杆臂几何变化分别4.459／4.465mm RMS，必须与原生状态差分开。新frame内foot相对NULL的gap原生水平p差RMS3.233850m，远大于杆臂0.331mm，说明foot实际作用仍在共同状态；这个“有作用”并不等于改善。

## 本轮可以决定什么

名义frame提供更直接可解释的共同body约定，并使实际roll/ba状态改变；它未达到“foot开始稳定改善水平导航”的目标。原历史1°不能作为此次foot退化的充分解释；也不能根据这次H结果反选原frame作为已标定真值。本轮就此停止，不增加第三臂或角度扫描。

下一研究应在明确的统一frame上处理foot端点与SDK速度的信息使用关系、阶段相关源差及依赖；不能继续期待纯坐标整理或yaw通道微调自动消除平移矛盾。源内forward不一致没有改变，本轮没有尺度/滤波/时间修正结论。脚本`nmb1_nominal_frame_readout.py`；配套六张`NMB1_NOMINAL_FRAME_*.csv`与scratch `READOUT.json`保存全部固定分层、状态点及事件分母。
