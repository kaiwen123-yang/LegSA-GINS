# 部分方向 GLS 的信息等价与下一问题

2026-10-07。针对“部分相位秩不足，是否被三维基线压缩补成虚假完整方向”这一假设，现有代码和 BY2O 原供给不支持该解释。不能仅把当前基线因子改写为同模型原始观测行就期待增益。真正需要检查的是物理方向域与共同姿态先验结合后，单次局部线性更新是否遗漏仍有权重的另一方向分量。

## 原供给实际保留了什么

`src/legsa_gins/paper_rebuild/carrier_phase/faults.py:273–325` 对固定共享整数做 GLS：依赖未知整数的观测行被撤下，码观测仍可保留；完整保留行协方差以 Cholesky 白化。函数允许秩亏结果用于诊断，但不把其伪逆宣称为满秩基线协方差。`continuous_arc_partial_quality.py:35–36` 要求总 baseline rank 为 3 且 nuisance dimension 为 3，才有资格输出当前 partial 供给。

原 BY2O ROLLING 的 117 条 partial 中，相位部分秩 1/2/3 分别有 68/44/5 条；码加保留相位的总秩全部为 3。不能把相位子集的低秩，当成实际送入后端的总测量噪声秩。

`continuous_arc_full_window.py:218–224` 直接输出自由 GLS 基线及其完整各向异性协方差，再加原有各向同性工作 floor。没有把基线投影到已知长度球面；其范数中位 0.484115 m、最大 1.389484 m，而物理基线长约 0.35 m。这些离球面的数值是观测似然中心，不是要直接当作最终机器人姿态。

## 压缩等价在哪些条件下成立

固定本次保留行、共享整数、观测几何和工作协方差。记扣除已知整数后的观测为 z，基线设计矩阵为 B，保留协方差为 Q，且 B 列满秩。定义：

    C = (Bᵀ Q⁻¹ B)⁻¹
    c = C Bᵀ Q⁻¹ z

则对任意基线 b，都有：

    (z − B b)ᵀ Q⁻¹ (z − B b)
      = J_min + (b − c)ᵀ C⁻¹ (b − c)

这里 J_min 与 b 无关。把共同状态的非线性基线 b(R,p) 代入，等式仍成立；它不只是在某个 yaw 上一阶成立。同一状态先验、同一 b 的 Jacobian 下，原行与压缩形式给出的测量信息矩阵、信息向量相同。足端已经进入共同状态的先验，不能在改写原始行时再独立重复加一次足端先验。

原工作 floor 为 F = I × (0.35 × radians(1.5))²。压缩协方差 C + F 对应原观测模型 Q_eff = Q + B F Bᵀ；仍可得到同一 c 与 C + F。若直接恢复原始 Q，则同时去掉了工作 floor，已经是另一个噪声模型，不能把收益归为“消除了压缩损失”。

本窗 floor 的单轴方差为 8.3960176e−5 m²。原最弱信息轴方差最小 0.062119 m²、中位 0.529693 m²。加入 floor 后，信息量比值 λ/(λ+f) 的强/中/弱轴中位分别为 0.396750/0.999523/0.999842。它降低信息，主要影响强轴；它没有给原相位空方向制造精确信息。本次没有移除或调小该 floor。

当前三维创新的噪声满秩，3DOF NIS 不应仅因相位子集秩低或姿态 Jacobian 秩为 2 而直接换成 1DOF/2DOF。若要改变检验对象，应另行推导统计量，不能由几何自由度直接替换现有门限。

这些等价关系以固定保留行、整数假设及 Q 为条件，不证明整数一定正确，不证明原始所有观测都已保留，也不证明同源 GNSS 与先验独立。故障资格、依赖撤销和残差质量判断仍有各自作用。

## 有意义的下一问题

117 条供给中有 41 条的保存物理方向域包含两个分量。这里是同一基线 GLS 椭球与物理长度/重力约束相交后的多个方向区域，不是把两个整数候选姿态平均成一个 c。直接保留 c、C 不会仅因域分成两段就丢失上述条件似然。

局部 EKF 的高斯状态近似仍可能有问题，但“两个物理分量”不等于“两个显著后验模态”。应先检查实际载波更新前共同姿态先验的均值、完整协方差、扰动坐标与事件时序，及分量角度坐标定义；确定第二分量是否仍有非忽略权重。不能用更新后状态、仅 yaw 标准差或参考轨迹代替 prior。若保存数据不足，下一次最小诊断应只补缺少的真实 prior 记录，再决定是否需要改变更新方式。

当前不重写原始因子，不删码观测，不缩小协方差，也不直接增加多分支后端。该结论用于把下一步定位到实际近似损失，而非仅改变等价表示。
