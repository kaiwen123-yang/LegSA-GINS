# NMB1 SDK 共同状态差异：匹配结果与实际信息传递

本轮常量二维修正状态 **未缓解足点造成的水平退化**。joint 模型全窗 NULL→XYZ 的 H RMSE 为 4.159070→6.204042 m，163 s 空窗为 4.654693→8.334093 m；对应足点水平惩罚比 off 模型增大。Up 收益保留。真实日志证明 foot→b、SDK→共同 p/v/R 均已发生，失败不能解释成“状态没有接上”。这轮是结果指导的模型试点，不能宣称可信航向稳定改善导航已经达成。

## 比较合同与完整结果

全窗足点 H 惩罚由 off 的 +1.373585 m 变为 joint 的 +2.044973 m；gap 由 +2.440274 m 变为 +3.679400 m，描述性差中差分别 +0.671388/+1.239126 m。gap 中 NULL 自身从 5.550483 降到 4.654693 m，而 XYZ 从 7.990758 升到 8.334093 m。不能把这种 RMSE 交互写成可加的物理因果分解，也不能只看 NULL 改善就判定统一算法成功。恢复至首载波的 joint NULL H99 还从 off 的 25.769598 增至 27.942409 m；尾段 H 几乎相同，不支持持续净收益。

进入 gap 前，两臂已在有位置/速度等锚信息的阶段形成约 −0.0216 m/s 的前向差异估计，σ 由 seed 的 0.2232 缩至约 0.0092 m/s。XYZ 的 b_forward 在空窗持续跨过零，出口达到 +0.01924；NULL 则约保持 −0.02131。因此 b 没有被锁死，也不是仅记录一条静态曲线。Pbb 缩小是给定常量模型和工作独立假设的条件信息积累，不能据此宣称校准正确或剩余误差可信。

严格空窗内部，XYZ 的 b_forward 增加 **+0.040811856 m/s**，同轨迹事件账本中 SDK 累计 +0.040081694、foot 直接累计 +0.000730162；b_right 的 foot 累计 +0.020582466，SDK 累计 −0.013108052。242 个 foot 更新全部真实改变 b。523 个 SDK 中 89.10% 上调 b_forward；NULL 的 SDK 前向累计仅 +0.000443799。这些是同一已运行轨迹的条件均值增量账本，不是移除一个来源之后的反事实分解。

恢复至首载波这一固定段，GNSS position 又通过 cross 将 XYZ b_forward 累计拉回 −0.015055537 m/s；首载波后相同来源还累计 −0.002105648。最终 b_forward=+0.009785 因而混合了多个锚信息阶段，**不能直接和源内 7 mm/0.1 s 的平均差相减来判“还没估够”**。

NIS 较小与水平误差较大同时出现，不能把当前门控接受当成可信导航净收益。foot NIS 在 gap 也几乎不变：off 中位/P95=0.684391/2.092588，joint=0.675278/2.137800，全 242 次接受。现有证据支持“持续未知绝对差异可以共同估计，但常量二维修正不足以消除运动与支撑条件下的相互作用”；尚不能指认某个来源为真或据此挑选新 Q、尺度或噪声。来源内既有运动/支撑相位差异仍需与下一模型的可辨识性一起处理。

## 实际 foot→b→后续共同状态作用

以下均为测量条件误差均值变化映射到 feedback 切空间、reset 前的**单次中位数**；不是保存 NAV 的精确瞬时跳变。δφ 是 NED 左旋转向量范数，不是 Euler 角差。

| gap 因子 | 次数 | norm δb m/s | norm δp_H m | norm δv_H m/s | norm δφ ° |
|---|---:|---:|---:|---:|---:|
| JOINT_NULL / BODY_HORIZONTAL_VELOCITY | 523 | 0.00000624 | 0.04913037 | 0.05640074 | 0.00612664 |
| JOINT_XYZ / BODY_HORIZONTAL_VELOCITY | 523 | 0.00009181 | 0.01316159 | 0.03299123 | 0.00385408 |
| JOINT_XYZ / FOOT_UPDATE | 242 | 0.00011021 | 0.03073822 | 0.05862395 | 0.00687218 |

用每个 SDK 消费时刻对齐此前最后一次 SDK 之后的 foot，gap 中有 **195 个唯一后续 SDK 更新**；它们的 δp_H/δv_H/δφ 中位数为 **0.008174 m / 0.022639 m/s / 0.002722°**，距最后 foot 的时间中位数 **0.097999 s**。其中 194 组没有夹入其他 ordinary 测量，仍包含惯性传播，不能将这些 SDK 增量独立归因于 b 这一个通道。该表按 SDK 时刻归段，关联到 243 次 preceding foot（含 1 次 gap 前 foot）；实际 gap foot 分母仍是 242。完整全窗 382 组覆盖 474 次 foot，末尾 2 次 foot 没有后续 SDK，未伪造配对。

这轮新增的是可检查的共同状态事实：foot 无直接 b 测量列，却通过 cross 改变 b；随后 SDK 的含 b 条件创新与完整 joint 协方差改变共同 p/v/R。它没有证明 SDK 时变信息的独立净收益，因为两臂都保留 SDK；也没有证明 carrier 航向通过它获得稳定导航收益。当前常量模型收益门未通过，生产代码、参数和本轮结果冻结，不追加 native、噪声扫描或新对照。
