# NMB1 同区间足端／SDK 速度的有符号一致性读出

2026-10-07；当前研究 HEAD 352843e 基础上的新诊断。只读已保存足端 provider、SDK provider 和 motion cache；本脚本 raw/NAV/reference/native 读取／调用均为 0，不拟合参数、不重选支撑足、不增加拒绝门。

**主结果：空窗 242 个支撑区间中，足端推得的共同前向位移比 SDK 速度积分平均少 7.260 mm；98.35% 的区间同为负号。它是持续、两足共有的来源冲突，量级足以成为米级水平分歧的候选机制；它不能证明 SDK 或足端哪一个正确，也不能单独认证真滑移。**

**仅实际 END 覆盖区间就有 1.226 m 的固定方向水平累计冲突，且等效前向差速约 0.071 m/s，因此它在量级上足以解释“共同状态可能出现米级分歧”。** 这不等于证明 native 位置差的确定比例：间歇更新、SDK 竞争、姿态／bias 交叉协方差和未观测区间决定实际滤波响应。没有将 0.071 m/s 外推整个 163 s 或拿它拟合导航结果。

## 5. 科学边界与下一接续

这个读出直接证实的是 **支撑足端静止模型推得的位移与 SDK 速度积分持续不一致**。真实共同滑移、SDK 速度自身偏差／滤波延迟、足点运动学比例／柔性、足点与速度参考原点及时间关系都可能贡献共同项。两只足同向并不能把这些原因分离；SDK 与足坐标也来自同一设备，不能互相充当独立真值。

因此不能从当前 c_i 阈值造滑移标签或撤销已用足因子，也不能据此缩放 SDK、重标定支撑噪声或按足对删除。原长度差分几何检查对共同平移不敏感；零 REVOKE 与本次持续共同冲突并不矛盾。

当前可反驳线索已具体化：主偏差在两对足和所有时段持续同号、速度关联强于转角大小、两足前向同号且SDK/foot运动高度正相关。这反对简单轴翻转、单足异常及纯大转弯解释；更支持优先检查共同来源模型与消费关联。若选择后续同支撑 episode 的单一来源消费实验，需承认它改变重复／相关信息使用，并不会自动解决本次物理均值冲突。真实可撤销证据仍需能够区分模型冲突与单源失效的独立约束。
