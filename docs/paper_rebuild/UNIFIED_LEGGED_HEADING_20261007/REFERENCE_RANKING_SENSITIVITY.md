# 参考位置误差会不会改变方法排名：固定输出的条件敏感性

2026-10-07。读取四臂已保存的同 80,272 历元误差序列，逐文件 SHA 与 SDK joint 上一读出一致。没有运行 native/evaluator，没有打开 raw 或 reference payload，没有生成替代真值、修正轨迹或删点。

## 计算对象与条件

令同一固定 NEU 坐标、同一原时间及物理点假设下，两臂相对旧参考 r 的误差为 eA=a−r、eB=b−r，d=eA−eB=a−b；假设真参考与旧参考的共同位置差为 u=x−r。均方误差差 D=mean(||eA||²−||eB||²)，则

```text
D_true = D − 2 mean(d dot u)
RMS(u) ≤ B  =>  |D_true − D| ≤ 2 RMS(d) B
B_tie = |D| / (2 RMS(d))
```

任意时变 u 中，B_tie 是让两臂最早可能并列的 RMS 下限；这是 Cauchy–Schwarz 的紧界。在 B<B_tie 的条件下排名不变。达到阈值仅说明存在最不利方向，不说明实际参考偏移具有那个时间形状、方向或概率。本读出只计算标量阈值，没有构造该轨迹。各行的最坏方向分别求解，不能断言一条实际轨迹同时实现全部窗口/分量/方法对的最坏排名；严格反转需要越过并列阈值。

若另作受限假设 u=c 恒定，则最小常量位移模为 |D|/(2||mean(d)||)。这与任意时变界分列，不把恒定偏置当真实误差模型。若方法输出完全相同，则无参考位移可打破两者的并列；本次四对均非退化。

本计算固定原 evaluator 的 ECEF 插值和 NEU 投影轴、原采样权重、时间对应与安装/杆臂变换，只考察共同 additive reference position shift。不能据它认证时钟或物理比较点，也不覆盖改动算法输出杆臂后两臂各自不同的变换。没有独立历元假设、不除以 sqrt(N)、不从 RMSE 平方扣参考方差。航向 circular/安装/姿态协方差问题不在此标量位置公式中。

## 与参考自身报告不确定度怎样并列

参考源内审计得到 gap 水平合成 sigma 的 RMS=2.030940 m、Up=0.825005 m；FULL 为1.623396/0.644975 m。这些来自10 Hz唯一测量历元，当前敏感性来自既有导航输出历元，采样权重也不同。厂商 sigma 是内部边际模型量级，未校准到独立实际误差，更不是硬上界 B。故不能自动代入上述界宣布排名已被保证。

这些量级及恢复时4.070662 m自身修正，证实有必要限制真值措辞，却没有证明参考实际误差达到4.84 m RMS并且沿最不利方向。单次4.07 m位置跳变既不是整段RMS误差，也不能和B_tie直接等同。结论仍是：现有参考相对排名保留；真实绝对排名待资格确认；不能因参考可能有错反向宣布足端模型已经正确，也不再只凭未经认证的排名继续增添状态或拟合参数。
