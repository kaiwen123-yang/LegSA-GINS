# 两足差分方向信息：共同两时刻状态、锚传递与使用边界

2026-10-07；基于 HEAD `6bf84b5`。本文件是精确数学设计与现有实现只读审查，不改变 C++、输入、资格规则或已有 XYZ/SDK 试验。源内 481 个 END / gap 242 个 END 的实际量级由 `direction_audit` 单独读取；本文件不以参考轨迹选择方向或宣告新因子收益。

**结论先行：** 单条有序足对差分提供两维相对旋转均值信息，弱轴为足对方向；未知起点姿态完全消元后，它没有独立终点绝对方向信息。有真实、独立的起点载波方向锚时，必须在同一 `(R0,R1)` 中 Schur 消元：两个非平行弱轴的 rank-2 信息通常只传递 rank-1 终点信息，不能由“两个 3×3 矩阵之和满秩”宣称终点三维互补。真实部分载波的多候选似然必须保留，不能替成任意 yaw σ。

## 1. 变量、来源与残差

`R0,R1∈SO(3)` 将同一约定下的 body 向量转到**同一个固定世界系**，`D=R0ᵀR1`。实现中可用 ECEF；不能把两个位置处的 NED 分量未经运输直接视为同一坐标。足序固定为同一对 token 的 `i,j`，令

```
b0 = r_i0 − r_j0,      b1 = r_i1 − r_j1,
f(R0,R1) = D b1 − b0.                       (1)
```

它是现有两足残差 `e_i−e_j`。共同 `p1−p0`、共同 body-origin/IMU 杆臂，以及两足完全相同的接触位移均消失。并未因此证明两足没有相对移动、足序错误或 SDK 相对误差；接触 token 只维持来源和因果生命周期。

不能把已有完整 XYZ 两足因子和由同一端点生成的 `f` 当独立观测同时消费。若后续选择仅方向因子，它替代该部分原始似然；直接共同 XYZ 平移信息，包括原有效的共同 Z，均不再存在。姿态经 full cross 影响 p/v 是另一回事。

## 2. 全端点协方差与差分似然

端点向量及其完整协方差为

```
z = [r_i0; r_j0; r_i1; r_j1] ∈ R^12,
Σ12 = Cov(z),                         含足间、时间间所有交叉块
M(D) = [−I, +I, D, −D],
W(D) = M Σ12 Mᵀ.                                      (2)
```

令 `C=Cov([b0;b1])=[[C00,C01],[C10,C11]]`，则同一式为

```
W = C00 + D C11 Dᵀ − C01 Dᵀ − D C10.                  (3)
```

例如 `C01=Σ_i0,i1−Σ_i0,j1−Σ_j0,i1+Σ_j0,j1`。重用端点、交叠支撑弧或共享 SDK 状态时，这些交叉项不能因换成“方向观测”自动消失。

冻结的独立、各向同性四端点工作假设为 `Σ12=σp² I12, σp=.01 m`，此时

```
C00=C11=2σp² I, C01=0, W=4σp² I.                     (4)
```

因此每个残差分量的 σ 为 `2σp=.02 m`，不是 `sqrt(2)σp`。这里“独立”是尚未标定的工作模型，不是 SDK 内部独立来源证明。

若从 `c=(e_i+e_j)/2, f=e_i−e_j` 出发，把共同三维位移作为无先验 nuisance 积分/消元，保留的是 `f` 的**边缘协方差** `W`。不能丢弃 c 的均值后又使用 `Cov(f|c)`，那会暗中保留被撤销的共同信息。若 c 与 f 同时保留，则必须使用完整联合块，不能独立重复消费。

## 3. Jacobian、秩及径向资格

以下 `η0,η1` 是实际旋转的世界系左扰动：`Rk'=Exp([ηk]×)Rk`。设 `a1=R1 b1`、`G=R0ᵀ[a1]×`，由 (1) 得

```
δf = G η0 − G η1,
Hphysical = [G, −G].                                  (5)
```

或在相对 body0 左扰动 `D'=Exp([δθ]×)D` 下，`Hrel=−[D b1]×`。对于非零 b1 与正定 W，冻结线性化点的**局部均值信息**

```
Jrel = Hrelᵀ W⁻¹ Hrel
```

秩为 2，弱轴为 `D b1`；共同世界系的信息 `J=GᵀW⁻¹G=R0 Jrel R0ᵀ`，弱轴为 `a1`。两维非零特征值可能不同，不能以一个 yaw σ 概括。

以上 J 将 W 在当前线性化点冻结。一般非对角 Σ12 可使 W 随 D 改变；这里**没有**声称它是任意异方差模型包含协方差导数项的精确 Fisher 信息，也不从未经标定的噪声椭球旋转中虚构第三条物理方向约束。当前 (4) 下 W 与 D 无关，均值信息的秩结论没有这个额外问题。

保留足对长度失配 `ℓ1−ℓ0` 与两维切向方向读出；沿基线的残差可用于现有几何资格，但不是第三条旋转约束。若归一化为 `uk=bk/ℓk`，则

```
Nk = (I−uk ukᵀ)/ℓk,
fu = D u1−u0,       Au=[−N0, D N1],
Wu = Au C Auᵀ.
```

在选定局部切平面 T 中使用 `Tᵀfu, TᵀWuT`；长度差的 Jacobian 是 `[−u0ᵀ,u1ᵀ]`，它与方向的噪声交叉块也必须保留。不能先用同一长度证据选中过门，再把它当独立新证据乘第二次。切向投影是局部 chart，不是全局方向等价：有序两足的反向/大角度不应被投影为零；源内表应同时保存原始三维残差、夹角及长度，不重新交换足或翻转符号。

现有长度差 `.080662844 m` 等工作资格不在本轮重新调门。其无异常不能认证无相对滑移。

## 5. 未锚定起点消元：绝对方向增量为零

把 (5) 的信息写在同一 `(η0,η1)` 上：

```
Λfoot = [ J  −J
         −J   J ].                                    (8)
```

公共旋转 `(η0,η1)=(g,g)` 位于零空间，且相对足轴也有弱方向。没有关于 R0 的独立锚或其他先验时，消去 η0 得

```
I1,foot = J − J J† J = 0.                              (9)
```

这不是小角线性化的偶然结果。令 `Lf(R0ᵀR1)` 是足因子完整似然，在 R0 上取无信息 Haar 测度，则

```
L1(R1) = ∫SO(3) Lf(R0ᵀR1) dR0 = 常量.                (10)
```

因此足方向不能独立创造绝对 heading。若只有 END 的独立载波信息 B、而 R0 完全未知，则消元后仍只有 B，新增 foot 绝对信息为 0；不能把同一个 END carrier 倒填为 START 锚。

“此区间没有新的 carrier 点”也不等于真实导航“没有任何绝对历史先验”：初始化、既有 PVT/RP/carrier 和 IMU cross 可能保留信息。源内读出不读取完整导航 prior，故只能报告 (9) 这一无锚条件，不应擅自把真实滤波器 prior 设为零。

## 6. 独立真实起点 carrier 锚：必须 Schur 传递

若 START 存在已由实际载波似然得到的独立局部姿态信息 A，且与足观测条件噪声独立，联合块为

```
Λ = [ A+J   −J
       −J    J ],
T(A,J) = J − J(A+J)†J.                                (11)
```

T 是消去未知 START 后，传给 END 的局部均值信息。半正定奇异情形用有相容 range 的广义 Schur/白化 QR 消元；不能通过补一个任意小对角来制造锚。

```
0 ⪯ T ⪯ J,   T ⪯ A,
ker T = ker A + ker J,
range T = range A ∩ range J.                           (12)
```

这里 A、J 都已在相同世界左旋转坐标中表示。量级与弱轴必须经过坐标运输后比较，不能仅相加两个 body-frame 3×3 数表。

- A=0：T=0。
- START 姿态确定（A 沿所有方向趋于无穷）：T→J，最多 rank 2。
- A 正定：T 通常 rank 2；等价于先消去起点不确定性后的方向信息。
- 单条完整 carrier 基线锚常见的均值信息 A 为 rank 2，弱轴 u；foot J 弱轴 w。若 u、w 不平行，则 A+J 虽满秩，**T 只有 rank 1**，信息方向沿 `u×w`。若弱轴平行，T 为 rank 2。
- 若实际某一 partial 分支只有 rank-1 A，其信息方向与 `range J` 有交集时才可传递；一般偏离该平面时，R0 的剩余自由度可吸收它，T 为零。不能给未观测方向补任意 yaw/tilt σ 来“恢复”交集。

例如两条近水平但不平行的足/天线弱轴，交叉方向可接近当地竖直，说明潜在的一个 heading 传递分量；这仍需实际 START 锚、足方向资格和坐标/噪声量级，不能从 body0 z 几何单独认证绝对 yaw。

若 END 还有独立 carrier 信息 B，则终点信息是 `B+T(A,J)`。是否补充 END 的弱方向，应考察 T 在 `ker B` 的作用，而不是 A+J 的秩。START/END carrier 共用整周候选、相位噪声或弧状态时，独立块假设不成立，必须把它们放入实际联合似然；不能把同一 carrier 弧的两条输出当两份独立锚。

## 7. 真实共同导航 prior 与部分候选域

已有同一状态 prior 的信息为 `Π=[[Π00,Π01],[Π10,Π11]]`，其中包含已经消费的 IMU、RP、carrier 等来源及 cross。固定线性化点，定义

```
Schur1(Λ) = Λ11−Λ10 Λ00† Λ01,
ΔI1 = Schur1(Π+Λfoot) − Schur1(Π).                    (13)
```

精度矩阵不能代替残差与均值。若联合局部因子的 canonical 形式为 exp(−ηᵀΛη/2+qᵀη)，消元还须保留 q1,eff=q1−Λ10Λ00†q0；候选似然权重还包含该分支的积分归一化和残差代价，不能仅凭 Schur 特征值给候选重新赋权。

若新独立 START carrier A 尚未消费，则在两项中都先加入其正确块，再计算 foot 的条件增量。若另有 v/p/bias/SDK b 等 nuisance，先在同一完整因子系统中一致保留/消元；不能把三维姿态的单独边缘方差反求一张虚假的独立 prior。START 的确定性 clone 可能使协方差奇异，白化因子空间消元比人为正则化更符合原来源信息。

(13) 允许足端相对姿态信息通过已有 cross 改变当前 p/v，但它是**给定整个共同 prior 的条件增量**。不能把其中已有 gyro/RP 信息再归给 foot，也不能从信息秩直接推导导航 RMSE 收益。

对真实 partial carrier，设可接受候选及权重的似然为 `Lc(R0)=Σk πk Lc,k(R0)`，则严格的传递对象为

```
L1(R1) = ∫ Lf(R0ᵀR1) Lc(R0) dR0
       = Σk πk ∫ Lf(R0ᵀR1) Lc,k(R0) dR0.             (14)
```

只有在单个已限定分支内部、局部近似合适时，才能用该分支实际信息 Ak 代入 (11)。分支均值、跨模态间隔、整数/方向候选身份和质量域都必须保留；一个平均 yaw 加任意 σ 不等价于 (14)。足因子可重分配候选权重，但必须记录它真正改变了哪些候选。若该 carrier 候选先前已用过同一足证据，不能再乘一次 Lf。

本源内读出允许保存实际足 J、弱轴/谱、原天线 `[0,−.35,0]` 的几何弱轴夹角及“无锚/有真实锚”的条件标签；若没有实际 START carrier 似然或完整 prior，就只报告潜在几何，不能填造 A、计算所谓实测绝对航向收益。

## 8. 同源 gyro、工作 frame 与撤销

在线因子的 D 来自共同两时刻状态，不是先用 gyro 预旋转端点后生成一条“独立测得的姿态”。源内读出可用既定 IMU8 的因果增量构造 Dhat 作为条件线性化点，必须同时说明：

1. 它使用原均值去除、历史 Rx(−1°) 的 IMU 增量；足点依然沿原 raw-FRD/identity 工作合同。本轮不把未知安装物理解释称为已标定，也不为改善残差改变 frame。
2. 逐增量右乘 Exp 的读出不是 native 全部 mechanization；未复刻 coning、地球/运输项及在线 bias，因此其残差不是完整 native prefit，更不是足方向真值。
3. ARW 的白噪声 Qθ 只是一个可算项，原 gyro 均值去除会引入时间间共同误差，bias、时间映射及 SDK 足点内部 IMU 依赖尚未完整标定。

可列 `Swhite=W+Hrel Qθ Hrelᵀ` 作为同源条件读出的白噪声敏感性，不得把它作为新独立 foot+gyro 似然再次喂入已经使用这些 IMU 的状态。对线性残差 `r=H δx+n`，若 `N=Cov(δx,n)`，真实条件创新应含

```
S=H P Hᵀ+W+H N+NᵀHᵀ,
K=(P Hᵀ+N) S⁻¹.                                      (15)
```

现资料不能把 N 认证为零；采用 N=0 必须保留其工作模型标签。也不能用不可得 cross 做“防御性”虚拟大噪声替代资格判断。

各向同性冻结工作模型下可直接比较足差分角度 σ 量级 `2σp/||b||` 与 `ARW sqrt(Δt)`。这只是 endpoint-only 与 gyro-white-only 的相对均值信息尺度，遗漏 bias/共同来源误差；即使前者弱几个数量级，也不能据此证明长期无作用，反之也不能预告有收益。
