# NMB1 全支撑弧对照：100 ms 相位取样不是主冲突的充分解释

2026-10-07。唯一追加假设检验：去掉 GNSS 5 Hz 机会及固定约 100 ms 截取，比较原规则下完整连续双 token 弧与同弧首段。**完整弧仍有约 6% 的前向差，拒绝“约 7.5% 主要由固定机会／100 ms 相位采样造成，延长弧即可解决”的解释。** 阶段取样确实放大差异，但没有消除持续来源冲突。

## 有符号读出

模型仍为 gyro 因果左 ZOH 的 `common=(r_i0−D01 r_i1+r_j0−D01 r_j1)/2−integral(D0t v_sdk dt)`，零杆臂工作假设不变。差速是 sum(common_x)/sum(dt)，比例是 −sum(common_x)/sum(SDK 前向积分)，均为描述值，不是拟合补偿。

## 科学接续

1. 相位采样能放大共同偏差；不能把首段结果外推为整个支撑期恒定运动。
2. 完整弧负差仍持续，不能以“换成全弧”作为已证实的修复，也不能按阶段阈值删掉不利数据。
3. 本试验只比较同源 foot 与 SDK velocity；不能判定哪侧是真值。结合已有 foot≈SDK position、foot_speed 与足点导数的阶段差，优先解释为待辨识的来源／模型不一致；不能据此命名真实滑移或认证某个常量 bias。
4. 这个否定结论不改变足端三维支撑约束的物理定义，也不引入 q 字段作为独立新观测。下一模型应明确它解释的共同误差来源和可辨识性，而不是让偏置状态吸收所有差异。
