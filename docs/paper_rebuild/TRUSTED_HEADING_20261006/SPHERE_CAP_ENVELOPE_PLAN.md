## 整连续域的解析外包

每类已有固定整数后中心 c、协方差 C 和预算 rho = tau_expanded − S。原条件实值域为 E = {b : (b−c)^T C⁻¹(b−c) ≤ rho}。rho < 0 对应原成本域为空。以下同时外包 E 与长度球面的整个交集，不只投影中心、球面最优点或 top 2。

### 水平投影椭圆

P 为当前明确的两个正交单位水平轴。E 的水平投影恰为中心 h = Pc、协方差 C2 = PCP^T、预算 rho 的椭圆。令 A = chol(C2)，u = A⁻¹h，n² = u^T u。若 n² ≤ rho，椭圆包括水平原点，方向全圆。否则 a = rho/n²，在白化坐标内切点为

`t± = (1−a)u ± sqrt(a(1−a)) J u`，其中 J 将二维向量旋转 90°。

把 A t± 的两个方向取包含 h 方向的窄弧，就是精确椭圆的方向覆盖。它使用水平完整协方差的各向异性，通常比原最大特征值圆盘紧，但不承诺每类有改进。代码另显式外扩浮点误差：白化半径增加 epsilon/sqrt(lambda_min(C2))，不得将负或非有限特征值截成零。

### 长度球面与三维外球

以 r ≥ sqrt(rho lambda_max(C)) 外包 E；保留原已存外球半径且另有明确向外数值 guard。记 s=||c||、u=c/s。对 ||b||=L，外球条件蕴含

`u · (b/L) ≥ k(L) = (L² + s² − r²)/(2Ls)`。

这是球面 cap 必要域。s 近零时只允许保守全圆或径向严格分离后的空域。向外降低 k 后若仍 k>1 才可判数值必要域空；k≤−1 为整球。若 k≤|u_vertical|，cap 包括某个竖直极点，azimuth 全圆；不能在极点给虚假的窄航向。

否则 k>|u_vertical|≥0、p=||Pu||>0，围绕 atan2((Pu)_E,(Pu)_N) 的方向半宽为

`asin(sqrt((1−k)(1+k)) / p)`。

理由是固定 azimuth 偏差 δ 后，在同半球最大化仰角得到最大内积 sqrt(p² cos²δ + u_vertical²)；反半球只能逼近极点上界，当前 k 已排除它。边界误差只向外扩，近相切不能按 roundoff 丢弃。

仅就未启用的区间接口，k(L) 的最小值在区间端点或区间内 L*=sqrt(s²−r²)（须 s²>r²）处达到，覆盖整 shell 用该最小值。错误的精确长度仍可能排除物理真值；测试显式保留此反例，不能由数值内核验证实际长度先验。

### 圆周交集与语义

相交水平椭圆覆盖、球 cap 覆盖和旧有效覆盖，所有连通分量均保留。跨 ±pi 的区间拆分后求交，不只保留一支。小于角 guard 的近相切缝隙保留小区间，不宣称严格空；必要时用外包圆弧另报告 hull。`total width` 与 `hull width` 分开，不能把仅保留多个组件造成的 gap 变化全归因于更好的观测。

得到非空只说明**必要条件未排除**，没有证明精确椭球与球面存在共同点；得到空是 guarded floating-point 模型下必要域分离，不是区间算术证明，更不是物理周跳真值。
