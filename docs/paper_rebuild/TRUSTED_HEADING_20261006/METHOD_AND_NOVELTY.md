# 持续可信航向：方法主线、信息增益与新颖性边界

状态：**科学设计与获授权的局部数学内核；新贡献尚未验证**。科学审查以研究分支 `856923d` 为入口；随后阶段 A 单独授权实现第 8 节内核及物理单元测试。本轮没有整数搜索、原始实测处理或导航；原 V3/main、原始数据、论文正文不变。R6 的停止结论仍有效，见 [DECISION_AND_LIMITS](../AR_V3_RESEARCH_20261006/DECISION_AND_LIMITS.md)。这里不以新名称重新宣布失败支线成功。

## 1. 决策：一条主线，两条备用

**主线：以完整载波候选支持为底座，形成可撤销有向本体资格下的航向集合；在物理整数弧变化时保持合法信息，按实际可用时刻恢复输出。** 第一落点应复用现有球面候选器和安全整数下界，不立即开发新的大规模运动耦合整数求解器。

真正要回答的问题是：**即使整数身份尚不唯一，所有在声明的观测/先验误差模型下仍可能成立的状态是否已指向足够集中的航向；若支撑、转动先验或载波弧失效，如何撤销不再成立的推断？** 这与“选一个整数并维持它”不同，但集合估计、完整性监测、有向姿态辅助和恢复本身都有前作，组合也尚不能认定首创。

| 路线 | 能增加什么 | 失败边界与优先级 |
|---|---|---|
| 主线：完整方向集合 + 有向重力/相对转动资格 + 可撤销先验 | 有向信息可以排除 Gram 保留的反射；方向集合可能在 N 不唯一时仍可用；明确未搜索尾部与连续基线域 | 重力不合格、转向量接近零、搜索不完整时不能宣称可信；优先做解析反例与小规模资格 |
| 备用 1：存活 SD 弧的整数差图输运 | 避免纯 pivot 消失丢掉仍合法的差分信息，改善连续性，无需新传感信息 | 是条件于原候选的精确坐标维护；不修复错整数/非整周偏差，单独作为 AR 理论创新偏弱；工程优先 |
| 备用 2：充分三维激励下共同 SO(3) 的手性资格 | 三条线性独立基线方向可以区分保留全部 Gram 的镜像，不必假定初始 yaw 已知 | 必须有真正三维方向激励；近共面病态、共同 gyro 错误、内层求解代价；只作为主线重力不合格时的后备设计 |

三项贡献可暂按职责分开，避免第一项和第三项重复：

1. **测量层候选**：短侧向安装基线到机器人方向/姿态的观测模型、可观子空间和几何退化条件。长度、误差传播和侧装外参本身是标准内容；新增价值须来自可复核的测量失效机制及有效策略。
2. **本体层候选**：支撑变化下合格的重力/转动约束与独立来源的速度更新，显式处理同 IMU 相关性。当前 SDK 机体速度源不等于已完成关节—足端接触里程计。
3. **整数层候选**：保持物理弧身份及候选来源的方向集合、合法弧输运和有向恢复；证书面向目标航向而非仅整数赢家。集合完整性、错误先验退出及实测收益仍待建立。

以上是研究分工，**不是三条已成立的新颖性声明**。

## 2. 有向信息究竟增加了什么

### 2.1 统一坐标和已知量

令 `r` 是 RX1→RX2、长度 L 的已标定机体安装向量；`R0∈SO(3)` 把初始机体系向量映至同一个固定导航系；`Dk` 把第 k 时刻的机体系向量映至初始机体系，`D0=I`。于是

\[
b_k=R_0D_kr,\qquad \|b_k\|=L.
\]

固定导航系中的**有符号**单位重力方向为 g；初始机体系对应向量为 `q0=R0ᵀg`。D 的左右乘、gyro 正负号、时间积分、IMU—机体外参以及 RX 箭头必须独立确认，不能把未知 ECEF 转动矩阵直接施加到 b0 上。

只有 r 和相对转动、不知道 R0 时，两向量至多提供无向夹角。合格 q0 加入后，还有

\[
g^Tb_k=q_0^TD_kr,\qquad
g^T(b_1\times b_2)=q_0^T(D_1r\times D_2r).
\]

第二式是有向三重积，保留了相对于重力的转向。若取首历元为初始时刻，可令 D1=I。它是标准 SO(3) 不变量，**不是本项目新定理**；可研究的是它何时具有可靠、有效的限定域。

### 2.2 为什么 pitch 或无向 Gram 仍不够

R6 的精确别名满足 `b'i=S_v bi=bi−v`，`S_v=I−2vvᵀ/||v||²` 是公共反射；所有 `biᵀbj` 相同。若 `v⊥g`，则 `S_v g=g`，连 `gᵀbi` 都相同：只添加 pitch/垂向投影不一定分开这类解。但

\[
g^T(S_vb_1\times S_vb_2)=-g^T(b_1\times b_2).
\]

因此，**有符号三重积在离零足够远且误差有界时**可排除该反射；零转动、绕基线轴转动、或 g/b1/b2 共面时，该项为零，仍没有区分力。近零时不应把噪声符号当作新信息。真实三维转动本身也不保证此三重积远离零。

若角误差界分别为 `eps_q, eps_D`，r 精确且 D1=I，一个保守的右侧不确定度界为

\[
|\tau-\hat\tau|\le 2L^2\{\sin(\epsilon_q/2)+\sin(\epsilon_D/2)\}.
\]

这是由单位向量与旋转的弦长上界得到的粗界，不是统计标准差；外参、长度、时间错位还需另入域。符号只有在整个区间不含零时才合格。不能给每个 pair 独立 sigma 后相乘，因为同一 gyro/重力历史产生共同误差。

### 2.3 重力资格不能由“有加速度计”替代

原始加速度是比力，足式运动、冲击、滑移时不等于重力。接触可信度只能支持一个需验证的模型，不能证明 q0 正确。已知安装方向也不能独自恢复未知绝对姿态。IMU+点接触的绝对位置与绕重力 yaw 不可观；因此载波完全中断且 gyro yaw 偏差无可靠界时，无法承诺无限期有界的绝对航向。[Hartley et al., RSS 2018](https://www.roboticsproceedings.org/rss14/p50.pdf)

备用 2 的数学区别是：若 `[D1r,D2r,D3r]` 满秩，公共 SO(3) 保持其有向体积，镜像改变其符号；仅施加所有 Gram 等式允许 O(3)，还须 det/手性条件。rank≤2 时可存在合适 SO(3) 扩展，不能由“多了第三历元”自动声称初始姿态唯一。

## 3. 完整候选航向集合：可审查的最小估计目标

### 3.1 集合而非前两名投票

以固定观测支持、完整 Q 和实际弧身份定义

\[
\mathcal C_t=\{(N,b,\xi):J_{raw}(N,b)\le\tau_t,\ \|b_k\|=L,\ (b,\xi)\in\mathcal P_t\},
\]

其中 ξ 包含先验误差/允许故障模式，P 是当前合格的物理约束。投影为当前方向集合 U 和通过外参/倾斜关系得到的机器人航向集合 Ψ。输出条件应是：集合非空、覆盖完整、有意义的圆周包络足够窄、当前物理资格成立且结果已实际到达。跨 ±π 使用圆周集合；相反方向的两个峰不能取算术平均冒充高置信输出。

这里“整数不唯一但航向集中”原则上可用，但必须同时包围**每个 N 下允许的连续基线**，不能只取每个 N 的球面最优点。当前 solver 只认证前两类（[solver.py](../../../src/legsa_gins/paper_rebuild/carrier_phase/solver.py) 212–250 行）；即使前两名航向接近，也可能有第三个成本合格、航向很远的解。

### 3.2 适配已有候选器，先不增加大整数模型

固定 N 的原高斯模型可分解为

\[
J_{raw}=J_{float}+J_N+(b-c_N)^TW(b-c_N),\quad W=C_{b|N}^{-1}.
\]

保留现有安全整数松弛下界，但搜索停止目标从“证明第二名”改为“所有未探索节点下界均超过固定阈值 `tau−Jfloat`”。候选数限制、超时、遗漏 nuisance 或不可验证数值下界均应返回**集合未完整**，不得继续给完整集合型航向。若使用删相位的新似然，必须明确它是新的观测集合，不能沿用原完整似然证书。

对已枚举 N，令 `rho=tau−Jfloat−JN≥0`，至少可用

\[
\|b-c_N\|\le\sqrt{\rho\,\lambda_{max}(C_{b|N})}
\]

获得保守外包，再与长度球/方向域组合；多历元需取正确 marginal 块或完整椭球投影。这个外包可能很松，不能保证可用率，但不要求立即求解新的全局耦合内层。候选剔除须证明其**整个可行域**与先验不相交；只检查最优 b 不满足先验就删 N 是不合法的。

若成本阈值大到包含很多整数，完整枚举可能仍不可用。可保留未展开整数节点的方向外包，只在外包均落入输出角域时停止；否则输出不可用。这个分支方法也需新的数学/数值证书，当前尚不存在。

### 3.3 “可信”的条件定义，不依赖在线整数真值

可先定义**声明模型下的覆盖型输出**，而不定义实测正确固定率。对于预定支持、正确确定性测量模型、已知高斯 Q、真参数在允许域内，真参数处的原始噪声代价满足 `eᵀQ⁻¹e ~ chi²_n`；取其分位数定义原始残差集合，在这些假设下有覆盖依据，在线不需要读真实 N。

这不能把自由拟合残差的 `n−p` 自由度任意移植到“已选 N + 非线性约束 + 被筛观测”的集合；也不能把当前工程 Q 当作已校准物理噪声。数据选择支持、先验误差、故障模式、相关观测和跨窗口复用必须计入资格。反复重叠 5 历元测试的单窗 alpha 不等于整段任务风险；若要全时段覆盖，要另给联合模型或可求和的风险分配。

没有真实整数标签仍可检查：集合完整性、已知真值合成覆盖、物理单位/符号、故障注入下退出、无参考时序/恢复和集合宽度。它们不能代替实测错固定概率；共享 GNSS 的 Fixposition 参考也不能提供独立整数标签。数据不支持时，风险字段维持未知。

## 4. 错误先验退出：不能用恢复措辞掩盖不可能要求

建议原始载波支持和本体资格分层保留。先验只能形成可撤销的候选视图；若先验被撤销，曾仅因该先验被排除的候选必须能从原始支持恢复。不能只留下已“固定”的赢家再宣称可以无损恢复。先验矛盾可以触发退出，但自洽的错误先验可能不产生可检测残差。

设 A 为 raw-only 合格集合，B 为用合格先验收缩后的集合。若允许“先验任意错误”而又要求无条件安全，故障模式并集至少包含 A，`A∪B` 不会比 A 更窄。**任意坏先验安全、同时无条件提升可用率，两者不能免费兼得。** 需要明确可验证的误差界、故障假设或独立健康证据；阈值膨胀/一致性否决不能替代这一点。

同一 IMU 既支持 AR，又传播主 EKF 时，输出与状态误差相关，还可能经历数据选择条件化。若输出为 `z=h(x)+nu`，需要来自共同噪声的交叉项 `C=Cov(delta_x,nu)` 或共享原始因子的统一处理；简单增大 R 不能声称消除相关性。不能获得相应资格时，该输出保留为研究旁路或明确条件测量，不能包装成已校准独立 GNSS 航向。

## 5. 弧生命周期：备用 1 是主线的必要工程底座

SD 节点应含 receiver pair、完整 constellation/signal/frequency 与两端实际 arc token。整数边表示合法差值。旧 pivot 失效时，先在旧连接分量恢复相对整数 potential，再投影至存活节点；`(Ni−Np)−(Nj−Np)=Ni−Nj` 可保留，不能先删 pivot 使所有边被误判丢失。跨频/跨系统偏差与原组模型资格仍需保留，不能仅因图可连通就建立无效整数差。

这只是条件于原候选的精确输运，不增加新观测，也不修复非整周偏差。投影会合并原候选类，须保留全部来源；旧 top2 合并不证明新类的第二名。删除观测或改变 Q 后，旧原似然最优性也不自动保留。未来新 arc 必须有新未知整数，不能因同一卫星重新出现就继承旧值。

当前 [tracking.py](../../../src/legsa_gins/paper_rebuild/carrier_phase/tracking.py) 190–224 行是单一 owner，首个支持/验收失效即永久 release；[partial.py](../../../src/legsa_gins/paper_rebuild/carrier_phase/partial.py) 53–59 行要求完整 selected labels。新图输运应新增清楚的条件跟踪身份，不重写旧验收为新的搜索证书。

输出角色必须分开：当前载波方向测量、载波中断时的本体传播航向、不可用。传播只能让不确定度随模型增长，不能重置载波测量年龄或制造新 GNSS 更新；恢复结果按实际可用时间发布，不回填过去，不伪造 N 的 selected_at。

## 7. 最小反例优先，不扩实验清单

后续实现资格至少应能正确处理以下五类独立构造；本轮只提出判据，**未执行**：

1. **反射与有向量零值**：沿用物理 LOS 整数反射别名；Gram/pitch 保留两解，非零有向量可排除镜像；将转动改为使三重积为零后必须恢复未决。
2. **错误重力/错误转向界**：真实可行解被坏先验剔除。撤销先验后原集合应恢复，不能只返回“原 winner 仍通过”；自洽坏先验未检测的情形必须保留失败。
3. **第三候选与连续方向域**：前两名同向但第三个成本合格异向；或同一 N 的允许连续基线横跨告警域。都不得输出完整集中集合。
4. **pivot 消失与真弧重置**：仅 pivot 失效应保留存活整数对比；新 token 即使恰好给出相同数值相位，也不得继承旧整数。候选类塌缩必须保留来源与未决竞争。
5. **因果可用性与重叠窗口**：求解完成晚于测量到达、载波中断且 gyro 有偏、滚动窗共用同一噪声。不能回填、复活已失效 owner，或把重复通过作为独立概率累乘。

是否推进实测不以“候选减少/ratio 增加”决定。最低正面证据应是原信息模型确实无法区分或无法给出窄方向域，而新增合格信息能得到覆盖正确的更窄域；同时错误先验反例按声明故障模型退出。纯实现更快、原本已唯一的容易例再次正确，分别只是工程收益与正确性资格。

当前下一步应由 root 将上述主线分成有限实现与预登记预算；本备忘录不授权追加计算。没有依据承诺 GPS Solutions/TIM 接收、跨日泛化、实测正确固定率或安全关键完整性。

误差界推导用 `||q−qhat||≤2sin(eq/2)`、`||(D−Dhat)r||≤2Lsin(ed/2)` 与柯西不等式：第一高度界为 L 倍重力弦长，第二高度界为两项弦长和乘 L，三重积界为两项弦长和乘 L²。它们是共享同一不确定域的必要外包，不能按三个独立概率检验相乘。输入 unit/SO(3) 的有限数表示公差只加入声明的算术保护项，不当作物理噪声。

### 9.2 球面与有向信息的安全收缩

当前 Gaussian 集合包含固定长度的可行集合。最小安全收缩可以先仅做必要性判定：若某 N 的连续球外包中心 c、半径 r 满足 `abs(||c||−L)>r`，且数值保护后仍严格分离，则该 N 不可能满足长度；首版实现尚未加入。与球面相交不能只替换成最优球面点，因为可行的球面片仍有宽度。

有向先验亦只允许证明**整个连续外包**矛盾时排除。对两基线外包中心 c1/c2、欧氏半径 r1/r2，有

`|gᵀ(b1×b2)−gᵀ(c1×c2)| ≤ ||c1||r2 + ||c2||r1 + r1r2`，

高度的候选侧误差不超过对应半径。将其与 `directed_motion` 的先验侧区间比较，严格不相交才可以剪除整类；重叠只表示未排除，不意味着该类存在符合约束的点。当前 directed_motion 的点对 `CONTRADICTION` 不能直接作为上述整类排除。候选不确定域/先验域之间的相关未知时，该笛卡尔积外包更松但不凭空收窄。

raw-only 全集及约束前的来源必须保留。先验失效后退回原全集/原包络；不是只保留赢家后“重新验收”。如果无法资格先验界，或任意错误先验模式仍允许，输出不可比 raw-only 集合更窄。连续域绕 ±pi 用圆周并集；水平外包含原点，输出全角未资格，不用 atan2(0,0) 假造确定航向。
