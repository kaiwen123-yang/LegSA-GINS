# 固定 1191 窗口的物理弧支持审计结果

本次发现的主要缺口是**局部物理弧失效导致整个已选集合释放**。535 个原 DD 标签支持失败窗口中，509 个首先失去 target 物理弧，25 个失去 pivot 物理弧，1 个二者同时失效；没有仅由 pivot 坐标重命名造成的首失败。保留合法剩余关系后，516 个失败窗口在原五个未来槽内都仍有至少 4 条独立相位差和三维 phase 几何 rank。**516 只是条件支持上界，不是新增准入、正确固定或可融合测量数。**

## 首次支持失败与剩余关系

物理节点身份为“完整信号身份、两接收机 SD arc token”。每窗以原 selected 关系建立连通分量；某节点首次失去资格或原 token 后，本窗口内永久移除。先保留分量内整数差分的可识别关系，再投影幸存节点；丢失旧 pivot 不会抹掉仍可推导的 target 间差分。新弧、同卫星重新出现和不同原分量之间不继承整数。

这里的“物理弧失效”指保存的节点身份/资格合同失效，**不是已证明发生了物理整周跳变**。metadata 变更和 TDCP–Doppler 不一致各自保留。

## 保留支持的几何代价

重构保持当前全部 code 行，phase 行采用同一原分量内幸存节点的当前 DD 之差。当前 pivot 即使是未知新弧，也可在相位相减时消掉；它的 code 噪声或偏差仍存在于保留的 code 观测中。完整观测变换为 B'=UB、Q'=UQUᵀ。条件自由基线协方差为 Cb=(B'ᵀQ'⁻¹B')⁻¹。

比较分母是同历元**当前全部整数都已知**时的完整 code+phase 几何协方差。这是乐观的条件几何参考，不是可部署对照；这里既未估计 N，也未评价真实基线误差。每个窗口先取五槽的最差比值，再对窗口作统计，P95 使用线性分位插值。

| 516 个条件支持上界窗口 | 中位数 | P95 | 最大值 |
|---|---:|---:|---:|
| trace(Cb_partial)/trace(Cb_all-current-N-known) | 2.8756 | 12.2092 | 91.4247 |
| lambda_max(Cb_partial)/lambda_max(Cb_all-current-N-known) | 2.9792 | 14.4169 | 119.2002 |

剩余几何即使 rank 足够，也可能明显变弱。这些比值不是角误差、保护水平或固定风险；后续不能仅按条数/rank 就开放融合。全部 1191 窗口及 19 个不足支持窗口的统计均保留在 [派生统计](ARC_SUPPORT_AUDIT_DERIVED_STATS.json)，未删去不利大值。

## 下一阶段允许推出什么

这份诊断支持继续检验“局部弧退休后剩余关系是否值得重新资格检查”，不支持把问题概括成单纯换 pivot。纯坐标变化不是本子窗的主要失败来源；节点局部隔离和幸存关系重检才对准观察到的缺口。

下一步可在同 1191 个窗口复用原冻结 primary/competitor 整数，只计算重构后固定 N 的残差、长度与物理 SD 相位故障诊断。必须记录两个原候选投影是否合并，明确没有覆盖未知第三候选，也不继承原 top-2 全局证书。不得按未来残差重新选子集、回填新弧整数，或从较优结果选择窗口。本报告没有执行该下一阶段。

现有错误整数和非整周偏差可以随关系一起保留；两原候选投影后相同也不意味着不再存在竞争。条件支持增加尚不能替代完整准入、重获、延迟与最终 V3 全窗导航验证。
