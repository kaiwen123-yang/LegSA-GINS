# 完整导航评价的事前指标与采用边界

状态：指标与预算合同，尚未授权具体配置运行。具体方法、输入、可用时刻和源码身份
须在首次 native 前以运行登记补齐。本合同在新的完整导航效果产生前制定；
其工程门限不是统计显著性、测量不确定度或录用标准，不得按新结果移动。

## 固定参照与输出支持

复用 AR_V3_RESEARCH_20261006/V3_BASELINE_LOCK 与 V3_BASELINE_METRICS：
BY2 [66,340]、BY2H [413,683]、BY2O [3186,3563]；原历史/初始化、
评价点/冻结 evaluator、时间和角度 wrap 均不变。研究 PVT、裁剪窗口不能替代 V3。
原始参考仅在方法与输出封存后由 evaluator 读取；所有新输出与失效状态保留。
原三窗基线已有结果，默认不重跑 V3，更不重跑封存矩阵。

完整窗指标与共同输出支持指标同时给出。共同支持必须在新输出封存后，使用已保留的
V3 error_series.csv.gz 实际时间键与新方法有效时间键求交，并由同一冻结评价规则对齐。
历史全量 NAV 已释放，不能从 summary 计数、首末时刻或插值假造旧输出支持；
如必要逐时刻载荷缺失，该共同支持指标记 NA，不用汇总值代替。
没有有效绝对航向时可做惯导相对传播，
但必须标识其状态和增长的不确定性；不得回填固定或将传播计为当前载波可用。
缺少真值的整数正确率、错误固定概率、速度真值指标一律 NA。
Fixposition 参考具有共享 GNSS 来源，不是独立真值。

## 主要指标与非退化界

主要指标：逐序列 wrap-safe yaw RMSE/P95/P99、大误差事件，水平与 Up RMSE/P95/P99；
完整导航输出覆盖、绝对航向可用覆盖、最长空窗、恢复时间；
完整前端/更新计算耗时及测量到决策可用的实际延迟。绝对最大误差完整报告，
不因“离群点”删去，但不将仅一次最大值当概率估计。

研究候选的工程非退化界，在每条序列分别检查：
- 水平/Up RMSE：新值 <= V3 + max(0.0005 m, 0.01 * V3)。
- 水平/Up P95 与 P99：新值 <= V3 + max(0.001 m, 0.01 * V3)。
- yaw RMSE/P95/P99：新值 <= V3 + max(0.02 deg, 0.01 * V3)。
- 导航输出覆盖不得靠主动少输出而下降；未匹配/不可用计数必须逐项报告。
这些小余量是预先选定的实用研究容差，不是声称数值严格相同。
同时报告零容差的原始差值，不能把容差内小恶化写成改善。
任一序列 H/V 超界则完整方法不通过采用门；不以跨序列平均掩盖。

足以推荐进入用户审核的新增收益，须除以上门外至少满足一个事先声明的目标：
A. 至少两条序列 yaw RMSE 相对降低 >=5%，第三条满足非退化；
B. 三条 clean 窗都满足非退化，自然遮挡 BY2O 的 yaw P99 降低 >=15%，
   并在随后独立登记的载波中断场景中，相对同原始观测、同故障注入和同验收规则的
   原载波前端，将下述受限恢复耗时均值降低 >=20%，不增加错误接纳证据。
B 必须同时具备实际中断验证，不能仅凭 clean P99 达标。
只提升候选数量/ratio/条件几何，不满足新增收益；只改善一条未经登记窗口也不满足。
即使过门，也只是研究版本可送用户审核，不自动替换 main。

## 事件和恢复时间的精确定义

导航大误差事件沿用既有评价阈值：绝对 wrap-safe yaw >2 deg、水平 >2 m、
绝对 Up >3 m，三个通道分别计。阈值等号不越界。按冻结评价网格连续越界段计事件，
首个越界时刻为开始；恢复要求连续1 s的有效输出均在阈值内，在该确认区间末时刻
宣布恢复，不把确认时间回填至区间起点。缺测会打断稳定确认，也单列输出空窗，
不作为误差为零。文件末仍未恢复者右删失；无越界者单列，不记为瞬时恢复。

原始载波故障的开始、结束和信号层在独立故障计划中预先固定。资格恢复从故障
结束至首次重新满足同一已冻结当前观测验收规则并连续保持1 s的确认末时刻计算。
原载波前端和新前端使用相同输入、接收可用时刻、故障、验收规则和20 s观察范围。
所有预登记case进入受限恢复耗时均值：已恢复值取min(恢复耗时,20 s)，
未恢复取20 s仅用于受限指标，必须同时标注右删失、未恢复计数和可恢复比例，
不能称其实际恢复耗时为20 s。原始记录不足故障后20 s的case在输入计划阶段
判定不可实施并单列，不在结果出来后替换。百分比计算分母为原前端受限均值，
分母为0时百分比NA，该项收益门不成立，并报告绝对差。

V3输出来自PVT且没有本研究的AR状态，所以不能定义其AR重获耗时，更不能把
仅中断原始载波、仍保留PVT航向的条件当作V3同层故障。原载波前端的恢复比较
只支持载波机制归因；V3导航效果仍按完整clean窗单独检验。若要比较V3导航
故障恢复，必须另登记对两方法一致的可用观测故障及导航误差恢复定义。

## 归因和初轮预算

原 V3 为复用基线。新方法初轮最多三个作用臂：
载波/模糊度管理；本体独立速度或支撑约束；二者完整组合。
三臂乘三完整窗最多9个新 native/evaluator身份，方法尚未成立的臂不为凑数强行运行。
仅当新二进制需要兼容性检验且有明确身份比对依据时，可增加每序列最多1次
关闭新增功能的检查，共最多3次 native/evaluator，单列不混入效果样本。
因此初轮总上限12 native、12 evaluator；0参数扫、0成功窗口替换。

各臂分别冻结具体代码、配置、provider、初始化和所改观测项。
同源PVT航向与载波不能在未解释相关性时当两份独立测量重复注入。
共享IMU、重叠时间窗、SDK内部估计依赖须明确；R膨胀不等于解决这些相关性。
先保留EKF；如有局部状态/相关噪声更新，另列数学和消融依据。

## 停止与继续

源身份/配置误读、参考在线读取、时间/坐标错误属于技术停止；
保留原attempt，修正后独立登记，不静默覆盖或把失败改为未执行。
机制没有增量辨识能力、预算内始终不能形成完整候选集、或者错误先验不能撤销，
则对应分支不进入导航；可以在有新信息或明确数学理由时提出替代实现，
不能仅通过调整阈值继续试到通过。

如果H/V超界或收益门失败，不把整批后验当参数调优集。
先给出可检查的因果假设，必要的修正与新身份另登记；无依据则关闭对应支线。
三项候选贡献逐项给出成立/不成立/证据不足的技术结论。
新版本没有足够收益时正式采用建议保持V3；原始完整目标和用户审核权均不改变。

多星座多频率、原始载波故障注入及跨日留出须各自保持真实/合成身份，
具体case数量与先验门限在看到该批结果前补充登记。
不将同日三窗或高度重叠1191开发窗视为跨日独立重复样本。
本文件只用于实验执行与技术采用判断，不是论文材料。
