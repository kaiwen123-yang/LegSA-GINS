# 候选方向筛选（初始，非新颖性结论）

问题优先、失败分析、组合/分解三个视角；下列并非十项拟实现算法。
按已有信息、可实现性和能否验证收敛，文献结果见 METHOD_AND_NOVELTY。

| 候选 | 预期信息/作用 | 决策与首要反例 |
|---|---|---|
| 两历元无向夹角 | 限制跨期方向 | 旧反射别名已否定当前扩展收益，封存 |
| 单期加pitch/重力 | 限制基线垂向 | 已有前作；水平反射仍可能保持 |
| 重力定向相对转动 | 有向旋转区别镜像 | 研究；弱激励/坏重力/时延需退出 |
| 三维多方向proper-SO3 | 手性信息 | 备用；真实平台激励是否足够未知 |
| 仅top2航向集中即接受 | 用整数不唯一换方向连续 | 不接受此论证；漏掉第三候选不安全 |
| 完整候选集合的方向投影 | 面向航向而非强求全部整数固定 | 研究；完整支持与遗漏界是难点 |
| 物理SD弧整数关系图 | pivot改变和局部断弧时保留条件信息 | 先实现；不能把条件关系称真实FIX |
| 支撑足差分相对转动 | 平移消去、提供可观旋转分量 | 先实现；两足rank2、共同滑移不可识别 |
| GNSS无关SDK速度 | 明确来源/减少GNSS反向循环 | 已有研究接口；同源相关性仍要处理 |
| 因果状态与重获策略 | 观测/传播/未决/失效不混淆 | 必须贯穿；旧信息重用不得重复收缩 |
| 直接扩维大整数EKF | 联合估计 | 暂不选，成本大且未证明必要 |
| 动态来源分组更新 | 控制共享噪声和垂向影响 | 接口审查后选择最小必要修改 |

优先级：弧关系内核 + 支撑旋转内核 + 有向/候选集合理论，
再由实测输入资格决定统一前端。名词组合本身不构成新颖性或效果证据。
