## 输入语义差异

指定的 V2s 冻结 HV provider 实际使用 **Go2 自身 roll/pitch/yaw**，不是任务括注中的 Go2 roll/pitch + A1 yaw。冻结 CSV 的 `frame_candidate` 为 `go2_velocity_as_body_flu_then_rotate_by_go2_attitude`；`paper_rebuild/providers.py::_go2_priors` 调用 `go2_velocity_frame_review.py::transform_go2_velocity_for_frame`，其 `_rotate_rpy` 使用原始 Go2 `yaw_rad`。本次按已明确指定的冻结 provider 计算，未重旋转或替换其 `vn/ve`。A1 在本统计中仅用于缺测区间剔除及沿航向／右向横向分解。以下数值不得称作“A1 yaw 旋转的 HV”的标定结果，也不构成对 provider 物理坐标系的独立验证。

CAL 的 HV 和 GNSS 文件与各序列原 V2s（BY2）/V2（BY2H、BY2O）输入 SHA-256 相同，copy ledger 为 byte_equal；本次再次验证所读取文件的固定哈希。PVT 由固定 raw UBX-NAV-PVT 的整数 iTOW 解码，同历元 N/E/D 速度与 V2s GNSS18 输入逐行一致。A1 源历元经 status header 毫秒身份映射到 iTOW，与 GNSS18 yaw_valid 历元集合一致。

## σ_HV 与三个决定参考值

`σ_HV = sqrt((std_N² + std_E²)/2)`，单一标量，对应 provider 生成字段 `go2_horizontal_velocity_std_mps`。不扣除 PVT 自身噪声，按任务要求作为保守的交叉源残差量；这不是独立 HV 白噪声方差的识别。原始 provider 的 std_vn/std_ve 均为 1.5 m/s，冻结 runtime std_scale=1、adaptive std disabled。

三序列整体 σ_HV 约为 0.81–0.92 m/s；BY2O 含 5,344 个低速样本，而 BY2/BY2H 的低速箱为空，整体数值的横向比较受运动组成影响。>0.8 m/s 箱的 N 轴标准差为 1.262093 / 1.273862 / 1.298125 m/s，E 轴为 0.239764 / 0.260015 / 0.218389 m/s。不能以整体标量近似相近作为传感器白噪声属性已跨序列一致的证明。
