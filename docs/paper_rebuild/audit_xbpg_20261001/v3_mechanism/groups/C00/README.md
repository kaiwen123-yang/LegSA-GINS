## N16：999对二维HV权重的实质作用

F04的1369个HV事件均为实际二维更新，metadata.std_xyz第三分量为999。取消**仅maxStd中的禁用D分量**并保留其他LSIM、旧OIM、cap后，1369个事件的影子最终R都改变。event299，实际provider时刻66.19904589653：旧LSIM=2；仅取消D维条件后LSIM=1.5，仍受原非nominal质量项影响；实际最终scale=2，影子=1.5。实际二维R对角为0.035291868488000006 (m/s)²；N12单独影子在该事件仍被LSIM遮蔽，R不变。这区分了N12与N16两个局部路径，没有将二者同时接入滤波器。

这证明999路径在本组实际决定了权重的一部分，不证明它损害位置精度，也没有得到“修正后RMSE”。A04关闭SA，不给其HV记N16实际权重影响。

## 同批问题与证据边界

[N11/N15/N01/N02条件简报](SAME_BATCH_CONDITIONS.md)及逐字段表记录已发生的未补偿res=3与非零bias、必需输入字段完整性和真实倾角。N11触发条件已实测，但纠正后的杆臂项、更新差与轨迹影响未试；安装/原始三维baseline/参考独立性仍未闭合。

所有中间量均为`replay_observed`。本组原输出字节对应支持将这些执行路径关联到选定C00历史输出，但不把新日志称历史日志，也不外推6468身份。原指标、参考点与参考独立性资格未在本组升级；没有修正式算法或重新求性能统计。

字段口径：调度窗口按触发GNSS事件/函数入口时刻；创新窗口按该事件记录的measurement_time，RP/HV为实际匹配provider时刻。固定半开边界附近可能分入相邻窗，不混用分母。无真实到达资料，available_time仍UNKNOWN。
