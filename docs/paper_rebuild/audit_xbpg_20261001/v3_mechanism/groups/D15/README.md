## N16不是“命中1369次就影响1369次R”

F04的1369个HV事件均使用二维R，metadata.std_xyz=[0.132838,0.132838,999]。仅移除禁用D维对maxStd的贡献，LSIM均由2变为1.5，但**只有40次最终影子R不同**；其余1329次被旧OIM或cap遮蔽。见 [INNOVATION_COMPACT](INNOVATION_COMPACT.csv) 的HV行，与C00的1369次最终R变化不能互相替代。

event595中实际R对角0.035291868488000006，N16单独影子为0.026468901366000004 (m/s)²；这是保持旧OIM的N16单因素影子，和同事件N12单独影子的0.17645934244000003不同。event907的实际及两种单独影子R对角均为0.17645934244000003；即使命中了999条件，最终R仍不变。没有把N12、N16同时接入滤波器，也没有将两个单独影子相加。

## 本对象的裁定

正式输入和历史输出身份已闭合，新观察版没有改变所核五文件或科学manifest；中间量仍是新`replay_observed`日志。N12/N16已从源码适用推进到真实重放事件与局部权重层证据，但闭环修补尚未执行，无修后RMSE。原D15性能表仍描述原算法及其固定门；不能因发现NIS差异宣布所有旧数字无效，也不能因F04接受更多来源宣称其机制最优。

最小后续候选是分别固定本F04对象与C00，单独验证N12、单独验证N16的纯函数与闭环差异；先保留当前基线，不同时调门限或改变故障。A04仅作为原SA关闭路径对照，不能当同状态反事实。全部结论限所测seed00，不扩展到整个D15族或6468身份。
