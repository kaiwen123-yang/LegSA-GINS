# N12_ONLY：C00/F04 与 D15_seed_00/F04 的实际事件结果

两个已授权对象的四条事件流均完整读取并通过身份、序号/首尾、事件关联和同快照算术核对。候选的条件创新已进入实际更新：两组首个实际 R 差异均出现在 GNSS 输入 1 的 RD 更新，并在共同 IMU 43 的末状态留下差异。C00 没有接受状态变化；D15 有一次 yaw 从原版接受变为候选硬门拒绝。这些事实证明本候选在这两个对象上改变了闭环，不证明精度改善，也不替代最终采用裁定。

本项只分析 `N12_ONLY/RUN_00004`（BY2 C00/F04，`data_mode=real_clean`）与 `N12_ONLY/RUN_01401`（BY2 D15_seed_00/F04，`data_mode=semisynthetic`）。两者 `synthetic_data_used=false`；只有 D15 的 `semisynthetic_data_used=true`。定义沿用 [V3_DEFINITION_DECISIONS.md](../../V3_DEFINITION_DECISIONS.md) §2.1：以当前顺序条件创新 `nu=dz-Hdx_before`、同次 `P_before/H/base_R` 计算 OIM 统计量，保留 raw dz 供原硬门和 EKF 使用。原 V3 结果及冻结定义原样保留。
