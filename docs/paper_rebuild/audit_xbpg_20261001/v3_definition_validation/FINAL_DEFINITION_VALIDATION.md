# V3 定义与单项闭环裁定

本轮完成原定10个候选组合，保留原V3，不合并任何候选。继承直接5 Hz标量heading、HV沿用旧status-heading、原21维误差状态滤波及RV/RD/RP/HV弱辅助主线。N12与N16确认了需要修清楚的计算契约，并有独立代码和实际闭环证据；N09按原文证据只能定为可选更新能力扩展。**必要数学/维度修正不等于性能必然改善，也不等于本轮已经决定采用某个新共同版本。**

范围是一条BY2录制上的C00、D15_seed_00、A1/A2各20 s seed_00四种条件、七个原case/method身份。十个候选组合不是十个独立自然实验。新结果分别是`real_clean`或`semisynthetic`；合成测试独立登记，不进入这些性能表。没有联合候选、参数搜索、bootstrap、全矩阵、论文或横向工作。
