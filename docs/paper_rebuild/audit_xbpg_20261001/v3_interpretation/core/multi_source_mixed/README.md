# CORE — 多源混合故障（multi_source_mixed）

本族包含 4 个退化类型（D57–D60）、每类型 9 个种子，共 36 个案例；11 个方法对应 396 个唯一 native，v3/v2 合计 792 个评价槽。BY2 同一条原始轨迹上的半合成受控退化，不是这些数量的独立实测序列。失败行完整保留。

## 注入什么，保持什么

D57 保留各源 latency/jitter 的真实时间 token，V3 只按原始 iTOW 精确匹配 raw 航向，不插值、不取邻行、不修正时标；预注册明示有效航向行为 0。D58 是位置停测+航向尖峰+恢复，D59 坏位置+RD/RV 冲突但航向不注入，D60 多源坏值+乐观 std+恢复。恢复区间只是注入组件元数据，现有 V3 全窗指标不能自动变成恢复时间或段内 RMSE。HV 原样继承 status 旋转。

| 类型 | 已实现的组件和幅值 | 作用窗及未改内容 |
|---|---|---|
| D57 | position、RV、dual yaw、RD、RP、HV 六源各有独立 latency∈[0.1,0.3] s；各源另抽 jitter 最大幅度∈[0.02,0.05] s，再逐行加对称均匀 jitter | full_sequence；按源保留原行身份并排序，微小重时刻按原规则分开；不是整体统一平移，不改 IMU 时间；V3 保持冻结后的时间 token，严格原 iTOW 配对 |
| D58 | 位置停测 10 s；同窗内原有效 yaw 行约 10% 选 ±10° 尖峰 | 各 seed 的旧位置表记 50 行、旧 yaw 表记 1 个尖峰事件；原事件按 1 s 单元与故障窗相交映射到 V3 航向，后接原 20 s 恢复窗；不重新随机抽 5 Hz 尖峰 |
| D59 | 位置 N/E 各 sigma=3 m、Up sigma=5 m；RD 加模长 1 m/s 的固定水平偏置，RV 不变 | full_sequence；bundle 记位置1510行、RD1248行；`good_yaw_preserved.values_unchanged=true` 表示本 case 未注入 yaw 故障，V3 正式直接航向仍是 R5；不是参考意义上的“零误差航向” |
| D60 | 原20 s窗内位置 N/E sigma=3 m、Up sigma=5 m，位置std×0.25；yaw sigma=10°、原yaw std×0.25；RV/RD三轴各sigma=0.5 m/s、各自std×0.25 | 两速度源使用冻结的独立命名随机子流；V3 yaw 仅转移已实现的1 s圆周扰动单元并与窗相交，保留原逐行std、不给中间5 Hz行补缩放；之后保留原20 s恢复窗 |
