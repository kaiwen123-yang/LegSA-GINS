# CORE — 接收机速度与 Raw Doppler（velocity_raw_doppler）

本族包含 9 个退化类型（D42–D50）、每类型 9 个种子，共 81 个案例；11 个方法对应 891 个唯一 native，v3/v2 合计 1782 个评价槽。BY2 同一条原始轨迹上的半合成受控退化，不是这些数量的独立实测序列。失败行完整保留。

## 注入什么，保持什么

D42–D45 操作接收机速度 RV；D46–D49 操作 Raw Doppler；D50 通过偏置 RD 制造二者冲突。两者是不同通道，名义相同 case 不等于所有方法都使用同样被污染的更新。实际 81 份 bundle 的 `semantics.no_active_path` 均为 false，但这只说明存在该注入源的实现路径，不保证每个方法启用该源、每次更新有效或通过门控。

RV 是 GNSS18 中的接收机 NED 速度：从 1 开始数，第 8–10 列为 `vn/ve/vd`，第 11–13 列为 `std_vn/std_ve/std_vd`，第 17 列是独立速度有效位。RD 则来自单独的 `raw_doppler_factor_path` CSV，同名 NED 速度/标准差字段之外还有 `valid`、`provider_status`、`quality`、卫星数和来源身份。RD 不是将 RV 换一个名字，也不是原始多普勒频率直接进入这张退化表；本族是在冻结的 Raw Doppler 速度产品上施加已注册扰动，未重新处理 RAWX/SFRBX、卫星状态或接收机位置。
