# CORE — 双天线标量航向（dual_yaw）

本族包含 12 个退化类型（D30–D41）、每类型 9 个种子，共 108 个案例；11 个方法对应 1188 个唯一 native，v3/v2 合计 2376 个评价槽。BY2 同一条原始轨迹上的半合成受控退化，不是这些数量的独立实测序列。失败行完整保留。

## 注入什么，保持什么

D30/D31 为 5/20 s 航向停测；D32/D33 为噪声，D34/D35 为尖峰；D36/D37 修改 std，D38 为坏 yaw 配乐观 std，D39 为质量掉线，D40 为 baseline/rel-acc 元数据，D41 为单接收机非对称扰动转成标量角差。D40 的真实 bundle 明示 no_active_path、baseline_length_solver_visible=false、solver_runtime_input_unchanged=true；它不是正式标量方法的 3D baseline 实验。随机扰动按原 1 s 单元延拓；std 缩放仅原有行继承，中间 5 Hz 行未补缩放。HV 仍继承原 status 航向旋转，不随新 5 Hz 航向重建。

本族正式方法为标量 **R5/BOTH_FIXED**，不是 B3/3D baseline：raw HPPOSECEF1/2 按原 iTOW 精确配对，基准有效性要求两台接收机的 NAV-PVT carrSoln 均为 2；再施加已冻结的故障映射。下表的旧 bundle 受影响数是冻结源的行数，**不是新 V3 5 Hz 表的受影响历元数**，更不是 evaluator 的 matched_count。本项未读取 provider 载荷重新统计这些数。

## 时间支持与尚未完成项

评价合同窗为 BY2 [66,340] s，逐运行实际 time_start/time_end、output/matched/reference 点数及 coverage 原值在 ORIGINAL_RUN_VALUES.csv。coverage=matched/output 只说已有输出匹配率，不证明窗完整、连续、同历元支持或独立样本。此处对比运行级原数，没有施加共同历元网格，也没有从全窗指标推断故障段/恢复段结果。

时序证据已由唯一 scanner 完成本组检查，见文末实际范围。本 worker 未读取 error_series gzip 正文；根代理须在处理到本族时链接唯一 scanner 的同组检查回执。不存在的 NAV/STD 不重建；不能以本项逐案例算术验证代替逐历元核对、求解重现或数学审查。

数据与参考边界：Fixposition 商业融合 reference 不是独立真值；重复使用 BY2 原始轨迹和注入种子不构成独立真实场景样本。既有 bootstrap 的条件性和模块/参考相关性边界见 [方法与指标说明书](../../METRIC_AND_METHOD_GUIDE.md)。
