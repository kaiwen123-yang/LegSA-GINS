# CORE — 位置标准差与状态（position_std_status）

本族包含 7 个退化类型（D23–D29）、每类型 9 个种子，共 63 个案例；11 个方法对应 693 个唯一 native，v3/v2 合计 1386 个评价槽。BY2 同一条原始轨迹上的半合成受控退化，不是这些数量的独立实测序列。失败行完整保留。

## 注入什么，保持什么

D23–D25 膨胀位置标准差，D26 使标准差过度乐观；D27 同时损坏位置值并缩小 std；D28 位置值不变但 std 悲观；D29 仅状态/质量降级。标准差是输入权重字段，不能直接称作真实误差方差。不同方法使用 SA 的差异可对应输入暴露差异，但本项不证明 SA 的因果保护机理。

实际参数如下，来自逐 case bundle 的 `case_meta.degradation_parameters_json` 与 `components/0/details`。这些都是输入 **std 字段**的倍率，不是从本轮 RMSE 估出的噪声或新调参。全部实际 `duration_s=full_sequence`；注入基于 provider 全序列，评价窗仍为 `[66,340] s`，没有为每个 seed 新造 anchor 中心停测窗。

| 类型 | 原定义与实际组件参数 | 改变/保持的量与实际支持 |
|---|---|---|
| D23 | `position_std_scale`，factor=1.5 | 位置 std×1.5；`values_unchanged=true`；各 seed 组件记 1510 历元 |
| D24 | 同类 scale，factor=2.5 | 位置 std×2.5；值不变；1510 历元 |
| D25 | 同类 scale，factor=4.0 | 位置 std×4；值不变；1510 历元 |
| D26 | 同类 scale，factor=0.25 | 位置 std×0.25；值不变；1510 历元 |
| D27 | `bad_position_optimistic_std`，h_sigma=3 m、v_sigma=5 m、std_factor=0.25 | 同时扰动位置值与 std；1510 历元；不能把它归成“只改权重” |
| D28 | 原名 good_position_pessimistic_std；实际仍是 factor=4.0 的 `position_std_scale` | `values_unchanged=true`；1510 历元，实际组件参数与 D25 相同 |
| D29 | `gnss_status_quality_downgrade_only` | 组件记 303 个元数据历元，但同时明示 `no_active_path=true`、`solver_values_unchanged=true`；不是向正式标量运行通路施加了有效坏位置观测 |

D29 的名称不能代替上述实际作用说明，也不能据其低误差宣称算法已抵抗一条未激活通路上的状态降级。D25 与 D28 保留各自原注册 case/run 身份和分母，不在本项事后去重；它们的实际扰动参数相同，现存逐种子/方法/评价版的七指标字符串也相同，不能当成两种独立物理机制的证据。完整源路径及 `/components/0` 指针在 INJECTION_COMPONENTS.csv；原 YAML D23–D29 定义为第 213–254 行，各类型起止行在 TYPE_DEFINITIONS.csv。

[TYPE_DEFINITIONS.csv](TYPE_DEFINITIONS.csv) 保留原 YAML 定义；[INJECTION_CASES.csv](INJECTION_CASES.csv) 和 [INJECTION_COMPONENTS.csv](INJECTION_COMPONENTS.csv) 来自逐 case 的实际冻结 bundle，后者保留组件名、affected_source、affected_epoch_count、details 与原 JSON pointer。实际窗口、随机方向、幅度与 anchor 以这些已实现记录为准。
