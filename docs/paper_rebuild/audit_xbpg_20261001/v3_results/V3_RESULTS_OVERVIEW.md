## 9. 常见字段怎样读

| 字段/术语 | 阅读方式 |
| --- | --- |
| `native_status` / `evaluation_status` | 解算终态与评价槽终态分开；未启动评价不是评价器失败 |
| `run_id` / `case_id` / `seed_index` | 物理运行、工况、注册种子的不同键；跨协议还需加 protocol 身份 |
| `horizontal_rmse_m` / `h_rmse_m` | 原表中的水平位置 RMSE（m）；名称映射只用于浏览，原列名仍保留 |
| `position_3d_rmse_m` / `up_rmse_m` | 三维位置 / Up 分量 RMSE（m），不是水平误差 |
| `yaw_rmse_deg` / `roll_rmse_deg` / `pitch_rmse_deg` | 相对声明参考的角度误差（deg）；与基线朝向或独立真值无自动等价关系 |
| `matched_epoch_count` / `count` | 对应支持点数量；某个 summary 中的 count 须结合来源对象读取，不一概当运行数 |
| `time_start/end`、`sequence_window_start/end_s` | 实际已记录支持与注册窗口分开；时间基准见同一行 base_time/契约，不自动假设所有序列从零开始 |
| `finite_count` / `registered_count` | 有限指标样本 / 注册分母；失败保留在后者，不填成零误差 |
| mean、median、p95、maximum | 当前表已定义的分布层级；跨运行 RMSE 分布与历元误差分布分开 |
| `coverage_ratio`、3σ/convergence 字段 | 既有评价摘要字段，本轮仅转录；未重新验证统计或协方差校准含义 |
| recorded / verified hash | 前者来自原 pin/receipt；后者只在本轮确实读到并计算该对象 hash 时填写，不校验整个盘 |
| `unknown`、null、空字段、NOT_RUN、UNAVAILABLE | 保留来源语义；空值与零不互换，空字段解释见对应状态和字段映射 |
