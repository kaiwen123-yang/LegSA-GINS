# 有界 EKF 改动范围：替代旧绝对冻结约束

2026-10-06，依据用户最新决定。用户允许核心数学适度改变，同时明确
不能无节制扩大。此文覆盖 EKF_FIXED_SCOPE.md 的绝对冻结条款；
历史文档保留，不把过时限制解释成新的审批要求。

## 默认选择

继续使用 KF-GINS 误差状态 EKF 与现有惯导机械编排。第三项的第一步
是载波前端两历元机制验证，不因“需要新颖性”更换估计器。
V3、当前研究控制组及旧数值结果分别保留身份。

## 允许的局部改动

每项改动必须对应一个已证明或可检验的问题，并能单独消融：

1. 方向或体速度的观测函数、Jacobian、完整测量协方差、可用时刻和准入。
   单位向量的秩亏应采用合适二维切空间或其他有据处理，不硬逆三维奇异矩阵。
2. 若源审计及推导支持，补充测量噪声与预测误差的交叉项，处理共享IMU。
3. 必要的、维数受控的局部误差处理；增加状态必须先说明可观性、激励、
   额外数据与计算成本。首个机制试验不增加接触点、全星整数、滑移或时延状态。

全量整数/接触联合扩维、改为 FGO/InEKF、重写传播、同时更换多源 Q/R
均不在首轮范围。它们不是“禁止研究”，而是在已有小问题未解决前没有
投入依据。常规实施决策由代理承担，不再为每个可逆改动询问用户。

## 相关观测更新的精确边界

约定 delta_x = x_true - x_pred，残差 r = z - h(x_pred) = H delta_x + nu，
C = Cov(delta_x,nu)。则在线性化、模型正确且给定整数分支的条件下：

    S = H P H^T + H C + C^T H^T + R
    K = (P H^T + C) S^-1
    P_post = P - (P H^T + C) S^-1 (H P + C^T)

要求完整联合协方差 [[P,C],[C^T,R]] 半正定，且 S 可逆或在对应的可观
子空间求解；只保证 P、R 各自正定不够，不能任意指定 C。
这是标准相关噪声更新，不是新增创新点。只有推导出 C 的来源和传播
才有采用依据；不可从评价曲线拟合 C。离散候选选择、错误整数、重叠窗口
重复信息和多源PVT/载波相关性，不会被上述局部公式自动全部解决。
实现时还要与工程误差状态符号、反馈/重置Jacobian及数值稳定更新一致。

若相关来源无法定量处理，先停留在独立前端对照，报告这一限制；
不能仅放大 R 后宣称消除了反馈重复，也不从未知相关性推出算法必然无效。

## 因果性与独立速度

不把融合后全局yaw/位置作为“独立”AR或速度输入。标准 h(x) 依赖预测
状态是正常测量建模，与利用后验制造第二份观测不同。
本体速度应由GNSS无关源构造；共享IMU或SDK内部融合状态需记录，不能
把“构造不读GNSS”写成统计独立。足端失效只降低相应本体约束可信度。

保持 H、V、yaw、峰值/尾部和空窗的共同报告；不用通用零垂速约束掩盖
问题，不按参考误差删结果。所有算法修改与测试在E盘Ubuntu22.04 WSL。
