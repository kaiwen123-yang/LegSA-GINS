# 三项贡献的统一架构与动基线模糊度研究决策

日期：2026-10-06。研究设计及证据审查，不是成稿或新算法结果。
依据用户最新决定：允许有界、问题驱动的 EKF 修改；旧绝对冻结约束被
BOUNDED_EKF_SCOPE.md 取代。上轮载波数值试验完成状态不变。

## 1. 研究决策

保留两项已有系统贡献，将第三项的主攻方向从“选择、保持、重获”提升为：
**本体相对运动约束下的短基线部分整周模糊度固定**。

更精确的技术问题是：在未知初始姿态、相对旋转有误差、载波支持会变化的
条件下，能否利用跨历元刚性基线的运动形状区分整数候选，并将可信方向
送入现有导航骨架？选择、续接和重获是该方法的配套，不单独凑贡献数。

这项方向尚未实现，也未证明比既有方法新或优。先验证它是否实质改变
整数辨识能力，再决定是否扩展完整求解器；不要用重新命名代替算法差异。

论文可以有三项贡献，但不要求三项都是全新的基础算法。期望结构是一个
明确的载波估计主方法、一个平台方向测量模型、一个本体互补融合机制。
如果第三项只变成新验收阈值，或只能胜过未经资格验证的对照，就不能把它
升级为主方法贡献。V3 仍是已有论文工作的依据。

## 2. 三层分工，避免重复计功

| 层次 | 建议贡献表述 | 它回答的问题 | 需要的独立证据 |
|---|---|---|---|
| 方向测量 | 紧凑足式平台短侧向双天线的方向观测建模、误差传播与准入 | 给定基线估计，哪些姿态方向可观，测量误差如何影响航向？ | 安装几何、倾斜与水平投影退化、各向异性协方差、异常准入的单独消融 |
| 本体融合 | 本体弱约束与 GNSS 无关构造的速度观测之条件互补融合 | GNSS、接触及速度源质量变化时，哪些状态信息可以相互补充？ | 源构造独立性、速度语义、共享噪声、接触失效、H/V 与航向消融 |
| 整数估计 | 本体相对运动约束下的短基线部分整周模糊度固定 | 哪些载波整数能够同时解释一段真实可行的基线运动？ | 整数真值模型、错误运动先验反例、公平 AR 对照、连续性与恢复、留出实测 |

信息流是“载波整数估计 → 方向测量 → 导航融合”；本体相对旋转也向
整数估计提供一个来源明确的约束。它不提供独立绝对航向。
PVT 与载波可以作为同一方向接口的替代提供者；同时使用时不能默认独立。

目前 V3 主要是双位置方向及原有本体弱约束；研究分支新增的向量接口、
体速度独立触发与载波链，不能倒写成原 V3 已有方法。
现有 SDK 体速度已可不经 GNSS 构造，但不是自行构建的足端里程计。
足端运动学、接触一致性及误差传播的自主实现仍须单独完成验证。

方向层应从物理关系 u^n = R_b^n l^b / L 出发。单条基线只给两个姿态
方向的信息，绕基线的旋转仍不由它单独观测；不得把侧向角度换算当成
新的姿态可观性。若使用归一化，J=(I-u u^T)/||b||，条件协方差为
J Q_b J^T，秩至多为2。短基线、接近竖直的水平投影、安装误差及长度
误差应分别处理。该标准误差传播本身不构成首创声明。

## 3. 第三项必须改变估计问题，而不只是增加否决门

现有选取窗口的核心可写成

    y_k = A_k N + B_k b_k + e_k,     ||b_k|| = L.

N 是连续且已选物理弧对应的共享整数。工作 Q 包括共用参考星造成的
双差相关性。当前各历元 b_k 独立落在球面上，没有相对姿态的约束。
错误整数可能通过逐历元改变基线方向，仍取得不差的观测残差。

新增运动约束收紧可行集合，不保证增加固定率。它不能恢复缺失载波或
未解半周，也不能把现有535个弧变化未决自动变成成功。若主要瓶颈仍是
观测资格而非整数不可辨识，应优先修正共享观测模型与支持管理；不能仅
因形状模型有数学内容，就把求解器扩展当作必然有效的升级。

若刚性机体系基线 r 已知、||r||=L，且本体相对旋转 DeltaR_k 合格，
同一短窗口内应该存在一个未知的初始姿态 R0，使

    b_k^e = R0^e DeltaR_k r,        R0 in SO(3).

初始姿态必须作为未知量；不允许把已经融合 GNSS 的导航 yaw 填入。
原始 gyro 增量不是已知 ECEF 旋转。上式必须使用一致的参考坐标系；
地球自转、安装外参、时延、偏置与非刚性误差须建模或进入误差集合。

消去公共左侧旋转，得到必要的形状关系

    b_i^T b_j = r^T DeltaR_i^T DeltaR_j r.

这表示各历元基线的相互夹角受到同一段本体转动约束。它允许未知初始
航向，研究价值在整数候选能否被这种跨时约束区分，而非“加了 IMU”。

若相对旋转的 SO(3) 测地误差确实满足
||Log(DeltaRhat_ij^T DeltaRtrue_ij)|| <= epsilon_ij，0<=epsilon_ij<=pi，
这里使用旋转向量范数，不是两个标量旋转角之差。一个保守必要条件是：

    |b_i^T b_j - r^T DeltaRhat_ij r| <= 2 L^2 sin(epsilon_ij / 2).

两历元可采用更紧的角度区间。令 beta_hat 为 r 与 DeltaRhat_ij r 的
夹角，则真实基线夹角须在

    [max(0, beta_hat-epsilon_ij), min(pi, beta_hat+epsilon_ij)].

令上述端点为 beta_lower 与 beta_upper，相应点积区间为
[L^2 cos(beta_upper), L^2 cos(beta_lower)]。夹角很小时，
统一点积误差界可能过松，首个原型应检验这一点，而不是为了通过而放宽。

这些是标准旋转几何的推论，不是新的数学定理。若 epsilon 来自概率
区间而非物理硬界，约束就只有对应的模型内覆盖含义，不是绝对保证。
偏置、时延等被漏掉时，错误约束可以排除真整数，必须给出反例。

多于两历元的 Gram 必要条件还存在反射和整体可实现性问题；每对均
过门不等于存在同一条合法 SO(3) 轨迹。不能将共享积分噪声的约束
作为若干独立高斯观测重复累加，也不能只靠这些条件宣布新的全局证书。

## 4. 求解与融合的有限改动

先保持已选六维整数、信号前端和完整 DD 工作协方差，仅用两历元及
共同有效弧构造最小受限问题。此时是预选整数类上的求解，并非重新声称
等价于原始所有未选整数的完整似然。选择机制后续再单独改变。

对同一个 N，旧独立球面模型是新形状约束模型的松弛，因此

    J_independent(N) <= J_shape(N).

旧搜索下界可作安全剪枝依据，候选可作初始化。但新最优可能来自旧的
第三名及更后候选，不能只重排旧 top-two。新增跨历元约束会破坏现有
逐历元球面内核的可分离性。新连续内层及其界未证实前，报告实验候选
和上下界，不沿用旧1191次最优证书，也不沿用旧运行时间结论。

同一 gyro 既用于相对运动又用于主 EKF 传播时，载波输出与预测误差有
相关性。即使只用 gyro 选择整数、随后在固定 N 下重算载波基线，选择
依赖也仍然存在；“不回灌姿态”不能证明统计独立。

因此先验证载波前端机制，再推导条件于固定 N 的局部测量 Jacobian、
不确定度及与导航误差的交叉项。若需要，可按 BOUNDED_EKF_SCOPE.md
局部修改观测更新；无法处理的离散选择风险和跨时复用必须显式保留。
只膨胀 R 不能声称解决了相关信息重复使用。

## 5. 现有对照能证明什么

外部对照存在大误差，但“经典方法固定率差”这个概括不准确。
以下为已保存 BY2 表的诊断结果，不是本次重跑，也不是统一条件排名：

| 条件 | 数量/全窗历元 | 航向诊断 RMSE deg | 数量的含义 |
|---|---:|---:|---|
| EXT01 C-LAMBDA V2 | 980/1370 | 85.015472 | 完成搜索并返回候选，无固定验收；固定率 NA |
| EXT02 C-WLS V2 | 961/1370 | 85.179795 | wrapped 候选，无固定验收；固定率 NA |
| EXT03 ratio-fixed | 78/1370 | 40.062654 | ratio>=3 的固定标签，不是真整数正确率 |
| 官方 RTKLIB V1 | 154/1370 | 14.611254 | Q1 且方向有限 |
| 官方 RTKLIB V2 | 60/1370 | 4.511761 | fix-and-hold 输出，更稀疏，不能择优替换V1 |

误差是基线投影航向相对 Fixposition 融合 Euler yaw 的诊断；参考不独立，
也不是 EKF 融合后的航向。B/H 的 EXT01 可建模搜索均完成，大误差不能
归因于搜索没收敛。半周资格、SPP 前门、EXT02 整池拒绝策略等会降低覆盖；
共享模型错误也不能由两个方法相互一致来排除。未经物理资格核查，不能
把这些误差概括成文献方法不适合短基线。

当前载波的116/1191是100–340 s重叠窗口的初始准入；157/1200是测量
覆盖，145/1200是原生更新覆盖。旧1370历元为66–340 s，EXT01/02还仅
使用GPS L1单历元。输入、时间窗、验收与统计单位均不同，不比较百分比。

当前研究版同后端 PVT 向量对照 yaw RMSE=1.620834 deg，
密集载波版=1.937270 deg；后者 H 也未更优，微小 V 差不构成有效收益。
这不是当前载波超过已有强对照的证据。PVT 研究对照也不是原 V3 的同一
方法身份，不能以该数字替换原 V3 结果。

## 6. 近似前作与真正待证明的差异

有限定向检索，不是穷尽性新颖性证明：

| 已有内容 | 主要来源 | 对本提案的限制 |
|---|---|---|
| 固定长度 C-ILS 与动态实测 | [Teunissen / GPS Solutions](https://link.springer.com/article/10.1007/s10291-010-0164-x) | 短基线、长度约束、动态平台本身不新 |
| 无初始航向的陀螺相对转角辅助 AR、误差分析 | [Zhu et al., Sensors 2013](https://www.mdpi.com/1424-8220/13/6/7979) | 加 gyro 或消去初始yaw本身不新 |
| 姿态精度驱动的 PAR | [Castro-Arvizu et al., ION ITM 2022](https://elib.dlr.de/193961/1/ArvizuMedinaVila_ITM_2022.pdf) | 按航向精度选子集本身不新 |
| 多天线载波/惯性紧组合与错误固定恢复 | [Yoder and Humphreys, author preprint](https://arxiv.org/abs/2201.11776) | 组合惯性、AR与恢复机制已有完整系统 |
| 姿态先验的基线二阶协方差与单历元AR | [Sun et al., CJA 2025, author institution](https://research.polyu.edu.hk/en/publications/baseline-constrained-single-epoch-gnss-attitude-determination-usi/) | 只改先验传播不能泛称新的惯性辅助AR |
| 超短基线长度误差与数据驱动随机模型 | [Liu et al., Measurement, online 2026-08-19](https://www.sciencedirect.com/science/article/pii/S0263224126025686) | 只做长度误差修正加自适应权重也有近作 |

值得验证的更窄差异是：三维非固定转轴运动下、带有可解释相对旋转误差
集合的部分整数分离，以及适配动态支持的搜索/撤销规则。必须与普通
多历元长度约束、现有惯性辅助AR及相同验收机制直接比较。
“这些模块没人如此组合”只能是系统设计动机，不能作为唯一新颖性证据。

## 7. 下一轮只做有判别力的最小试验

A. 先核资格与机制：已知 N/b 的正向观测、坐标与相位/半周语义；
   冻结单一观测模型，比较独立球面与两历元运动约束。包含静止、绕基线轴、
   非共轴转动、偏置、时延、错误外参及故意错误的运动误差界。
   记录真整数是否被排除、错误整数是否分离、未决和运行代价。
   这只能验证机制，不以合成改善冒充实测收益。

B. 有区分力后再扩大：同源 Q/信号/支持/历元/计算预算，比较标准
   长度约束、普通PAR、惯性辅助及拟议方法。原生发表流程单独报告；
   接入统一验收流程时标明适配，不能重命名成作者完整复现。
   选择、运动约束、局部续接逐项消融，不一次改完所有模块。

C. 通过前端后再导航：同一后端替换方向提供者，既报告观测层，也报告
   全时段导航层。使用相同时间支持，保留失败、空窗及真实可用时刻。
   干净场景不以新尾部风险、H/V恶化换平均yaw；弱信号场景看可用率、
   航向尾部、恢复时延。工程有意义的容差先按任务需求预注册，不能按
   当前最好结果倒推。不要求每一段每个标量都严格改善，但退化要解释。

D. 独立留出：同一天多路线是空间变化，跨日是时间变化，不能相互替代。
   现有1月数据可作候选，先核传感器字段/同步/参考资格，且列明它此前
   是否已经用于开发。没有合格新数据时不声称跨日泛化。真实固定正确率
   需要整数真值或有据的独立验证，Fixposition参考不能代替它。

若 A 已表明错误先验代价大于候选分离收益，或仅增加延迟而无辨识收益，
停止扩大该支线，将负结果保留。若 B/C 只胜过弱对照却不改善强对照或
困难场景的完整性能，同样不将它作为成稿的新增主贡献。

## 8. 对 GPS Solutions 的判断

[期刊官方范围](https://link.springer.com/journal/10291/aims-and-scope)
覆盖 GNSS 系统设计、数学建模、算法及具有挑战性的应用。因此不需要
为投稿而更换整个滤波器；关键是 GNSS 测量或估计问题有明确推进。

上述三层结构比并列堆模块更一致，但目前无法据此量化录用概率。
优先补足第三层方法的真实差异、公平强对照、错误固定风险和留出实测。
若第三层未成立，沿用V3证据组织成稿，不能用拟议方法或负结果包装创新。

本次验证范围：文献与已保存源码/报告的只读核查、设计推导、文档链接与
Git差异检查。没有新增算法实现、求解、评估、参数扫描或真实数据测试。
