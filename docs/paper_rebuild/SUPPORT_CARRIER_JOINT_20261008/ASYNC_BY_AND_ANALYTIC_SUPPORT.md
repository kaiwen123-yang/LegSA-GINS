# BY 异步共同导航与支撑解析模型

本阶段推进一个共同 R/v/p/偏置/接触/载波图。三个候选创新仍是同一目标，尚未证明稳定超过冻结 V3；本文件记录实际进展与改变下一步的负证据。

## 已改变算法，而非新增独立航向模块

- 真实异步启动：有限过去窗口内的 IMU、足端、GNSS 天线位置/速度、原始 code/phase 均按实际时刻进入同一图。原始 PV 不搬到载波时间；没有 SDK 航向、未来航向回填或人工 yaw 先验。四个固定 yaw 初值只用于求解；无足够局部秩或尚无收敛解时输出 NO_INIT。有限初值搜索与局部协方差不认证全局方向覆盖。
- 同一支撑模型的解析误差：共同平移释放采用 e_i=R^T d_i-r_i-q_k，共同自由变量 q_k 无额外先验；每足原始 AR1 误差及旧 fixed 误差表达式继续连接。任何姿态迭代都满足相对几何等式。保留方向的条件分支同时保存 R/v/p/b 状态，供方向作用与历史修复的归因比较。
- 物理载波关系：在图内施加 DD 坐标恒等式，随快照和历史一起恢复；新弧不继承旧整数。多历元候选窗口用实际见过的 DD 生成森林整数基，只将 A 改为 A*T，原 y/B/Q 保持不变。改变参考星或可见卫星不再要求四包标签完全相同。关系秩不等于方向可观测秩。
- 恢复时区分可重试的空工作域与确实遗漏的历史候选；未完成求解、计算预算外假设不被叫作已物理排除。各模型只在相同原始行及预测进度上竞争。
- 评价仍在算法外：共同图直接输出导航状态，冻结 V3 评价桥接只改变输出格式/评价点，不反馈任何参考量。

## 为什么停止上一次完整模型比较

9faa97c 的 `cohort_predictive_qr_20261008_seed6100801` 已终止，保留 U0/U1 各1287行结果；未完成 U3、未执行 U2 不构成结果证据。诊断在同源0–1秒 common 分支发现所谓精确足坐标残差达0.03921米。GTSAM 的线性约束消元不足以保证非线性 LM 每次回缩后仍在可行流形上；调大约束权或降低检测门限都不解决表示问题。现改为上述解析误差，2→3→4→2足的相关似然与独立稠密模型一致，投影恒等式任意姿态下残差至1e-14。真实载波线性坐标的新变量也从物理可行初值建立。

固定支撑路径与9faa97c同源前6秒91事件逐点比较，p/v/rpy/bias/cost均无变化。修正后的完整同流四配置运行是 `cohort_analytic_20261008_seed6100801`；运行状态必须从其回执读取，启动不等于完成。

## 首次真实整数工作域为空意味着什么

100.198/100.398/100.598/100.798四包有19/18/18/18关系、三种标签排列，23个实际DD关系映为21维整数树基。浮点代价126.6976小于204.5465的工作阈值，但剩余77.8490整数度量预算内没有格点；1039个枚举节点完整耗尽该工作域，尚未进入长度或足端筛选。这不是运行超时、标签门槛或足先验太弱，亦不代表全局最佳整数成本已求出。记录见 `BY_FIRST_RAW_INTEGER_DOMAIN.json`。

下一项核心研究应在同一图内解释这个模型不支持事件：用更新前载波创新和锁时/半周/物理弧记录定位冲突；若有依据，仅释放受影响物理弧的整数限制为连续干扰量，保留原观测和完整Q，再检验剩余关系是否形成非空方向域及后续预测。没有定位依据时保留未决；不遍历子集直到成功，不用足先验把空域强制变成整数解。现有部分资格/撤销逻辑可复用，但不能从空域虚构可信方向。
