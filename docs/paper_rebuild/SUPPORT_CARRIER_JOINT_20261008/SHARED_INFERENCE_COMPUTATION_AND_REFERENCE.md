# 共同推断的计算复用与可回退参考

2026-10-08。实现阶段，长期 goal active。以下改动仍在同一个 JointNavigator / R-p-v-bias-contact-carrier 状态图内；未产生独立航向输出再反馈。

## 已完成的实质改动

### 已有平方根分解用于完整协方差查询

Gaussian 条件模型完成一次 QR 后保留 GaussianBayesNet。后续方向和外部预测所需的联合协方差通过选定单位列的转置三角回代得到，不再为每次查询重新消去整图。保留零方差精确坐标、全部交叉协方差及原线性化坐标；没有构造全逆、修改 Q 或添加先验。

GTSAM 的 backSubstituteTranspose 已包含条件噪声标准差，不能再次乘 sigma。边缘化后，旧分解对剩余变量的子查询仍是原分布的联合边际；下一次新增因子或改锚优化会替换分解。snapshot/restore 保留这个不可变分解。非 Gaussian 路径沿用原实现。

必要检查包括非单位 sigma、精确零约束、乱序 key、完整交叉块、边缘化、restore 和新增因子；与独立重新 QR 一致。48 段二维链加精确 alias，98 维图、6 维查询、30 次重复：复用分解 0.13464 ms/query，重新 QR 0.77145 ms/query，约 5.73 倍；协方差最大绝对差 8.53e-14。**这是查询核函数，不是完整导航加速倍率。** 每模型优化仍有一次 QR，模型数量 M 仍会增长。

复现入口：`tests/paper_rebuild/test_joint_linear_conditionals.py --chain-length 48 --benchmark-repeats 30`，在仓库根目录设置 `PYTHONPATH=src` 并使用登记算法环境。

### 修复后的条件历史进入后续共同线性化

上一事件发布的非线性条件轨道，在下一事件先推进到与原固定接触背景相同的证据前沿，再提供当前 bootstrap / step / conditioned 锚。其余 Gaussian 条件模型实际使用这个修复后的共同状态线性化。过去的锚、已累计预测分数和已发布输出保持其实际历史；选择新锚不是新观测。

原 fixed 和所有其他解释继续保留，可以重新选择 fixed。shared 路径不进入旧的 adopt / clear 流程，避免把一次工作选择变成不可回退的源裁决。输出分别记录当前事件实际使用的 `common_linearization_reference_used` 和供下一事件使用的 `next_common_linearization_reference`。

三事件调度验证中，先显式选择一个已完整非线性重建的轨道，随后验证它确实成为另一 Gaussian 图的共同锚、每条外部行只计分一次、下一事件实际返回 fixed。该检查隔离调度正确性，**没有证明自动失效检测或导航精度收益**。对应 `test_joint_shared_reference.py`；根部在两个实现合并后再次运行该项，通过。

该版本仍是一个额外共支撑组的条件解释族。禁用不可回退清空后，不能借 generation 递增冒充已覆盖组合多故障。下一步需要可回退的组合源策略及依赖，不能任意删除旧模型。非线性分支也是优化状态加线性化协方差的预测高斯近似，不是精确非线性积分后验。

## BY 测量模型的实际新证据

固定 100.198--109.998 s 的 50 包数据，保留 840 码行并形成 799 个同弧相位时间差，严格消掉 41 个常整数坐标。保留共享 pivot、差分复用原包的跨时间协方差，并允许每包独立三维基线。

原模型下 cost=2834.932，对应自由度 1489；相位差分 cost=2175.695，原模型零假设期望 651.992。超差不能只归因于常整数选错。2280 条接收机信号记录、100 个 RAWX payload 与原数据一致，原 DD Q 重构逐元素差为零，没有发现这一窗口内的字段或单位构造错误。

这还不能区分白噪声幅度低估与时间相关相位误差，更不能拟合一个任意常偏置来取消整数性。完整记录为 `BY_PHASE_TIME_DIFFERENCE.json`。

下一步已限定在 BY 开发数据：110--170 s 校准、180--240 s 检验。比较原 Q、由实际 SD/DD 结构映射的附加白噪声、有限相关时间的物理信号相位误差。参数通过消去几何与连续整数 nuisance 的 restricted likelihood 确定，不使用最佳整数、参考轨迹或通过率调参。误差状态的物理 signal 身份独立于整数弧，整数 slip 不自动重置它。详见 `BY_NOISE_CALIBRATION_PLAN.json`；此处仅预声明，尚未得到校准结果。
