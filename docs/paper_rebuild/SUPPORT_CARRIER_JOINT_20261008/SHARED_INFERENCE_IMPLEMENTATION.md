# 共同线性化支撑推断：已接入同一导航器

2026-10-08。实现阶段，完整机制与导航收益仍未验证；长期 goal active。

当前 `--support-inference shared_linearization` 已接入合成和实测两个运行入口的同一 `JointNavigator`。正常背景仍联合优化 R/p/v/bias/接触/载波；竞争支撑解释沿相同物理变量的线性化锚用 Gaussian QR 推进，不逐解释运行 LM。原 full_nonlinear 路径保留作在运行对照。没有增加独立航向模块、额外先验、噪声下限或新观测。

这是共享推断设计的第一步：**已移除常态每解释的非线性 LM，但每解释仍保留 Gaussian 图和 QR**。尚未实现全部叶因子/消元消息共享或统一低秩存储，M 及恢复档案仍会增长；不能称已经达到长期有界实时性。

## 实际实现

- `JointWindow` 保存共同锚、真实 QR 增量、平方根因子、目标常数及全部交叉信息。边缘化在原锚上 QR，snapshot/restore 保留高斯坐标。不能用姿态 retract 后再 Log 恢复增量：大于 pi 时会改变高斯均值。
- `NavigationBranch` 按事件 X/V/B、物理接触 arc 和整数 label 映射共同锚；私有 nuisance 和未包含的历史状态明确标出。不同真实启动模式有独立 chart ID，不能仅凭空 integer lineage 合并。异步共同锚 bootstrap 用一次 Gaussian QR，不重复四种子 LM。
- 外部预测按共同锚的 h0+J delta 与完整 anchor covariance 计分，同一原始行先预测后消费。物理方向协方差用同一坐标推到短基线切平面；普通条件均值坐标与共同锚坐标不能重复运输。
- 背景被当前条件支持集排除时，从竞争解释首次使用前的 checkpoint 重建真实非线性历史，并沿原始评分行账本重新计算共同状态与预测证据。若复核后赢家改变，继续复核新赢家。已展开解释随后按非线性路径推进。
- 未展开解释仍标为非线性未决。Gaussian 分数不构成严格非线性排除，完整性字段不沿用 true。缺共同 chart 时保留未决身份；对齐检查同时比较状态时刻和预测证据前沿，不能在纯足/IMU事件发布旧时刻状态。
- 原始事件与锚的有限运行档案支持超出30秒的按需重建；其存储尚不有界。原足 AR、共同平移释放、相对几何释放、物理整数条件及未受影响的足约束继续在同一个估计器内。
