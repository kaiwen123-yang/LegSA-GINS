# 完整联合算法与长期执行计划

2026-10-08，执行版 v1。以用户讨论稿为基础，经本轮源码和联合模型审查修订。工程设置先用 5 s 固定时滞、约 10 Hz 关键状态、高频完整 IMU 预积分、30 s 可回放历史、4 个活跃连续分支；这些是初始预算，不是理论保证。

## 1. 一个估计目标

状态为每关键时刻的 `X_k=(R_k,p_k), v_k, b_k=(ba_k,bg_k)`，每支撑弧的世界点 `c_ia`，每物理载波弧的整数关系/未决浮点自由度。每个假设 h 有自身条件状态和边缘化先验：

`J_h = J_history,h + J_IMU + J_code/carrier,h + J_support + J_GNSS`。

共同位置、速度观测包含正确物理点和杆臂；方向只通过 `R_k b_body` 进入，不能另装输出 yaw 修正器。足点和 IMU 在同一目标中各出现一次。候选提出过程可以用原始载波松弛；不能将其拟合基线产品再与相同原始行独立融合。

沿用现有 EpochBlock 的**实际字段约定**：`y = A N + B (R b_body) + noise`。讨论稿中 A/B 的符号仅为示意，接入时以代码定义为准。保留完整 Q、星座/频率、参考星变换和物理单信号弧身份。

IMU 使用 GTSAM 预积分，并显式连接偏置随机游走或使用 CombinedImuFactor。仅添加 ImuFactor 不会自动建立跨时偏置演化。

## 2. 支撑与信息资格

`e_ik = p_k + R_k r_ik - c_ia`。接触点用当前状态变换足点作为**初值**，不给这个初值另加独立强先验。接触开始/结束在物理事件时间建节点；正常离地结束未来使用，历史有效信息保留。没有真实重叠支撑时不编造桥接。

同弧足点误差具有时间相关性。首版用明确相关时间常数的三维误差过程或等价块白化表达，测量尺度保留既有约 1 cm 工作量级；不靠 IID 高频累加或缩小噪声制造方向收益。误差过程是固定协方差的测量模型，不是任意吸收运动的滑移状态。SDK足点仍是高层代理。

共同/差分量来自同一原始足点块；使用可逆变换和完整协方差。释放共同平移应由共同移动模型及其证据决定：自由三维共同位移消元会同时失去共同 Z，不能按误差结果删 XY。差分几何失配再撤回相应方向分量。

足力决定接触证据，几何与共同运动判别固定接触假设。在线估计器看不到真值故障标签。对无法区分的共同滑移与机体运动，保留不可辨识结果；不把一致性判断伪装为独立真值。

## 3. 方向支持与多解

未知世界接触点、IMU 与足端自身具有全局 yaw 规范自由度。新增方向信息只能在已有绝对锚、共同 GNSS 运动观测和足式激励的联合模型下解释；纯全局旋转不同的等价解不能被无锚足端排除。以消去接触点、位置、速度、偏置、浮点整数后的方向信息和候选支持评价可辨识性。

保留部分关系 `C N = m` 时，对其余零空间浮点自由度联合求解/消元；不能取整补全。候选成本由当前窗口原始因子与每个假设自身历史先验计算，不能每次滑窗再累乘重叠证据。条件联合成本不是已校准完整性概率。

4 个分支是优化预算，不是全部支持。候选未搜索完或仍有分离方向时，输出未决/多分量，不能截断后宣布唯一；不平均出小方差 yaw。保留被支撑或先验排除候选的来源依赖及可再生成描述。

## 4. 固定时滞与撤销是一套状态管理

姿态/速度/偏置按 5 s 滑动。活动接触点和长载波弧变量按**最后使用时间**管理，跨窗保留相关性；不能因出生时间超过 5 s 自动消掉再以同 ID 插回。每个方向分支单独保留条件先验及边界线性化点。

失效发生/来源时间与失效证据到达时间分开。失效后：

1. 根据证据撤销或改换受影响支撑分量。
2. 恢复被其限制的候选集合，保留独立载波行及仍有效物理关系。
3. 窗内重算共同状态；已入历史先验则从首次污染前检查点重建。
4. 重放当时实际可用的原始事件，修复**当前状态**；已发布在线轨迹不回写。

30 s 原始缓冲需要配套未污染检查点、候选/弧身份/边缘化状态及依赖索引，只有原始缓存不够。超出可恢复历史的失效要报告剩余污染/恢复范围，不能称精确撤销。正常换撑不触发这条回撤链。

## 5. 数据分工和比较

| 数据 | 本阶段用途 | 参数政策 |
|---|---|---|
| BY（现有正式主序列 BY2；其他 BY 输入核实后明确登记） | 开发、源内噪声/时间模型及调参 | 不用 trace 选择参数；保持源内物理标定与离线评价边界 |
| BYO/BYH（现有标识 BY2O/BY2H） | 参数冻结后的测试 | 两者不参与本阶段调参/阈值选择 |
| XB 系列、NMB 系列 | 实机恶劣条件测试 | 同版本同参数；保留实际 NO_INIT、无支持和失败 |
| 连续物理合成 | 真值速度、候选真值及失效机制归因 | 预设场景/噪声种子，在线无真值标签 |

BYO/BYH/NMB 的旧结果已经被看过，不能声称从未见过的盲测。新阶段做的是预先冻结参数的测试；若测试暴露模型缺陷需修正，公开记为新开发迭代及重新冻结，不隐瞒反复使用。

四机制配置必须消费**同一份含故障原始流**：U0 采用 full-only 策略且无足点；U1 加整段支撑；U2 加部分关系/存活信息；U3 加历史撤销重建。“完整载波”指 U0 的消费策略，不是给其无中断观测。U2/U3发现失效时都停止未来坏辅助，区别仅是否修复过去影响。

机制组共同 GNSS/IMU、初始化和可用性完全相同，统一不独立叠加高层 SDK RP/速度。常驻 SDK 竞争配置用相同后端、载波和 GNSS/IMU，以 SDK 来源替换足点；冻结 V3 使用原版本数据和其真实输入政策作系统锚。后端和来源不等价时如实标注，不能将差异归为单一因子收益。

## 6. 四个连续交付

| 阶段 | 同一个算法增加的能力 | 必须交出的结果 |
|---|---|---|
| M1 联合运动求解 | 共同 R/p/v/b、整段接触点、原始码/载波关系和完整 IMU 进入同图 | 可运行转弯/换撑连续过程；足端与载波对共同状态的作用；自定义 Jacobian、规范和唯一计权数学核对 |
| M2 方向假设联合判断 | 现有枚举器提出候选、分别优化共同状态、保留部分关系和必要多解 | 相同观测下足式历史具体改变哪些方向支持；变化可追溯到足端因子，保持无锚 yaw 自由度 |
| M3 完整中断及撤销 | 部分/全部相位中断、新弧获取、窗外先验重建、候选恢复 | 约90秒完整过程四臂；一个固定实例后另两个预设噪声实例；超5秒迟到失配的当前状态恢复及有效载波保留 |
| M4 同版本实测 | BY开发后冻结，BYO/BYH、XB/NMB测试，SDK/V3比较 | 同版本支持/误差/失败全表，说明是否有采用价值；不能混用各旧版本最佳值 |

每阶段代码、运行命令、紧凑数值和结论一起提交推送 GitHub。研究后端内部可以按职责分文件，但不交付彼此不进入共同估计的独立创新模块。数学检查只覆盖会改变科学意义的 Jacobian、规范/秩、信息唯一计权和撤销等价性；不扩展无关全仓保护测试。

## 7. 第一张过程图和完成判据

同一时间轴展示：(a) 支撑身份、载波物理弧及故障证据到达；(b) 方向候选支持/可用状态；(c) 航向与不确定性、误差；(d) 共同速度/位置误差。合成真值仅离线评价，实时主曲线是当时发布的因果结果，回放修复曲线另列。

90秒过程包括有效初始化、倾斜转弯、多次换撑、部分丢失、全相位中断、新弧恢复、迟到支撑失配及一种不可辨识共同运动。基线采用实际 0.35 m，足点噪声不优于现有工作尺度。

成功需同时回答：足式确实增加方向信息；错误辅助能撤回且独立有效信息留下；共同导航有可归因收益。合成可以报告真值速度精度；实测仅报告速度状态作用/来源一致性和相对参考位置航向。误差、尾部、覆盖、最长空窗、恢复时间一起报告，不靠少输出换低 RMSE。不以预设空泛5%门代替机制证据，也不因为局部失败退回无限诊断；修正核心模型再运行同一过程。

## 实现基础

- [GTSAM BatchFixedLagSmoother](https://borglab.github.io/gtsam/batchfixedlagsmoother/)：按时间戳边缘化、批量 LM 和边界一致性机制；不属于本研究创新。
- [GTSAM ImuFactor](https://borglab.github.io/gtsam/imufactor/)：高频预积分连接共同位姿/速度，偏置演化需要额外建模。

优先使用 GTSAM 已有求解和边缘化。首个可执行纵向实现可用其 Python 绑定连接现有 Python 前端；若剖析显示自定义因子成本主导，再将相同残差迁移 C++，不为框架迁移另造一套算法。
