# 首轮完整过程与未完成主链

2026-10-08。用户纠正后的交付单位是一个完整的支撑弧—载波弧联合导航算法。90秒过程、四配置和过程图共同构成首项研究成果；短片段和因子实现只是内部工作。本文件记录实际进展及失败，不宣布首项研究成果完成。

## 已经接通的完整估计过程

`JointNavigator` 消费原始事件，所有条件方向分支在同一5秒固定时滞模型中估计姿态、位置、速度、偏置、世界接触点及物理载波弧关系。载波残差使用 `R b_body`；足端使用同弧世界接触约束及时间相关误差；高频IMU完整预积分。条件方向通过共同状态影响导航，没有额外的输出航向修正器。

底层优化、线性化及部分消元均调用GTSAM。4.2的Python批量固定时滞封装缺少当前所需的完整检查点访问，因此这里使用GTSAM LM、Gaussian partial elimination和LinearContainerFactor构造可回放窗口；没有重写通用优化器。先验保留交叉协方差、线性化点和用于分支比较的代价常数。

同一原始流下，U0采用完整相位消费策略且无足端，U1加整段支撑，U2加部分关系与存活保持并在发现失配后停止未来错误辅助，U3再重建过去已经消费的信息。真值与故障标签只进入离线评价。主曲线保留当时发布的因果输出。

## 下一步仍是同一个算法

1. 以已经完成的来源纠正后四配置为共同背景，在同一估计器中完成方向支持/接受与支撑模型判别；用尚未消费的独立观测比较固定接触、共同平移释放、相对几何释放模型，并累计后续真实证据。单点NIS不是这项研究的最终方法。
2. 完成按受影响支撑弧的分量撤销。目前共同转差分只处理四足组合，会在部分换撑区间丢失仍有效信息，甚至把同组未受影响足的平移联系一起释放；必须在同一图中保留未受影响足、两/三足有效差分及跨子集相关性。当前不能声称所有有效分量均保留。
3. 足式辅助需实证改变方向支持或使用资格。本例新弧在55秒后已条件化，坏支撑64.8秒才进入；77秒重建没有实际检验被坏支撑排除的整数候选复活。当前检测也只覆盖持续四足共同平移失配，尚不覆盖正常离地后才到达的证据和相对几何失效。
4. 补齐上述主链后，再运行另外两个预设噪声实例；随后BY开发冻结，BYO/BYH测试，XB/NMB恶劣条件测试，保持同后端SDK来源方案和冻结V3为竞争对照。NMB自然无新增载波区间不承担载波恢复证据，实测速度无合格真值不能报告精度提升。

这是联合原型的主链，不再另立“更新次数”“NIS诊断”或单独方向模块作为交付目标。每一项代码进展可提交推送，只有全部机制证据和共同导航作用成立才算首项研究成果完成。
