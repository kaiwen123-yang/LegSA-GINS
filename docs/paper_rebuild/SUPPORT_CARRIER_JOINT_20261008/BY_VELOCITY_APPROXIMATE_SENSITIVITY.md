# BY2 近似安装尺寸下的离线速度评价

已完成的 native-increment 05 U0/U1，与原 V3 RUN_00004 在共同有效区间 100.198–106 s（5.802 s）比较。请求窗为 96–106 s；前 4.198 s 的联合算法 NO_INIT 保留，不记零误差。本结果早于新的 source-noise 校准。

用户提供 IMU 在 VRTK 下方约 30–35 cm、基本垂直。官方 [FP_A-TF 定义](https://docs.fixposition.com/fd/fp_a-tf) 给出 VRTK 的 X 前、Y 左、Z 上；实际 BY2 的 301 条 POI→VRTK 变换均为单位变换。采用 r_POI→IMU=[0,0,−h]，h 为 0.30、0.325、0.35 m。水平零偏移与安装轴近似对正均未测量，未知误差界；这些尺寸是用户近似说明，不是精确外参或置信区间。

参考采用 ECEF pose 与 POI twist，执行 v_IMU=R_ECEF←POI(v_POI+ω_POI×r)；U0/U1 和 V3 均使用原生 IMU 点速度。每次参考仅由独立离线子进程打开一次；没有重跑导航、没有位置差分造速度、没有时移拟合，也未改变冻结的位置／航向评价。

32.5 cm 时，U1 相对 U0 水平／三维速度 RMSE 分别降低 0.002228／0.002195 m/s；三尺寸排序一致。U1 水平优于原 V3，但三维仍较差。仅垂直尺寸变化就令 U1 水平 RMSE 跨度达到 0.019075 m/s，明显大于本次足式增益；未知水平偏移及安装角误差未被这个尺寸范围覆盖。

这说明短窗内存在小幅速度改善迹象，尚不足以证明持续稳定收益。足端约束也直接作用于速度，因此不能把这里的差值全部归因于航向改善。原 V3 延续 66 s 起的历史状态，而 U0/U1 从 96 s 冷启动；三者初始化条件不同。Fixposition 与算法共享 GNSS 来源，仍是同源融合参考，不是独立真值。

完整 BY07 在本次评价时仍 RUNNING，没有提前评价。下一步复用同一离线桥评价完成的长轨迹；不再重启这些短窗导航。完整数值、来源及结果哈希见 BY_VELOCITY_APPROXIMATE_SENSITIVITY.json。
