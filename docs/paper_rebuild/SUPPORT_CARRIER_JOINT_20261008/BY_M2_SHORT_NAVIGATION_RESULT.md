# BY M2 短窗导航结果：航向和位置改善，速度收益尚未出现

本记录只汇总已完成的 `BY_M2_NATIVE_SHORT_08_U1` 与离线评估输出，运行版本为 `b5adc7a6b5557b106950733296de2e593842870f`。未运行导航、未重新评估、未读取原始参考载荷，也未调整任何参数。

请求区间为 **96–106 s**；M2 与旧 native05 U1 都只有 **100.198–106 s，共 5.802 s、190 行有限状态**，另保留 **135 行 NO_INIT**。以下均为这个共同物理区间的时间加权 RMSE。

| 指标 | 旧 native05 U1 | M2 U1 | 冻结原 V3 |
|---|---:|---:|---:|
| 航向 / deg | 3.932426 | 1.714091 | 1.160812 |
| 水平位置 / m | 0.048038 | 0.040057 | 0.038114 |
| 3D 位置 / m | 0.113787 | 0.111802 | 0.051799 |

M2 的航向误差比旧 U1 降低约 2.218°，水平位置降低约 7.98 mm，3D 位置降低约 1.98 mm。**原 V3 在这三个指标上仍更好。**旧 U1 与 M2 属于同一研究后端的版本比较，多个源文件发生变化，不能把全部差值归结为独立的噪声模型或足式贡献。原 V3 还保有从 66 s 开始的连续历史，而两个短窗 U1 从 96 s 启动，因此跨 V3 比较属于系统比较。

| 速度 RMSE / m/s | 旧 U1 | M2 U1 | 原 V3 |

M2 相比旧 U1 的水平和 3D 速度误差分别增加约 0.000138、0.000230 m/s。**本短窗没有证明航向改善带来速度收益。**航向与位置同时改善也不是独立的航向中介因果证据。速度点位几何是用户近似值；Fixposition 融合参考共享 GNSS 来源，不能作为独立真值。

100.798 s 的首次提案使用 100.198–100.798 s 的原始块：完整枚举得到一个候选，其物理整数基秩为 21，且这 21 个整数条件实际进入了共同图。完整相关 Q 下，原始代价下界为 115.447571，可行上界为 116.128368，低于保持不变的工作门限 204.546546。这里证明的是**有限 Gaussian 工作域内有可行候选**；不是假固定率保证、全方向覆盖或正式 AR。该次局部球面优化也未声称全局最优。

全短窗只有 **24 行完整工作支持**。随后多个提案耗尽 20000 节点枚举预算，末态 `active_support_complete=false`；这些未搜完的解释没有被当成科学排除。固定 M2 的 τ=2 s 是 BY 标定工作域的上边界，概率校准仍未完成。
