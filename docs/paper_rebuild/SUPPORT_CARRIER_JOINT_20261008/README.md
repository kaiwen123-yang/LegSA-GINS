## 当前主线：完成结果与模型修正

完整算法目标仍未达成，当前最关键的问题已从“是否接通”推进到“失效模型是否保留了有效信息”。[同源完整90秒](SEPARATOR_90S_SAME_SOURCE_RESULT.md)证明足端整体改善位置/速度，但失效撤销没有发生。两条[完整非线性条件历史](STANDING_SUPPORT_RELEASE_DIAGNOSIS.md)进一步确认：整弧释放会丢掉短时滑移前后的有效平移约束，使P/V中断期间漂移更大；不能靠降低门限或增加组合强行得到成功。

下一步唯一模型主线是[弧内有限共同滑移及同源预测证据](TIME_LOCAL_SUPPORT_MODEL_PLAN.md)：在共同导航图保留接触几何与原足AR误差，加入有限位移/速度过程；用未消费足观测和外部观测的联合预测评价解释，再从受影响历史重建。此方案尚未实现或标定，不算第二项创新完成。

实测入口已修正：[流式原始载波](BY_CAUSAL_CARRIER_PROVIDER.md)将首个合法块由100.198提前至74.398秒；[实际统一早期导航](BY_CAUSAL_EARLY_NAVIGATION_RESULT.md)在67秒通过原局部资格输出状态，实际消费足约束、载波与条件整数关系。该15秒共同评价仍落后V3。[原噪声完整BY结果](BY_NATIVE_FULL_NAVIGATION_RESULT.md)则有小幅航向改善但位置更差，尚未实现航向对共同导航的稳定净收益。冻结M2的完整BY仍运行，不能拼接不同版本为同一完整算法成果。

[连续策略路径](SOURCE_POLICY_PATHS.md)已实现完整历史组合及可撤回参考，但尚无连续多故障导航收益。两条旧实现广泛长跑已被当前完整90秒及定向诊断替代并明确中止，原记录保留；实际状态及唯一正在运行的完整BY见 [GOAL_PROGRESS.json](GOAL_PROGRESS.json)。下面的开工审查保留为历史，不代表当前实现。

### 当前证据不能遗漏的正、负结果

- 同研究后端 FULL→ROLLING 的 BY2/BY2H/BY2O 航向 RMSE 为 3.0436→2.6211、2.2695→2.2342、3.8657→3.5512 度。最长无方向输出仍为 35.8/46.6/104 秒。这不是与 V3 的胜负结论。
- BY2O 足点实际接受 1157 次；同 SDK 抑制政策的 REPLACE_NULL 对照下，航向改善约 0.089656 度、水平 RMSE 改善约 1.402 mm，尾部未一致改善。
- 受控迟到失配的 0.5 秒重放，73 行 NAV/STD/IMU 误差导出与从未消费足因子的对照一致；独立 partial 重新计算并保留。现有前端没有足端筛选整数的依赖，因此这不等于已恢复被足端排除的整数。
- 最新 BY2O 31.8 秒**位置产品中断**保留速度、Doppler 等输入。partial 降低航向 RMSE 约 10%，共同速度、位置和偏置发生实际改变；足式替代背景 H 约 0.790 m，SDK 背景约 0.398 m。不能继续把平移冲突解释为航向链没接通，也不能把全部差异归因于足点，因为替代政策同时改变 SDK 消费。
- NMB1 自然 163 秒缺口，同替代政策 NULL→XYZ 的 Up RMSE 26.391→1.147 m，H 5.550→7.991 m。既有足点模型包含有用信息及明显水平冲突；不能按评价结果只保留 Z。

这些是已完成旧研究版本的证据，不能拼成新算法的结果。真实数据使用 Fixposition 融合参考，不是独立真值；真实速度没有合格参考，速度状态作用不能称为速度精度提升。
