# 共享条件推断：下一步最小改造

状态：设计，未实现、未验证。目标是在原 `JointNavigator/NavigationBranch` 内改变推断组织，不增加独立辅助航向模块，不改变真实足观测、原始噪声或共同导航状态的物理定义。

当前每个实际共支撑组产生两个完整 shadow，且每个事件分别非线性优化。正在运行的旧全 shadow U3 日志已推进到 20 s 附近、约 224 个模型，但 rows 在终端完成时才保存；**不能把它写成已完成、已可读取的前 20 s 对照**。应保留该进程实际加载版本的源文件、参数及输入哈希；当前工作树快照不能冒充已加载源码。已有 U0/U1 不重跑。

## 1. 一个方案：共享非线性图，保留全部条件解释的平方根信息修正

每个实际整数 lineage 保留一个背景非线性图。实际共支撑组仍按输入的 arc ID 和共同观测关系建立；前后脚出生时间不同也不拆掉其共同失效解释。每个组保留 fixed / common-translation-release / relative-release 的身份、首次使用、依赖和证据，常态通过共同线性化图计算条件预测；只有需要不同非线性历史的解释才从首次使用前重建。

足观测仍在共同姿态、速度、位置和偏置图中。可用统一的概念残差表示：

`e[j,k] = R[k]^T (c[j] - p[k]) - z[j,k] - u[k] - d[j,k]`。

- fixed：`u=d=0`，保留原固定接触约束。
- common release：释放组内共同平移 `u[k]`，保留持续的足间几何；相对方向信息仍能约束姿态并通过共同状态影响 v/p。
- relative release：再释放足间变形 `d[j,k]`，用无冗余的对比坐标表示，避免给 common translation 重复自由度。完全释放后的该组足观测不再约束导航，但原始观测和依赖仍保留。

这不是新增强先验。nuisance 的规范自由度通过坐标选择消除，不用很大/很小的人工方差代替释放。背景中未受影响的脚继续参与测量与约束，重叠组的替代关系沿用当前 `_candidate_policy`，不能叠加两份同源信息。

## 2. 小推导与实现边界：只做平方根消元，不做 Hessian 相减

在一个固定共同线性化历史上，将原足 AR 联合残差白化，写成：

`r_F + A_F δx + B_m η_m`。

`B_m` 是模型释放的 nuisance 列；common 模型每次共同观测只有三维公共平移列，relative 模型另有足间对比列。原 AR 链 `e_k - rho e_prev` 必须同时作用于状态和 nuisance 列，保留历史相邻脚误差的相关性、原 whitening 和原 sigma；不能按 epoch 独立投影后再捏造脚噪声。

对 `[B_m, A_F, r_F]` 作秩揭示 QR，消去自由 nuisance，保留下方作用于 δx 的平方根残差。这等价于投影到 nuisance 列空间的正交补：fixed 不删信息，common 仅撤共同平移方向，relative 进一步撤相对方向。

解释上可写 `H_m = H_0 - V_m V_m^T`，其中 `V_m=A_F^T U_m`、`U_m` 张成白化 nuisance 列空间；**实现不能用这个式子直接相减 Hessian、求逆或修负特征值**。应在原 Jacobian/平方根因子上作局部 QR 替换，保留约束零行与秩信息。

历史边缘化后不能直接从一个混合 Schur prior 中减去“脚的对角信息”。需保存源因子到消元消息的依赖：改变某组时，替换相应叶因子并沿受影响的消元路径重新 QR；没有改变的消息共享。旧变量、结束的足弧及 nuisance 可以消入当前共同 separator，但必须保留全部交叉块、线性化锚和目标常数。该源的影响于是表现为当前 separator 上的条件均值/信息修正，而不是永久保留一份非线性轨迹。

每个解释保存导航/方向预测所需的小矩阵量及累计证据，不常驻一套完整 LM 图。常态每事件每整数 lineage 一次背景 LM，解释间的更新是 Gaussian 消息传播和必要的局部 QR。低秩仅在实际修正秩较小时带来收益，长支撑或宽 separator 不保证始终小秩。

## 3. 比较和资格：全部解释仍参与，未展开不等于排除

同一外部事件先预测、后消费。所有模型在相同 `row_ids`、相同共同线性化和完整声明协方差下形成 `predicted_mean, S`，累计一次 `r^T S^-1 r + logdet(S) + n log(2pi)`；沿用已冻结的工程模型代价和支持宽度，不把它称为校准概率。不得把反复滑窗拟合 cost 累加为独立证据。

此计算对**指定共同线性化的线性高斯模型**是精确的；相对于当前每个 shadow 各自重新线性化、优化和边缘化的算法是近似，不能宣称逐状态或逐决策等价。

每个未展开解释仍保留模型身份、源依赖、整数条件、预测 score、条件方向及 `COMMON_LINEARIZATION_ONLY` 标识。它在线性条件支持集内时必须进入方向并集；在线性支持集外只表示该近似图暂不支持，不能自动变成严格的非线性排除。不得只验证赢家，就把其余近似模型宣布为已排除或输出“唯一非线性解释”。完整性必须写明 scope；原来的全非线性完整性不能沿用为 true。

多个整数 lineage 分别维护背景和修正统计量，不把整数均值化或因一个接触模型的高分而丢掉其他整数方向。原枚举/分支预算不足状态继续保留；支撑推断加速不能填补整数枚举缺口。

## 4. 按需非线性展开与真正的历史撤销

优先展开当前背景被线性条件支持集排除时的竞争解释，以及可能改变方向使用资格的竞争解释。检查候选均值上的实际非线性残差与线性预测是否一致，作为额外展开信号；这只是误差诊断，不是未经证明的全局界。展开调度预算是计算预算，不能充当科学排除阈值。

展开从受影响源**首次使用之前**的 checkpoint 开始，读取原始事件，替换对应历史足约束，重做共同 p/v/R/bias、整数条件及外部预测证据。验证 score 替换相应历史段，不再把同一外部事件额外累计一次。只增大未来 R 或停止未来脚输入均不算完成撤销。

重建出的 clean conditional state 可以成为当前发布的条件导航状态或下一阶段的工作线性化锚；这不等于该解释已被全局唯一接受。其他仍未分辨的解释保留方向并集与未决身份。重新定锚时需建立新的共同线性化 generation，按依赖传播/重建其条件统计量，不能将不同锚、不同证据定义的 score 混在一起比较。

只有竞争解释被同域展开，或另有真实可验证的误差界足以排除它们时，才可声称全非线性唯一接受。本轮设计没有假定这种界已经存在。

## 5. 长期成本仍有未解决项

30 s 后仍受支持的源解释不能删除。其当前历史影响可以压缩到 separator 上的条件量，原身份和证据保留；若以后需要非线性恢复，仍依赖原始日志索引及首次使用前的 checkpoint，不能从少量低秩统计量恢复任意非线性历史。

低秩表示**不使模型数量 M 有界**。当前支持家族若不断增长，仍有每次外部事件约 `O(M * C_small_QR)` 的比较/传播成本，以及每解释修正、证据和依赖存储；长期原始日志/恢复记录也随数据时长增长。局部修正秩增大时，`C_small_QR` 也会增大。非线性重建另付实际受影响历史的代价，必须计入总耗时，不能从性能报告中扣除。

只有完整未来相关 separator 分布、后续因子作用及整数条件确实相同的解释，才可共享一个计算节点并分别保留身份/历史 score 常数；“离地”“均值接近”“超过 30 s”均不足以证明等价。若持续 M 增长让事件处理落后，必须报告比较 frontier 尚未追上及实际存储/时间增长，不能通过静默丢模型宣称实时。因此这是去掉 M 倍非线性主项的最小推断改造，尚不是长期有界实时性的证明。

## 6. 一个可证伪的连续实验

保留正在运行的旧全 shadow U3，待它实际落盘后复用其前 20 s 的模型/方向/score/事件记录作为参照；保留匹配运行哈希的原源码。若最终没有有效输出，这部分只能标为不可用，不能用进度日志替代。已有同输入 U0/U1 直接复用。

随后只运行一次新流程，使用同一冻结合成 90 s 事件流、实际支撑拓扑、噪声和参数，从起点连续走过原来的支撑失效及载波中断/恢复，不另造场景、不在 20 s 重新初始化。前缀核对共同线性近似与已落盘全 shadow 的差异，后段检查按需历史重建的实际作用。它仍是合成机制实验，不能叫 BY 实测收益。

执行前冻结比较口径，至少记录以下可证伪量：

1. 实际模型身份和外部 row 资格是否全保留；被旧全 shadow 支持而未展开的解释是否仍明确未决，有无虚假唯一接受。
2. 共同线性化预测 score/方向与可用全 shadow 对照的差异，以及这些差异是否迫使大量模型展开；若几乎全部展开，推断改造没有达到目的。
3. 常态 LM 次数是否随整数 lineage 数而非 M 增长；总耗时须包含全部重建，同时记录 M、修正秩、separator 大小、内存/日志空间和证据 frontier 的增长。
4. 失效后是否实际删除历史依赖并重建共同 p/v/R/bias，仍有效的相对方向是否保留；观察位置/速度变化时区分足的直接约束与航向经共同状态传递的作用，不能把状态差直接称为精度收益。

前 20 s 若没有失效/撤销事件，只能检验筛选近似和计算组织；撤销能力必须由后续同一连续事件流的实际行为支持。该实验失败时收缩结论并修改推断组织，不增加一圈数据矩阵掩盖问题。
