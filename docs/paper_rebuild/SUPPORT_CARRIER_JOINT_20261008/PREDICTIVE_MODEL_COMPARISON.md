# 联合预测支撑模型竞争：本轮运行前约定

2026-10-08。接续 `0c7e3b3`，本轮将已经验证的分量模型接入同一 `JointNavigator`，替换“四足、五秒、单点 NIS”工作触发器。以下决策代价在完整运行前固定，不根据本实例是否触发调整。

## 同一算法的推断规则

- 从实际合格足弧的共支撑拓扑登记曾出现的集合。两、三、四足均可进入，不按弧出生批次拆开共同支撑。它们是竞争失效解释，不是独立证据。
- 对每个集合，从首次使用前的共同检查点建立共同平移释放与相对几何释放条件状态。集合外足保持已有模型；模型保留同一 IMU、GNSS、载波及整数谱系。离地后继续接收独立外部证据，直到既有恢复域过期；已经受支持的条件状态继续保留。
- 每条整数谱系独立累计尚未消费外部行的 `r^T S^-1 r + log|S| + d log(2π)`；比较相同原始行的完整边缘协方差。先评分再消费，新的整数候选继承父分支分数，不把 proposal 的旧 raw cost 另加一次。
- 模型编辑代价为 `2 log(100)`，共同平移与相对几何释放相同；工作支持宽度为 `2 log(20)`。这是工程决策规则和条件外部预测支持，不是包含足端归一化似然的 Bayes 模型概率，也不是认证误报率。
- 每次先完成全部可计算模型在同一证据进度的比较，再判断。不能先撤两足并屏蔽相交四足模型；各组的共享观测分数不能相乘或相加。
- 当全部参与比较的整数域完整且支持集只剩一个来源模型时，执行模型变更。U2仅改变未来约束；U3恢复首次影响前检查点，重算共同状态、候选及边缘化先验。若原检查点已经过期，但对应条件状态从有效原始检查点持续完整推进，可以接管该已重算的状态；不能登记撤销后继续发布受污染状态。
- U2 的消融执行状态通过逐事件回调接收与 U3 相同的因果诊断、整数和未来支撑模型策略。诊断始终比较相同的已修复模型历史，U2执行图只追加从当前事件开始的因子；不把 U2 尚未修复的共同平移污染误判为新的相对几何失效。未决模型的执行策略也相同，避免将不同决策策略混进历史修复收益。
- 固定背景模型已不获支持、但多个释放解释仍难区分时，U3输出明确标记的条件导航状态，同时保留各个受支持组合自己的物理基线方向与局部切平面协方差。不把最好分支的小 sigma 称为整个方向域的覆盖，也不回写已经发布的在线轨迹。

## 本轮范围和完整性

本轮候选族是“现有已接受背景上，一个额外实际共支撑集合的失效解释”。接受后生成新的历史版本，并重新计算相关候选背景。它不是任意多个同时失效集合的穷举，也没有证明全局连续非线性方向域覆盖。原始整数预算不足、空候选域、历史过期均不能作为唯一可信模型的证据。

完整90秒原始流实际出现429个不同共支撑集合，30秒恢复域内最多169组。首版保留这些实际假设并串行计算，先核实联合推断及实际计算成本；不为减少运行时间只挑含已知故障的组。短运行只检查接线，不能作为研究成果。

## 同步修正的物理接口

- 预测 IMU 过程协方差改由实际 `ImuFactor` 残差 Jacobian 映射，修复原手工旋转在转动时与后端坐标不一致的问题。
- 首次完整运行在5.4秒的初始两足共同释放模型查询协方差时失败。相同图经显式稀疏QR与独立密集QR得到一致协方差（最大差约3.38e-13），确认是默认局部消元路径的问题而非缺锚。修复采用局部显式QR，未加先验、噪声下限或跳过该模型；原故障点已重放通过。
- 真实输入转换保留异步 IMU、GNSS、载波和足弧源时刻；不把末次足点复制到每个 GNSS 历元当作新观测。
- 后端支持逐历元 GNSS 协方差、天线位置与速度杆臂、显式足支撑资格。速度杆臂传播了角速率方差，当前尚未建立与已用 IMU 及跨包复用样本的完整噪声交叉项；真实对比必须共同采用并明确这一近似。没有运行 BY 导航或测试集调参。

## 本轮证据

完整90秒运行结果另存新目录，保留旧注册 Go2 噪声结果。先执行 U3，核查自然选择、条件恢复、已发布轨迹和完整误差；根据结果修正核心模型，再执行相同版本必要的机制对照。不得将输入转换、短片段通过或候选数量作为三个创新点已经成立的证据。
