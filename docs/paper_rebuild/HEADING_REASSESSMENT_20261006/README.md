## 必须保留的解释边界

- M0是诊断基线，M2/M3是隔离候选；没有把新结果追认给原6468项V3矩阵。
- 新solver调用共7次：首个完成传播后被二维计数合同拒绝，严格修复运行身份后6次成功；新离线评价6次。旧6组仅复用，不重复计数为新增试验。
- 新旧12组的NAV和误差时间支持精确一致；源文件/数学代码、样本年龄与去重、协方差采样均检查。参数未按参考误差选取。
- H20同时移除航向来源及依赖它的旧HV插值支持；不是纯yaw测量开关。其航向收益必须与各自正常同窗比较。
- SDK三轴速度的frame/物理点和噪声没有独立标定；足端代理不是速度真值。商业融合参考共享GNSS来源。
- XB双FLOAT绝对位置差为10–45m量级，不能删FIX门后用作0.35m基线；参考站RELPOSNED也不能当双天线向量。
- 本轮没有运行新AR或证明新的AR方法；一周路线是资格与研究决策计划，不是已经完成的整周升级。
