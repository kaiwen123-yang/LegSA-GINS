## 1. 两条路线的明确判断

**GPS Solutions 可以沿现有 LegSA-GINS 的条件融合问题继续写，不能把既有 V3 改写成新的模糊度求解器。** 该刊面向 GNSS 模型、算法、数据分析和应用，关注有新意的应用；没有规定所有论文必须提出新的整数模糊度算法。因此，短基线 heading 的可用条件、来源相关的速度辅助和失效边界有 scope 依据，是否够新仍要通过同行文献和实验证据判断。[官方 scope](https://link.springer.com/journal/10291/aims-and-scope)

**TIM 需要一篇以测量为主的论文。** 其 scope 包含仪器、测量方法、系统和测量信息。作者指南明确区分算法 RMSE 与仪器测量不确定度，要求说明采集与测量链；单纯提高导航误差成绩，或者把现有导航稿换标题，不足以支撑这条路线。[官方 scope](https://ieee-ims.org/publication/ieee-tim)、[作者指南](https://ieee-ims.org/publication/ieee-tim/information-authors)

“GPS 优先、TIM 另建测量论证”是本项目的研究安排，不是期刊之间的学术等级判断。用户已取消 T-Mech 路线，此目录不继续该投稿建议。

## 2. 原 V3 实际做了什么

原 V3 此前暂用的论文读者名为 **LegSA-GINS**（作者现要求重新讨论正式命名）。它消费已经生成的 GNSS 位置/速度/标量 heading 与机器人 body IMU；独立 RD 派生辅助、SDK roll/pitch 和机器人报告水平速度是其他辅助来源。SDK 水平速度不是已经证明的关节编码器正运动学，也不意味着独立于姿态和 GNSS。

原 R5 heading 在两接收机 HPPOSECEF 的共同精确 iTOW 上作位置差，经冻结的 A1 坐标/安装转换生成角度。准入条件 BOTH_FIXED 表示两端 PVT 的 `carrSoln=2`，不表示噪声固定，更不表示已经测得错固定概率为零。R5 是构造配方的内部标识；实际输入有 5 Hz 共同位置键，不应把二者混为一个概念。

这条方法链中没有把双差载波相位整数作为 V3 估计状态，没有 V3 内部的 float-to-fixed 整数搜索和成功率验收。接收机内部如何得到 RTK fixed 是上游过程；同一刚体上的两个接收机各自固定的绝对位置作差，也不能仅凭这个事实宣布实际运行的是接收机间 moving-base 载波差分链。后续 raw EXT 与 FGO 是另立身份的比较，不回贴为 V3 的内部功能。

当前证据入口为[原方法与配置故事](../../V3_STORY_20261004/02_METHOD_CONFIG_METRIC_STORY.md)、[原全量版本入口](../../V3_STORY_20261004/CURRENT_STORY_INDEX.md)。当前选读实现为 `protocol_v3/providers.py` 的原 T5a 调用与字节合同，以及 `hext/t5a_provider.py` 的共同精确时间、接收机状态和角度替换逻辑。它们是当前可读源；原执行身份仍绑定原 freeze/binary，不能以当前工作树 SHA 替代历史执行身份。

原 V3 三自然序列 yaw RMSE 仍为 1.886272 / 1.933770 / 2.433815°，保留原 6,468 次矩阵。2026-10-04 的修正版自然序列、135 条件核验、严格/分段 FGO、EXT 新版本分别有其源与输出身份，均不是对原选择的无声明替换。这里不增算或重跑任何一项。

## 5. 不靠改名就能成立的贡献

GPS 当前可写的研究问题是：短刚性双天线提供的**投影方向观测**在什么几何、时间与固定状态条件下可以辅助低成本 INS；来源重叠的速度信息何时有增益，何时应退让。主张限定为相对共享商业融合参考的条件一致性，保留覆盖、失败和负结果。

TIM 候选问题是：在双接收机误差相关、投影缩短、SDK 速度依赖姿态、参考共享 GNSS 的测量链中，如何定义量、传播相关性并验证报告区间。独立物理记录、输入不确定度与覆盖验证尚缺，故它是待完成的测量研究，不是已经做完的校准结论。详见本目录后续测量模型与方向论证。

两条路线都不能把线上参考打开数为零解释成历史标定/选型从未见参考；也不能凭同参考两个 RMSE 直接扣出独立精度。安装照片支持存在一个实际装置，不提供天线相位中心长度、精确轴变换、时钟延迟或独立参考事实。
