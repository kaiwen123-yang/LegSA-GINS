# 可直接用于汇报的三张解析敏感性图

**这三张图全部是假设输入下的解析示例，不是项目采集数据、物理标定、原 V3 结果或新增方法成绩。** 本块没有读取科学输入/输出或参考，没有执行 generator、native、evaluator，也没有给原 V3 改参数。

PNG 可直接给 PPT；SVG 可编辑；CSV 保存每一点和单位。图中英文红色标注和页脚应与图一起保留，不能裁掉假设说明。数据由 [脚本](../build_assumed_sensitivity_figures.py) 仅用自身常数计算。三图已实际逐张查看，标签、单位、页脚和曲线未见遮挡；计算收据只校验假设方程，视觉审核另在 [实际视觉收据](ACTUAL_VISUAL_REVIEW.json)。生成器没有能力自称已经看图，因此其 JSON 保留脚本阶段 PENDING 字样。

|图|给读者的问题|方程与假设|可以说明什么；不能说明什么|
|---|---|---|---|
|[U01](Fig_U01_projection_correlation.png)|两端位置精度相同，为什么短基线方向质量仍差很多？|每个接收机 N/E 轴 σ=1 mm；两端交叉协方差 ρσ²I；水平投影 r=2–35 cm；一阶 uψ=√[2(1−ρ)]σ/r|展示投影缩短与共同误差抵消。ρ 和 σ 均未由项目标定；1°横线是讲解目标，不是已验证准入门|
|[U02](Fig_U02_heading_velocity_cross_term.png)|SDK body 速度旋转后，忽略姿态—速度相关是否一定保守？|水平、局部微扰；δvE=δwE+Vδψ；假设 σw=0.05 m/s、σψ=2°；V=0.5/1/2 m/s；ρ 是这两个误差的相关系数|交叉项可能增加或减少传播方差。不能当作完整 SDK 测量模型、真实速度不确定度或固定尺度标定|
|[U03](Fig_U03_asynchronous_direction.png)|相同观测标签之外，为何实际同步仍需要证据？|假设真实水平 b=[r,0]、垂直于基线的恒速 V=1 m/s；异步差为 [r,VΔt]；精确角差 atan2(VΔt,r)|这是确定性几何扰动，不是标准不确定度；不含旋转/加速，不说明原 V3 实际存在这些时差|

U01 与 U02 是局部一阶模型。圆角跨界、水平投影逼近零、非高斯/错固定时需要更完整的分布或模型，不能将曲线无限外推。U01 的正相关使差分噪声减少，并不说明融合与共享参考的相关误差也已消失；不同差分方向的相关项符号不同。

[U01 CSV](Fig_U01_projection_correlation.csv) 498 行；[U02 CSV](Fig_U02_heading_velocity_cross_term.csv) 573 行；[U03 CSV](Fig_U03_asynchronous_direction.csv) 603 行。8 项解析计算核对通过，范围仅是这里声明的常数、矩阵与单位。同行独立答复核了三式的代数前提，没有把未读脚本/未读输出说成独立脚本验收。

如需实际测量结论，必须获得接收机相关性、安装/相位中心、SDK 速度/姿态关系与时钟记录，再在未用于拟合的物理验证数据上检查覆盖。GUM 的相关传播依据为 [JCGM 100 §5.2](https://www.bipm.org/documents/20126/2071204/JCGM_100_2008_E.pdf)；显著非线性处理参考 [2026 Amendment 1](https://www.bipm.org/documents/20126/2071204/JCGM_100_Amd1_2026.pdf)。这里仅借用通用传播原则，未复刻官方图表。
