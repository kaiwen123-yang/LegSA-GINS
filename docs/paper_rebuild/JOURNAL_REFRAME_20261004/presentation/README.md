# Presentation source and validation

The delivered PowerPoint follows the supplied 36-slide institutional template. Only its original cover and content layouts form the report; speaker identity was not invented. The source template SHA-256 is `dd521f62d3ef710a0506a7f4677ed7e14564ecac2dc58785ae5b44088aadfb63`.

## Rebuild

`source/rebuild.ps1` copies source scripts and saved scientific equation renders into a private NTFS workspace, creates a bundled-node module junction, prepares private template copies, builds via `@oai/artifact-tool`, runs the presentation finalizer, and renders the exact final file for review. Use a new empty `-WorkDir` for each rebuild: finalization deliberately refuses to overwrite a prior final artifact. `-Repo` and `-Template` can override the paths. The private workspace must be on NTFS for the node_modules junction.

The JavaScript imports the Codex bundled runtime and presentation finalizer at the installed version recorded in source. The `.build/equations` assets were generated by `build_equations.py` using WSL Python 3.10 and Matplotlib 3.8.4. To regenerate just formulae, set `LEGSA_PPT_EQ_OUT` to that directory and execute that script in a Python environment with Matplotlib; this is scientific typesetting, not estimation. All formulae are also recorded as LaTeX in `equations/formulae.json`.

`prepare_template.py` checks the original template identity, converts only negative chart axis IDs to consistent unsigned IDs in the import copy, and selects the original slides 1 and 24 for font-reference inspection. It retains every other package part byte-for-byte in the typography reference. Unused original slide 32 contains unresolved East Asian font inheritance. No font was added to or substituted in the source template.

## Content and editability

The deck contains 36 native PowerPoint tables and two native charts with embedded editable workbooks. Explanatory text, boxes, connectors and photo crop are native. Scientific data figures are high-resolution raster inserts with independent PNG/PDF/SVG exports and their source CSV/script receipts; their values are not reconstructed from the picture. Scientific equations have regenerable LaTeX source. The source index records per-page paths and source hashes.

The actual platform JPEG remains unchanged. Native crops show the robot and an equipment inset. No generated pixels establish measurement geometry or calibration. Legacy multipanel figures retain full overview pages plus additional native crops with larger labels; their original pixels and scales are unchanged.

## Reviews and corrections

The 96-page candidate review records are retained as historical records, not final acceptance. They identified a joint F02/F03 RV-plus-heading change, a missing small-angle frame definition, sparse readability in two appendix figures, and wording that could imply completed uncertainty calibration. The final report corrects those points and adds four enlarged appendix pages. The heading gate table also matches archived `>=` soft-gate comparisons.

F02/F03 saved curves remain unchanged. The actual archived F02 heading sigma is 2.933193 degrees; F03 also enables Scheme-C. Their difference is not a pure RV treatment effect. The final scientific formulas use explicit right-multiplicative body small angles for velocity-error propagation, and analytical sensitivity graphics remain labeled assumptions.

`FINAL_VALIDATION.json` covers package/layout/font/native-object checks. Individual visual-review records cover the actual rendered slides. Native PowerPoint opening and PDF export are separately recorded. One expected boundary warning is the inherited cover watermark intentionally extending beyond the slide boundary; it is not content clipping.

This workflow does not run any navigation solver or evaluator, move experiment archives, or revise the original V3 matrix. The manuscript is still a scientific draft; final journal figures, actual installation records and physical uncertainty validation remain separate work.
