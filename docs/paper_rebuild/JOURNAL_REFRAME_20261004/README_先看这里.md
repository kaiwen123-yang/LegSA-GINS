## GPS Solutions：建议先收敛的论文

现有证据最适合回答：**短横向基线在什么几何、时间与质量条件下能提供可用方向；依赖航向的速度辅助在什么情况下改善定位，又会在哪里失效。**

需要严格区分接收机上游 RTK 固定、两个位置解作差、moving-base / 约束模糊度解算三个层次。当前 V3 使用上游结果，没有内部整数搜索与完整 AR 验证链。动基线和载波比较很有价值，但仅凭外部方法分数较差，不能推导它们普遍不适用于机器人。若决定以新 AR 为中心，应另行建立同信息的观测模型、整数验证、错误固定标签及复固定实验。

下一步先完成八张主图的投稿版组装（采用 R2 主图计划）、Methods 与 Results 的相互核对、全部图注与参考文献，再补实体几何、时间链和参考配置的事实。新场景验证应与原来参考可见的开发历史分开说明。

## TIM：还缺哪些实证

目前完成的是不确定度**模型与预算框架**，尚未完成物理校准或区间覆盖验证。现有 RMSE、滤波器 R / P、接收机 accuracy 字段不能直接换名为已验证测量不确定度。

优先补充：

1. 实测三维基线、杆臂、安装旋转及量测方法与不确定度；照片和位置解中位数不能代替独立量测。
2. 硬件时间链、事件时间、偏移、漂移、延迟；软件相同 iTOW 不等于物理同步已证实。
3. SDK 速度的物理点、坐标系、时间定义与内部融合说明，及其与姿态的误差相关性。
4. 两接收机联合误差、共享 GNSS 输入及参考设备配置；共享来源要如实写出，不能改称完全独立参考。
5. IMU 噪声和模型偏差证据；之后锁定模型，用未参与拟合的数据检验区间覆盖与失效域。

待补记录、优先级和验收方式详见 `venue/REQUIRED_RECORDS_AND_ACCEPTANCE.csv`。这些事实需要设备记录或实际量测；本材料没有为缺失字段编造数值。
