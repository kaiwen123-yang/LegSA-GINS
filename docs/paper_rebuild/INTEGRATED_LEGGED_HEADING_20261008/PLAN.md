# 研究计划：足式运动怎样帮助短基线航向，并在失效和中断后继续改善导航

版本：v2.1，2026-10-08。状态：计划已形成，供用户审阅；本次只修改计划，以下算法工作和新实验尚未执行。研究目标未完成。
本文件是唯一研究计划入口。v2.1替代v2.0的正文安排；历史结果及原始数据不改写。冻结V3指科学版本7d43b9af26120ed5dde21f53e515386361072ba6，与本文计划版本无关。

## 1. 要完成的研究

紧凑足式机器人在机体转动、支撑变化和载波中断下，持续获得有观测依据的可信航向，并通过共同导航状态稳定改善速度和位置。

贯穿研究的一句话：
**判断观测能否区分“机体方向错了”与“支撑本身在动”；不能区分时保留可能方向，获得足够新信息后再接受航向，发现先前依据失效时撤回相关判断，并检验这些方向信息能否改善共同估计的速度和位置。**

交付一个完整算法。足端、IMU、码/载波及合法位置速度观测共同估计姿态、速度、位置、偏置、接触运动与整数关系。足式要实际参与测量、约束、方向接受及失效撤销。允许内部代码分工，但不得生成独立足航向后重复融合，不得在输出后修补yaw或替换轨迹。

三个创新仍是候选。研究要得到适用条件、可复现机制和完整导航结果；采用成熟滤波器、增加状态或实现回放本身都不能作为创新结论。

## 2. 三个创新具体研究什么、准备怎样做

### ① 在哪些足式运动条件下，短基线观测足以辨别方向？

短侧向基线在倾斜、转动以及整数未完全确定时，可能允许不同机体方向。要研究足式支撑和惯性运动历史究竟能排除哪些解释，什么时候仍然分不清。

实施：
- 从已有原始码/相位、三维基线几何和相关误差表达产生合法方向解释，不能先假定唯一yaw。
- 在同一段共同导航历史中加入真实支撑和IMU约束，比较这些方向各自是否还能解释观测。脚处于固定接触、共同运动或局部失效时，允许的方向应随其物理解释变化。
- 研究倾斜/转动、支撑数量与几何、运动激励、可用载波关系怎样共同决定方向可辨识性；先选能区分假设的代表过程，不铺参数大网格。
- 同时检查局部可辨识自由度与相隔较远的竞争方向，形成方向可辨识的条件及不可辨识反例，并用完整观测模型核验。足/IMU自身不能无条件创造绝对yaw。正确处理会改变结论的候选，不把有限初值或搜索预算当成唯一方向证明。
- 用BY检验预测不确定性/方向范围与实际误差、误接受和覆盖是否相符，再形成测试前冻结的使用规则。工作似然分数不能自行获得校准概率含义。

应得到的成果：
**一套随足式运动条件变化的方向测量和使用规则，以及清楚的可辨识边界。**
直接证据是：同源观测下有/无足式信息时，哪些方向被排除、哪些仍保留、有效方向范围和实际误差如何变化。

### ② 足式信息什么时候可信，失效后怎样撤回它造成的判断？

支撑模型贯穿这一问题，也决定①中的方向约束是否合法。要分清机体运动、足/接触面共同运动和局部足信息异常；冲击造成的真实机体运动不能一概当作脚滑或IMU失效。

实施：
- 先研究已有证据支持的固定接触和有限共同运动，加入从实际观测推断的弧内生效时刻，保留之前的健康约束。
- 同步研究运动停止和恢复怎样保留支撑信息。现有过程表达若不能解释源观测与完整运动，可改为有依据的分段运动/有限加速度表达；模型及参数只在BY开发。
- 只有共同运动不能解释的实际相对几何异常，才引入必要的单脚/局部失效自由度。所有解释必须面对同一观测，不靠删除残差赢得模型比较。
- 足、载波、外部运动和IMU历史共同决定支撑解释与方向解释，保留来源相关性。用于初始化、评分和状态更新的信息不能重复融合。
- 对每项方向接受/排除保留其所依赖的足源与时段。后来发现该来源不成立时，同时重算受影响状态、历史先验和方向判断；此前因该足源被排除的方向，在仍符合有效观测时重新进入。
- 保留健康时间、其他有效脚、未断载波及独立运动信息。正常离地不抹掉健康过去；仅停用未来足观测不算完成历史撤销。

应得到的成果：
**可以利用、质疑并有选择地撤回足式辅助的方向判断方法。**
直接证据是：足式曾经实际改变方向使用；其依据失效后，受影响判断与共同状态确实被修正，有效信息继续起作用。

### ③ 脚在换、载波在断时，怎样保住部分方向信息并恢复导航？

不把“全部整数固定”作为所有方向信息能够使用的前提。研究未断载波关系与支撑运动历史如何共同维持仍可支持的方向，并在新观测出现后重新可靠使用。

实施：
- 某些信号中断时，保留其他仍连续的相位关系和它们支持的方向约束；只有新载波弧引入新的整数身份，物理相位误差按自己的来源生命周期处理。
- 换撑时转移仍有效的共同运动/姿态信息，并将新接触的不确定性纳入同一估计。换撑本身不能被当成新增绝对航向。
- 部分载波和支撑只能约束部分方向时，保留这些信息及剩余歧义。全相位中断时，如实传播历史方向不确定性，不能把持续输出写成持续观测支持。
- 支撑失效与载波中断同时出现时，按②撤回受影响的判断，同时保留未受影响关系。
- 新载波、有效水平激励或其他足够的观测到来后，重新比较方向解释和使用资格，检查重新接受所需时间、误接受及共同速度位置恢复。

应得到的成果：
**支撑弧与载波弧共同管理的部分方向保持和恢复方法。**
直接证据是：同一完整过程中保留了什么、丢失了什么、恢复依靠什么新信息，以及相对整体重置/不保留部分信息获得的实际增量。

## 3. 一个完整算法怎样贯穿上述三个问题

共同维护姿态、速度、位置、IMU偏置、接触几何、有限支撑运动及载波物理误差；不同合法方向/支撑解释拥有相应的条件共同状态。

每次新观测到来：
1. 用IMU传播共同状态，并更新实际支撑/载波事件。
2. 判断当前观测还允许哪些“方向＋支撑运动”解释；足式帮助辨别方向，载波和外部运动也帮助辨别支撑。
3. 对可比的同一批新观测计算联合证据，消费原始信息一次，更新共同状态及方向使用资格。
4. 如果先前依据被否定，恢复到首次受影响判断前的历史，重开相关方向并重建其共同状态；有效的无关信息保留。
5. 发布由这一共同估计产生的姿态、速度和位置，保留必要的不确定性。多解尚存时不能平均成一个无观测依据的中间方向。

计划中的典型行为如下，尚不是已经实现的结果：
载波允许A/B方向 → 支撑和运动历史更支持A → 后续证据发现相关支撑在动 → 重评A，并按有效观测重开B → 部分载波中断时保留未断关系 → 新信息足够时重新接受方向 → 同一姿态参与加速度投影和足式运动约束，改变速度与位置。
如果算法一直正确保留两种方向，就如实记录“歧义被保持并在后来消除”，不制造一次错误接受来充当撤销成果。

当前共同图、载波关系和历史重建能力继续复用。最先改动未知支撑生效时段及其方向依赖，接入已有候选提议、保留与历史恢复处；不重写成三个独立估计器。

## 4. 从第一轮开始怎样检验

从第一轮就使用同一完整算法，沿一条连续过程观察：
正常运动 → 倾斜/转动与换撑 → 有竞争方向的部分载波 → 支撑运动/失效 → 中断 → 合法新信息到来与恢复。
具体运动、噪声、观测删失和判断区间在运行前声明。真值仅用于评价，不给算法真实故障时刻，不按错误候选反推故障幅度，不预设必须发生错误接受。

该过程与BY真实开发并行：
- 连续合成过程回答方向可辨识性、来源因果和撤销机制。
- BY完整真实区间回答来源模型是否适用、航向/位置/速度怎样变化，以及与V3还有什么差距。
- 现有90秒负例继续作为对照；65–77秒p/v双赢不再阻止其他研究推进，也不能把既有失败改写为成功。

必要对照按问题选择，不形成全组合矩阵：

| 要回答的问题 | 对照 |
| --- | --- |
| 足式是否增加方向与导航信息 | 同后端完整法与无足，其他合法输入相同 |
| 改善是否来自所提方向信息，而不仅是足点平移约束 | 保持足模型和平移输入，仅改变所提方向信息的使用 |
| 过去依赖的撤销是否必要 | 完整历史修复与仅停止未来使用 |
| 部分信息保持是否有用 | 保留未断关系与中断后整体重置，使用同一原始事件 |
| 系统有没有采用价值 | 完整法与冻结V3，以及既有SDK速度方案；说明来源政策差异 |

每次实质改动同时报告：方向支持和使用、支撑解释、实际撤销与保留、因果姿态/速度/位置、恢复与失败。
源拟合更好可以支持一个物理解释继续研究；不能单独宣布导航成功。某短窗没有同时改善p/v可以继续研究；不能用它否决整个方向，也不能隐去其代价。
位置/速度变化本身不证明航向贡献。方向作用必须有保持足和平移输入的必要对照；不可人为清零状态交叉协方差制造主要消融。

## 5. 数据、参数和最终判断

- BY/BY2：模型研究、参数辨识、调参、整体开发及版本选择。参考用于离线评价，不进入在线求解或帧/符号/时偏/故障时刻选择。每次实质修改单独记录，不改写已完成试验。
- BYO/BYH：冻结版本及参数后的主要测试，不按测试误差选阈值、模型或删段；既往已见，不称新盲测。
- XB/NMB：同版恶劣实机测试，保留无法初始化、长空窗、未决和无法恢复。
- 冻结V3：主要系统对照，复用合法已有数据/结果；比较完整请求覆盖、共同物理区间及同测点误差。研究内部增益不能当作相对V3的增益。

在看测试误差前，依据BY变异与参考/外参不确定性确定有实际意义的变化和允许代价。速度使用现有近似测点转换时报告敏感性，小于其影响的变化不称已证明增益。

阶段完成：交付同一算法的可复现实质结果，明确正面/负面/未决证据和下一步。阶段可以有失败结果，不能把“阶段结果交付”写成“最终目标实现”。

最终目标成立需要：
1. 一个版本完整贯通三个创新，足式实际参与测量、约束、信息接受和失效撤销。
2. 完整过程证明方向变化有信息依据，受影响判断可撤回，有效信息保留，并通过共同状态产生速度、位置的实质增量。
3. 固定BYO/BYH结果支持稳定导航价值，V3比较不再只有更低yaw而位置速度实质恶化；健康段、困难段、尾部及覆盖均不能被平均隐藏。
4. 同版XB/NMB明确恶劣条件下的有效能力、无法初始化/不可辨识和恢复边界。缺少相关事件的数据不能证明对应机制。
5. 算法、数学说明、复现命令、必要图与正负证据形成可审查成果并推送。

稳定改善不要求每个时刻或每个小窗都赢；需要预先声明的目标条件下跨主要测试的实质支持，且没有被隐藏的实质退化。若未达到，保留成果和具体科学阻碍，整体目标仍标未完成。

## 6. 一周主攻、最多两周的推进安排

各阶段都是同一个算法的逐步完整版本，时间交叠，不是三个独立模块依次拼装。

| 时间 | 主要工作 | 本阶段必须交付什么 |
| --- | --- | --- |
| 第1–3天（10月9–11日） | 同步处理“方向错了/支撑在动”的竞争解释：足运动时段、方向接受/排除依赖、候选重新开放；并行准备真实测试入口 | 第一版贯通三问题的完整过程；清楚显示足式改变了哪些方向判断，旧负例产生何种变化 |
| 第3–6天（10月11–14日） | 按完整结果改进支撑起停/失效解释、方向使用和部分载波恢复；同版BY完整开发及必要归因 | 三创新各自作用及相互关系的明确证据；方向对共同v/p的增量或具体失败原因 |
| 第5–7天（10月13–15日） | 收敛BY开发参数、算法规则与测点口径，冻结并开始BYO/BYH | 第一周统一研究版、V3开发比较、首轮主要测试与尚未解决问题 |
| 第8–12天（10月16–20日） | 完成BYO/BYH和同版XB/NMB；只针对已证实问题回BY修正并重测受影响结果 | 固定真实测试结论、恶劣条件能力和失效边界 |
| 第13–14天（10月21–22日） | 收敛算法说明、必要对照、两幅核心图、复现入口和结论 | 一个完整可复现算法及三创新证据；明确目标已实现或尚缺什么 |

测试序列入口与真实缺测处理从第一天同步准备。支撑模型研究贯穿完整开发，不因一个短窗未赢而被抛弃，也不因拟合改善而无限扩张。
现有90秒自动约33分钟、BY旧配置完整运行约2小时22分钟，仅为已完成版本量级；新候选扩张可能更慢。按实际计时安排有判别力的完整对照，不重复无信息的参数网格。
第一周必须交付完整研究判断，第二周集中实测与收敛。时间限制约束工作和交付，不能保证自然实验必然得到正结果，也不能据预算截止把科学目标改成完成。

## 7. 什么情况下更改滤波方式

复用当前共同估计器，但不把其形式当成研究前提：
- 合法分离方向被单一Gaussian丢掉：可改联合多假设/条件平滑表达。
- 边缘化使必要历史撤销失真：可改时滞、历史保留或可恢复稀疏平滑方式。
- 线性化/误差定义虚构可观测信息：可改参数化、迭代或不变误差表达。
- 实测计算增长已阻止核心完整验证：可改共享计算和稀疏后端，必要时更换求解方式。

每次说明受限能力、所改数学表达及一项完整同源前后对照。无论怎样改，保持共同输入、共同R/p/v/b、来源相关性和可撤销方向判断；不能退回独立航向模块加事后导航融合。

## 8. 怎样边做边调整、怎样推送

每完成一部分，回答四件事：这次新增了什么科学证据；原假设哪里成立/不成立；下一项改动怎样影响三个创新；对完整导航收益和剩余时间有什么影响。
据此直接更新本计划，再提交推送必要代码、配置、结果、图和复现命令。有效负结果也要推送，运行完成/机制成立/目标完成分开记录。
每轮围绕一个决定性物理问题，可同时修改其相互依赖的支撑和方向表达，不为形式上的分工拆散算法。测试暴露通用错误时回BY修正，统一冻结再测，保留已见测试身份。
两幅主要图分别回答“方向为何接受、保持、撤回和恢复”与“同一过程中速度位置是否改善”。不先铺大量图或提前写完整论文替代算法工作。
候选创新的新颖性需与相关方法对照论证，但现阶段首要交付是这条完整算法及其证据，不能以术语命名代替创新。

## 9. 禁止事项

1. 禁止把一个因子、一次拟合、短窗改善、状态变化、测试数量或材料齐全说成三个创新及整体目标实现。
2. 禁止只讲宏观框架却不处理几何、支撑物理、源相关性、方向歧义、真实时序与历史依赖。
3. 禁止独立模块拼盘、独立足航向重复融合、yaw后处理、轨迹替换及不同版本最佳片段拼接。
4. 禁止舍弃支撑运动研究或用单窗口p/v双赢锁住全部研究；也禁止无限研究支撑拟合却不检查方向判断和导航作用。
5. 禁止防御性编程及保守性测试扩张：通用故障平台、过量守护、全仓回归、重复哈希封包、只挑容易短窗、无限预检及长期全部拒收。保留科学所需的公式、信息计数、真实缺测和历史因果检查。
6. 禁止用真值故障时间、参考选帧/符号/时偏或错误候选反推故障幅度来制造成功；不能把触地/冲击一律当作坏数据。
