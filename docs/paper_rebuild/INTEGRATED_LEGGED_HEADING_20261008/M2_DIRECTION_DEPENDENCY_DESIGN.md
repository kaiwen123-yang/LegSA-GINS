## 2. 先复用共同运动模型，不预先增加相对足失效自由度

共同平移不破坏足间相对几何，但能改变“足运动相对于GNSS世界平移”的绝对航向解释。令真实姿态R_t、另一个姿态R_a=Z(delta)R_t，身体世界速度v、共同接触世界速度u。足点r满足：

\[
\dot r+\omega\times r=R_t^T(u-v),\qquad
\dot c_a=v+R_a(\dot r+\omega\times r).
\]

当u=(I-Z(-delta))v时，另一解释的接触点静止。水平速度对应的滑移量为2||v_h|| |sin(delta/2)|。这一关系用于说明不可辨识性，不从选中的错误候选反推滑移幅度来制造成功。

条件是接触锚点未被更早独立健康历史固定；匀速或仅垂向加速度不给额外绝对yaw约束；原始载波确实支持相应方向和连续整数。码观测仍会统计地区分方向，不能宣称全部观测严格同分布。纯机体转动不会自动消除世界yaw对称；其载波几何变化可能消除它。

现有合成GNSS杆臂为零。非零杆臂转动时必须同时处理p_A=p_B+R*l_p和v_A=v_B+R*((omega-b_g) cross l_v)，不能强令竞争姿态共享相同机体速度后套用上述简化。

健康新撑不是在线真值标签。若新旧支撑都允许共同运动，竞争解释可能仅交换“哪段固定/哪段移动”；不能将换撑本身当绝对方向恢复。需要一致生成的水平加速度与GNSS、独立新相位关系或确有信息依据的既往接触约束破局。

因此M2先采用预先声明的一条相位关系和有共同接触运动的匀速阶段，随后共同运动平滑停止、正常换撑、真实水平加速度/转弯及新载波关系。保留后续部分/全相位中断和恢复，使用同一个JointNavigator与共同状态。具体运动和中断时序在M1判决后声明，再作一次新场景的合法观测前提核对；不能把本次旧场景诊断替代它。

这是针对可辨识性与依赖撤销的构造场景，不能代替BYO/BYH/XB/NMB自然性能证据。若算法始终保留不确定方向而未错误收缩，这是正确保留；不能谎称“错误航向已恢复”，也不得弱化传感器或放宽门限制造该情节。

## 3. 当前最重要的算法缺口

navigator._contact_support（740–748行）在已保留的整数分支×支撑模型上比较最小分数。_propose（929–941行）按含足图误差保留有限活动支，其余保留为dormant和未完成状态。当前proper模型的observed_groups仅覆盖单组变化（_register_support_group、_policy_search_readout）。这些诚实的范围标记没有把局部赢家称为全域可信，但仍未满足正式方向接受：被足信息筛出或预算遗漏的整数，与后来变化的支撑解释组合后，可能重新支持不同航向。

M2优先修补的是方向接受对源依赖撤销的闭合，不是增加模型种类：

1. 沿现有整数提议/条件与候选保留处记录排除所依赖的足弧；计算预算省略不等于科学排除。
2. 足源失效时，从首次依赖前重建，撤回受影响的整数排除并重新开放相应方向，同时保留独立有效载波及未失效支撑。
3. 可能改变方向结论的遗漏单元必须实际展开，或由同一观测分数的有效界排除；否则保留未决方向，不能以“已评估集合唯一”恢复全域接受资格。

复用现有重放、整数物理关系与共同状态，不建立独立的资格模块。保持本轮2log20工作带，不用新增先验、任意门限或无信息协方差代替覆盖问题。整体验收还包括原始方向信息对共同p/v的增量、历史修复相对仅未来停用的作用；几何预检和元数据增加均不能代替这些导航证据。
