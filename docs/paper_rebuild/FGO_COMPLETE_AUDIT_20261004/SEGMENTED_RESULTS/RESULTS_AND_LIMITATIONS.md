## 4. 同一物理点和支持的结果

参考仍共享 GNSS 来源，其独立真值、实物杆臂/安装/时延标定不足的边界未消除。没有插值方法输出、补造 IMU 缺失数据或把先验当动态解。离线参考按原冻结 LLH/RP 线性及 unwrap yaw 规则插值，插值左右时间/span 全保存；三个窗支持上的最大参考 bracket 分别 0.104911/0.103166/0.105823s，这与 native IMU 缺口不是一回事。

## 5. 3286 秒求解诊断：仍未收敛

新第二独立区段在真实 3286 秒仍发生 `TerminationType.NO_CONVERGENCE`，20 次更新（Ceres 报告 21 含初始），`nonlinear_solution_usable=true`。初始 cost 182.28415553565，末次 cost 182.27212349850；继续用该有限迭代可用终态，没有重启、加迭代或按 GT 判断是否接受。

重线性化前/后维度450，对角均衡 normal 数值 rank 均450（relative1e−12诊断定义），condition 约9.585e5；滑窗后435维 rank435，condition约9.256e5。三份 NPZ 独立重算 eig/rank/condition；浮点 eig 舍入引起 condition 相对差最多8.80e−10，核查容差1e−8仅用于保存矩阵算术复算，不是 solver/support 准入阈值。normal condition 近似 Jacobian condition 的平方，不能把该数值直接称为病态故障证明；full local rank 也不证明全模型或作者实现完全正确。

末次 whitened 因子平方和：GNSS dim3 6.698103；IMU dim15 230.474043；边缘先验 dim15 127.372101；half-squared 总 cost182.272123。它们是不同残差/噪声下的加权量，不可当物理米/角度误差分解或参考成绩证据。

历史旧 3286 也曾为可用未收敛终态，但新段初始化、模型和图历史不同，不能声称重现了旧完全相同优化问题，也不能从新 cost 变化推断“旧错误修复收益”。`TARGET_EVENT.json` 继承 core 的 per-sequence/no-restart 描述，在本 wrapper 指每个独立块内部的一次初始化；真实总体 7 次初始化以 BLOCKS/全部初始化账本为准，未改封存字段。

完整小载荷及矩阵在 `target_3286/`。当前结论是“完成诊断，未证明收敛问题已解决”；进一步作者等价收敛轨迹/精确缓存边界仍需独立证据，不能按 RMSE 调参掩盖。
