# Algorithm Overview

LegSA-GINS is planned as:

1. final_v23-style mature GNSS/INS backbone;
2. LegSA-ESKF source-aware filtering;
3. raw Doppler auxiliary factor;
4. Go2 yaw-rate and attitude weak priors;
5. support/gait/contact integrity features;
6. no-feedback fixed-lag smoothing;
7. reference-uncertainty-aware evaluation.

N0 does not implement algorithms.
