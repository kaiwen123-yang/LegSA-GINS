# PAPER4A Limitations Draft Bullets

- Physical body-yaw frame closure remains blocked and requires user-provided installation/extrinsic evidence.
- External literature methods are not exact reproductions; the supported wording is PDF-grounded native/proxy/backend-level implementations.
- Provider v4 is GPS+BDS residual-ready, while Galileo, GLONASS, and SBAS remain blocked.
- BY3 yaw is diagnostic-only and cannot support ordinary yaw generalization.
- XB/PG severe poor-GNSS data motivate a quality-aware fallback but do not prove high-precision performance.
- Same-evaluator superiority is not claimed because internal baseline join/provenance is incomplete.
- Trace remains evaluation-only; receiver IMU remains diagnostic-only.
