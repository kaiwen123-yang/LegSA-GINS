# Abstract Draft Boundary Safe

This paper studies GNSS/INS fusion for legged robot navigation using a dataset-role-aware stress protocol. The current write-ready evidence supports BY2 as the full-metric main dataset, BY3 as an independent position/up stress dataset with diagnostic-only yaw, and XB/PG as severe poor-GNSS stress data used for limitation analysis and quality-aware fallback motivation. The evidence package includes a quality-aware measurement management behavior matrix with seven recognized GNSS/INS QA methods, a BY2 120-case degradation protocol, and a provider construction chain from raw receiver data through RINEX and DD/LOS-backed literature module diagnostics. Later provider stages add GPS+BDS DD/LOS/covariance/residual-ready evidence. External literature modules are reported as PDF-grounded native/proxy/backend-level implementations and DD/LOS-backed literature module diagnostics, not as exact reproductions. Body-yaw claims, same-evaluator superiority, BY3 yaw generalization, and severe-GNSS high-precision claims remain outside the supported claim boundary.
