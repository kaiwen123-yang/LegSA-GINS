# Experiment Section Draft Bullets

- BY2 is used as the full-metric main dataset and supports the 120 canonical degradation family design.
- PAPER2A provides the quality-aware measurement management behavior evidence: seven recognized GNSS/INS QA methods completed BY2, BY3, and XB rows with trace online use disabled and receiver IMU as body IMU disabled.
- PAPER3D-R2 through PAPER3I provide the provider construction chain from Linux RTKLIB/RINEX reconstruction to GPS+BDS DD/LOS/covariance/residual-ready evidence.
- PAPER3E/F/G/H/I provide DD/LOS-backed literature module diagnostics and PDF-grounded native/proxy/backend-level implementations for appendix use.
- BY3 results are used only for position/up stress and diagnostic yaw discussion.
- XB/PG results are used only for severe poor-GNSS stress, limitation analysis, and quality-aware fallback motivation.
- Body-yaw RMSE, yaw superiority, same-evaluator superiority, and exact reproduction figures are omitted because the required proof is blocked.
